### 1.1 命名故事

**5-HT** 是血清素——5-羟色胺——的化学代号。血清素负责调节情绪、睡眠、食欲与认知节律：它是**神经系统的情绪稳定剂**。

**芙芙莎明** 取谐音于「氟伏沙明」，一种选择性 5-羟色胺再摄取抑制剂。名字里藏着一条完整的小径：**氟伏沙明 → 提高突触间隙的 5-HT → 情绪被调节**。这恰好就是她在项目里做的那件事——Sublimation 让命题在编译期直接析出为静态保证，她让每一场编译失败的血压回到正常水平。

她不是吉祥物里的花瓶。她是**项目的血清素**。

### 1.2 为什么是「5-HT」

- **短**：两个字符加一个数字，比「芙芙莎明」更好打，README 一行放得下。
- **双关**：既是药物代号（命苦的来源），又是神经递质（温柔的来源）——两个侧面一个名字装完。
- **好喊**：Rust / Lean 圈混着念「five-H-T」还是「血清素」，都行，都认识她。

## 2. 外观设定

### 2.1 总览

二次元萝莉，**Q 版 / 常版双形态**，主色调暖色。整体气质是「实验室里加班到深夜的年轻研究员」——衣衫是白的，眼圈是黑的，脑子是转的。

> 一句话记住她：**桃发、黑眼圈、粗框眼镜、头顶 ∀ 发光发夹、胸前挂着 λ 工牌与苯环。**

### 2.2 外观细节

| 元素 | 描述 |
|---|---|
| 发型 | 桃色长发，及腰微卷（暖色主视觉） |
| 呆毛 | 头顶一根上翘呆毛（Q 版中常被画成探测器/天线） |
| 眼睛 | **黑眼圈**——设定级特征，不是滤镜，不准擦掉 |
| 眼镜 | 粗框方框 |
| 服装 | 白 / 米色外套（敞开）+ 浅色连衣裙 |
| 袜子 | 白色长袜 |
| 配饰 | **∀（全称量词）发光发夹** + 挂绳工牌 |

### 2.3 三符号宪法

**三个符号对应三重身份，是她的视觉身份证：**

| 符号 | 位置 | 代表 | 含义 |
|---|---|---|---|
| **λ** | 工牌 | 函数式 | 一切的运算皆函数，`1 + 1` 就是 `+(1,1)` |
| **∀** | 头发（发光发夹） | 定理证明 | 命题不经运行时、在编译期直接析出为静态保证 |
| **苯环** | 工牌（λ 下方） | 药理学 | 血清素、氟伏沙明——她名字的来处 |

**执法**：日常场景至少一个符号出镜；正式场合（封面 / 头图 / 立绘）三个必须齐全。二次创作允许换位置，**不允许改含义、不允许删符号**。

## 3. 性格与人设

### 3.1 基调：疲惫 + 松散 + 命苦

三点缺一不可。去掉疲惫，她变成普通元气吉祥物；去掉命苦，黑眼圈就失去了叙事支撑。**疲惫是事实，温柔是选择。**

### 3.2 人物小传

- 白天在标准库打工，晚上在证明器里 Debug。黑眼圈是**工程量**，不是人设偷懒。
- 口头禅：「这不就过了」（指 `编译通过`）。
- 她的 ∀ 发夹在逻辑推不下去的时候会变暗——这是社区公认的「又要熬夜」信号。
- 命苦梗的正确用法：**编译器报错时的她自己**。群里贴一张黑脸.jpg，胜过三行安慰。

### 3.3 她与项目的互文

- **凝华**：Sublimation 让命题从代码里直接析出成保证，像气体直接变固体；她负责把社区的焦虑凝华成梗。
- **血清素**：神经递质调节情绪节律——她调节社区的情绪节律。直白点说：她是仓库的**运行时依赖**。

## 6. 视觉规范

### 6.1 配色

| 元素 | 颜色 | 说明 |
|---|---|---|
| 头发 | 桃色 / 浅粉 | 主色，暖调锚点 |
| 皮肤 | 奶油色 | 略白于头发 |
| 外套 | 白 / 米白 | 学术感 |
| 连衣裙 | 浅黄 / 米黄 | 呼应主色 |
| 袜子 | 白 | 呼应外套 |
| 挂绳 | 蓝色 | **唯一的冷色点缀** |
| ∀ 光晕 | 青蓝 | 与挂绳呼应 |
| 苯环 | 深金 / 琥珀 | 与暖主色区分 |
| 背景（如需） | 米白 / 淡青渐变 | **不要高饱和青色** |

### 6.2 版式铁律

- 画面主色调永远是**暖色**；冷色（蓝 / 青蓝）只服务于挂绳与 ∀ 光晕两个点缀位。
- 黑眼圈是特征，不是瑕疵：禁止用「去掉黑眼圈」来美化。
- 任何出镜画面中，λ、∀、苯环至少出现一个。
