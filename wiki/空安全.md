# Optional 容器

没有 `null` 裸奔——可能缺失的值用 `Optional[T]` 显式表示。空安全语法糖（`T?` 后缀、`?.`、`?:`、`as`、`Some` → `T` 隐式解包）已移除：Optional 就是一个普通的二值枚举容器，读写一律走显式手段。

## Optional 类型

`Optional[T]` 是两值枚举：

| 值 | 含义 |
|----|------|
| `Some(x)` | 有值 x |
| `None` | 空 |

```subl
var a: Optional[Nat] = Some(42)
var b: Optional[Nat] = None
```

## 解构取值（when）

```subl
when (maybe) {
    Some(v) -> print("有值：$v")
    None    -> print("空的")
}
```

## ifis 智能解构

只关心一种形状时用 `if (m is Some(v))`（脱糖为 `when`，见《模式匹配》）：

```subl
if (m is Some(v)) { print(v) } else { print("空") }
```

## 兜底默认值

没有 `?:` 空替代运算符——用 `when` 解构或 `getOrElse` 方法显式给默认值：

```subl
fun nameOr(maybeName: Optional[Str], fallback: Str): Str = when(maybeName) {
    is Some(n) -> n
    None -> fallback
}

var name = maybeName.getOrElse("无名")
```

## 方法链

Optional 上的函数式方法：

```subl
maybe.map({ v -> v + 1 })                    // Some(v+1) 或 None
maybe.flatMap({ v -> moreOpt(v) })           // 展平
maybe.getOrElse(0)                           // 取值或默认
maybe.isSome() / maybe.isNone()              // 判断
```

## 一句话

- 拿空值 → `None`；拿有值 → `Some(x)`。
- 读值 → `when { Some(v) -> ...; None -> ... }` 或 `map`/`getOrElse` 等方法。
- 类型上写下 `Optional[T]`，不存在隐式解包：把 `Some(x)` 当 `T` 用是类型错误。
