# Optional 容器（空安全）

没有 `null` 裸奔——可能缺失的值用 `Optional[T]` 显式表示。空安全语法糖（`T?` 后缀、`?.`、`?:`、`Some` → `T` 隐式解包）已移除：Optional 就是一个普通的二值枚举容器，读写一律走显式手段。

> v4 终版：when/ifis 分支一律用 `=>`（旧 `->` 已废除）。

## Optional 类型

`Optional[T]` 是两值枚举（标准库 `core/collection/optional.subl`）：

| 值 | 含义 |
|----|------|
| `Some(x)` | 有值 x |
| `None` | 空 |

```subl
var a: Optional[Nat] = Some(42)
var b: Optional[Nat] = None          // 无参构造子，写 None() 也可以
```

## 解构取值（when）

```subl
when (maybe) {
    is Some(v) => print("有值：" + toStr(v))
    None       => print("空的")
}
```

## ifis 智能解构

只关心一种形状时用 `if (m is Some(v))`（脱糖为 `when`，见《模式匹配》）：

```subl
if (m is Some(v)) { print(v) } else { print("空") }
```

## 兜底默认值

没有 `?:` 空替代运算符——用标准库的 `getOrElse` 方法显式给默认值，或用 `when` 解构：

```subl
fun nameOr(maybeName: Optional[Str], fallback: Str): Str = when(maybeName) {
    is Some(n) => n
    None       => fallback
}

var name = maybeName.getOrElse("无名")      // 取值或默认
var alt  = maybeName.orElse(otherOpt)       // 空时切换到另一个 Optional
```

## 方法链

Optional 上的函数式方法：

```subl
maybe.map({ v => v + 1 })                    // Some(v+1) 或 None
maybe.flatMap({ v => moreOpt(v) })           // 展平（Some→Some，None 短路）
maybe.filter({ v => v > 0 })                 // 谓词不成立时降级为 None
maybe.getOrElse(0)                           // 取值或默认
maybe.orElse(Some(7))                        // 空替代
maybe.isSome() / maybe.isNone()              // 判断
maybe.toResult("err")                        // 转 Result（None → Err）
maybe.toList()                               // 转 List（Some(x) → [x]，None → []）
```

链式写法推荐用尾随 lambda：

```subl
var result = maybe.map { v => v + 1 }.getOrElse(0)
```

## 与 Result 互转

`None` 携带错误信息时转 `Result`；反之亦然：

```subl
var r: Result[Nat, Str] = maybeName.toResult("缺少名字")   // Some(v)→Ok(v)，None→Err(...)
when (r) {
    is Ok(v)  => print(v)
    is Err(e) => print("错: " + e)
}
```

## 自己写兜底函数也行

Optional 的方法都是普通自由函数的扩展调用糖（`o.getOrElse(d)` ≡ `getOrElse(o, d)`），所以通用兜底函数随手就能写一个：

```subl
fun elvis[T](o: Optional[T], d: T): T = when(o) {
    is Some(v) => v
    None       => d
}
```

## 一句话

- 拿空值 → `None`；拿有值 → `Some(x)`。
- 读值 → `when { is Some(v) => ...; None => ... }` 或 `map`/`getOrElse` 等方法。
- 类型上写下 `Optional[T]`，不存在隐式解包：把 `Some(x)` 当 `T` 用是类型错误。

> 类型长了用别名缩短（决策 30）：`type NatOpt = Optional[Nat]`、`type Box[a] = Optional[a]`，见《Home》的类型别名一节。
