# 模块系统

## 目录即模块

- 编译入口根目录 = 根模块；子目录 = 子模块；模块名 = 目录路径（如 core/math）。
- 多模块编译：compile <根目录> -o out.js 时编译器采集模块树。

## 挂载（mount）

settings 文件命名 <模块名>.settings：

```text
mount core/math as math
mount db as db
```

- mount <path> [as <alias>]：把子模块挂进可见路径，递归传递、禁止成环。
- 别名可选；跨模块引用 alias.name 或裸名（可见路径优先）。

## 隐式 std

stdlib/ 隐式挂载：List/Cons/size/… 直接可用；跨模块定理搜索含 stdlib 定理空间。

## 跨模块搜索

- 名字解析：只查 visible(模块) 的符号表。
- 类型类字典：只查可见路径里的 impl。
- 定理搜索：searchTheorems 遍历本模块 + 可见路径各模块 theorems 表。

## 目录布局示例

```text
project/
├─ main.subl            # 根模块（入口 main）
├─ main.settings        # mount core/logic as logic
├─ core/
│  ├─ logic.subl        # 定理库（core.logic）
│  └─ classic.subl      # 经典逻辑（core.logic.classic）
└─ stdlib/              # 隐式挂载的 std（编译器内置目录）
```
