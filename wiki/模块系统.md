# 模块系统

## 目录即模块

一个目录 = 一个模块。项目里每个子目录默认是一个独立模块。

```
MY_PROJECT/
  main.subl                ← 根模块（有全局唯一 main()）
  MY_PROJECT.settings      ← 根模块声明（mount 依赖）
  core/                    ← 标准库包（隐式自动挂载，无需声明；见下节）
  users/                   ← 子模块目录
    users.subl
    users.settings
```

## 挂载 mount

在 `.settings` 文件里用 `mount` 声明依赖：

```
# MY_PROJECT.settings
mount users
mount core.math
```

- `core/` 标准库包**隐式自动挂载**——任何模块都能直接用（裸名 + 限定名，见下节）。
- 挂载后，被挂载模块里的类型、函数、构造子、定理对当前模块可见。

## core 统一标准库

标准库是名为 **core** 的**包**（目录下只含子包目录、无直接源文件），约定两种布局：

- 编译入口取标准库的父目录：入口目录下有 `core/` 子目录（如 `compile MY_PROJECT`，
  MY_PROJECT/core/ 即标准库）；
- sublimation 仓库布局：标准库位于 `<仓库根>/test/core`——编译入口取仓库根时，
  `test/core` 自动**嫁接**为根的 `core` 子树（absPath 前缀变为 `core/...`）。

core 是包目录：它的每个子包（core.math、core.collection、core.string…）各自是模块，
带自己的 `<name>.settings`；core 根本身没有 settings。子包之间一律按**完整包名**互引
（`core/logic/logic.settings` 写 `mount core.math`）——不能用 `mount core`，因为 core 根
没有 settings，且根模块不能挂自己的直接子目录（局部名冲突）。

### 隐式挂载

编译器为每个非 core 模块注入标准库挂载：core 的全部子包按名字挂入（`mount core.math`、
`mount core.collection`…），core 根跳过。因此任何用户模块**无需任何 settings** 即可：

- 裸名调用标准库符号（`gcd(3, 4)`、`Cons(1, Nil())`、`mapOk(r, f)`）；
- 全限定调用（`core.math.gcd(3, 4)`、`core.collection.size(xs)`）。

用户模块自带的同名子目录优先：`proj/core/` 存在时，`proj` 的 `core.xxx` 指自己的子模块，
不再隐式挂载标准库的 `core/math` 等（局部名 core 已被占用，注入跳过名为 core 的挂载，
其余子包仍注入）。

## 完整包名挂载

挂载路径支持**点分完整包名**——`core.math` 与 `core/math` 等价。多段目标挂载后，
它的**前缀包一并隐式挂载**，因此 `mount core.math` 之后，全限定调用 `core.math.gcd(...)`、
短名调用 `math.gcd(...)`、裸名 `gcd(...)` 三者皆可：

```
# p/settings —— 挂载 core 标准库的 math 包
mount core.math

# p/main.subl
fun main() { print(toStr(core.math.gcd(12, 8))) }   // 全限定：前缀包 core 隐式可见
```

根模块不经任何挂载即可以全限定名调用子包（`core.math.gcd(...)`），
裸名仍需挂载（挂载传递后可见）。

## 跨模块解析

裸名自动跨模块解析：

```subl
// 本模块没有定义 Ok/Err，但 core/collection 有——直接可用
var r: Result[Nat, Str] = Ok(42)
```

构造子（如 `Ok`/`Err`）、结构体、函数、定理都会在可见模块（含 core）里依次查找。

## 定理跨模块搜索

证明时，定理搜索沿可见路径跨模块展开：

```subl
+∵ n ∈ (0..30)
∴ n ≥ 0            // 命中 core/logic/logic.subl 的 rangeLowerBound / natNonNeg
```

## 编译

```bat
java -jar sublimation.jar compile MY_PROJECT -o out.js
node out.js
```

用目录路径作为编译入口（而非单个文件），即走模块系统。
