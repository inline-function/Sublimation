# 命题（Prop）

> wiki/03-证明-命题 · 事实来源：compiler/.../checker/Prop.kt（778 行）规范化机制、_langfacts.md §4

命题是证明层的「事实单位」——与程序层的值分流，只存在上下文 Γ 与约束位里。

## 语法

```subl
p                           // 0 元原子（标识符命题）
valid<7>                    // 参数化原子：名字 + 角表实参
$ == 7                     // 比较原子（$ 的 eq）
<p → q>                     // 蕴含（命题位 →）
<p ↔ q>                     // 等价（↔ 等同 <->）
<p ∧ q ∨ ¬r>                // 逻辑算符（Unicode 或 ASCII 归一：and/or/not）
forall n. tagged<n>         // 全称量化（∃/exists1 同理）
axiom p1, p2                // 独立公理语句（顶层+函数内）
```

命题出现的合法位置：
- **约束位**（角表）：函数签名 `<p>` 上文、`<$ = 7>` 下文、后件 `<tagged<7>>`
- **axiom 语句**（免验证注入 Γ）、`∵ p1, p2 ∴ q` 链、`expr by [q]`（t30 后：断言——核对成立但不注入）
- **when 命题条件位**：`when[p ∨ q] { (p → q) => { … } }`（蕴含须括号）

## 语义

### 原子化与归一

一切命题规范化为 **PAtom**（名字+可选参数序列）与逻辑组合：
- 比较式经求值折叠成 PAtom：如 `$ + 1 == n` 归一到等式原子（算术通道入口）
- ASCII/Unicode 算符等价归一：`and`⇄`∧`、`or`⇄`∨`、`not`⇄`¬`、`in`⇄`∈`、`!=`⇄`≠`、`<=`⇄`≤`
- 蕴含/等价保持二叉结构（BinExpr），参与 MP 闭包

### Γ 与推理

- `allFacts`：全域事实池（axiom、自动事实、下文弥散都注入）
- **分离 MP 闭包**：池中 `p ∧ (p → q)` 饱和产出 `q`（每次有新事实加入重跑）
- **∀ 实例化**：`forall n. P(n)` 的 n 可用池中命题实例分派（激进模式开启命题维穷举）

### 求值通道

- **算术通道**（ArithProve）：`≤`/`=`/整数常量构成差分图与等式链，`a ≤ b` 走边、`a = b` 双向边+传递，常量折叠降维
- **变量赋值通道**：`@var` 前进产生旧值等式 `k == n` 形态的 PAtom

## 示例

```subl
@impure fun main() {
    axiom forall n. tagged<n>
    axiom p ∧ (p → q)          // MP 闭包自动产出 q
    ∵ p ∴ q                     // 证明义务（q 已在 Γ ⇒ 直通）
    ∵ forall m. tagged<m> ∴ tagged<3>   // 实例化
}
```

## 陷阱

- **`→` 不可写 `->`**：命题位 ASCII 箭头非法（诊断指向 token）
- **原子不是函数调用**：`p(7)` 是程序层调用；命题参数走角表 `p<7>`
- **蕴含在 when 分支条件位须加括号**：否则被条件解析吃掉
- **MP 闭包是有向饱和**：`q ∧ (p → q)` 不产 p；反向不行
- **命题算符没有优先级**：和表达式一样全左结合，复杂式加括号
- **`≠`/`∈` 归一发生于命题层**：程序层比较表达式的 `!=`/`in` 与命题层语义不同（前者求值，后者入 Γ）
