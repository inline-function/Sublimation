# 上下文与自动证明

上下文系统让命题成为一等公民：代码里的断言可交给编译器证明，失败即编译错误。

## 记号

| 记号 | 含义 |
| --- | --- |
| `∵` | 从当前事实推导（R 即 Given） |
| `+∵ p` | 无条件把 `p` 注入当前作用域 |
| `∴ q` | 求证 q：从 Γ（事实多重集）与定理空间证出，否则 `E-CANNOT-PROVE` |
| `if[p]` | 命题守卫：分支成立的前提是 p 可真 |
| `<前件>` | 函数声明的前置前提 |
| `<$后件>` | 函数声明的结论；`$` 指代返回值 |

## 例：区间推理

```subl
@root fun ..(l: Int, r: Int): Range[Int]
    <∀n. n ∈ $ → n ≥ l, ∀n. n ∈ $ → n ≤ r>

+∵ n ∈ (0..30)
∴ n ≥ 0        // 证明：n ∈ (0..30) → n ≥ 0，由区间下界与 n ≥ 0 自然命题推出
```

## when 区间的穷尽性

编译器收集每个分支区间的**端点作为关键表达式**（如 0, 10, 11, 20, 21, 30），排序后检查相邻衔接：
当 `+∵ n ∈ (0..30)` 且分支覆盖 (0..10)(11..20)(21..30)，自动证明系统必须证明穷尽，否则报 `W-NON-EXHAUSTIVE`。

```subl
+∵ n ∈ (0..30)
when(n in _) {
    (0 .. 10)  -> print(1)
    (11 .. 20) -> print(2)
    (21 .. 30) -> print(3)
}
```

## 自动自反与范围

- 结构相同的表达式自动相等：`1 + 2 = 1 + 2` 可直接证明；`1 + 2 = 3` 不自动证（需要定理）。
- 每一个自然数恒有自然命题 `n ≥ 0`。

## 定理空间

- 定理 = 无 `@impure`、参数无 `@mut`、返回 `Null` 的函数（自动登记，无 `@theorem` 注解）。
- 证明搜索跨模块：可见路径各模块的定理空间全部参与（`searchTheorems`）。
- 预置库：`core.logic`（`rangeLowerBound`、`leqTrans`、`modusPonens` 等）、`core.logic.classic`（排中律、双重否定、换质位）。

## 规则

- **上下文中的表达式必须是纯的**：证明系统不处理副作用。
- 找不到证明 → 报错并列出尝试过的定理；绝不悄悄放行。
