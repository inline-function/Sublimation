# 名字与作用域

> wiki/01-基础-名字与作用域
> 主题域：词法作用域、反引号名、Unicode 名、`_` 隐式形参、`$n` 参数引用
> 事实来源：_langfacts.md（§1/§2/§5/§6）+ lexer/Lexer.kt（全文，实测 245 行）+ parser/Parser.kt（:56-70、:82-92、:1315-1349、:1684-1764）+ interpreter/Evaluator.kt（:833-863）；未坐实处标 待核

名字是绑定发生的地方。本条目回答两个问题：**什么字符序列能当名字**（词法层），以及**名字在何处可见**（作用域层）。变量绑定与可变语义见 [变量与绑定](01-基础-变量与绑定.md)，箭头形态见 [箭头家族](01-基础-箭头家族.md)，函数类型层见 [函数类型](02-类型-函数类型.md)。

## 语法

### 名字的词法形态

| 形态 | 写法 | token | 出处 |
|---|---|---|---|
| 普通名 | `add`、`_tmp`、`x1` | IDENT | Lexer.kt:102、208-213 |
| Unicode 名 | `整数`、`δ`、`中文_α` | IDENT | Lexer.kt:99、208-213 |
| 反引号名 | `一个 名字`、`a+b`（反引号括起） | IDENT | Lexer.kt:193-206 |
| 符号名 | `∈`、`≤`、`⊕`（连续符号字符合并） | SYMBOL | Lexer.kt:230-242 |
| 合成名 | `recomposion$Box$1` | IDENT | Lexer.kt:214-225 |
| 参数引用 | `$1`、`$2`（`$` 紧贴数字） | DOLLAR | Lexer.kt:146-150 |
| 返回值符号 | `$`（后不紧贴数字） | DOLLAR | Lexer.kt:129、Parser.kt:1325 |

以词法器为准的文法片段：

```
名字      ::= 普通名 | Unicode名 | 反引号名 | 符号名 | 合成名
普通名    ::= ("_" | 字母) (字母 | 数字 | "_")*         // 字母含中/希/英（isLetter）
反引号名  ::= "`" (换行 | "`" 以外的任意字符)* "`"     // 不跨行、不嵌反引号
符号名    ::= 符号字符+                                   // 非 ASCII、非字母数字、非空白、非逻辑单 token
参数引用  ::= "$" 数字+                                   // 仅 $ 紧贴数字时粘连为单 token
```

要点：

- **保留字**（Lexer.kt:39-45）：`fun class struct enum var impl for if else unchecked when is by type return def`。反引号名**不进关键字表**——`` `when` `` 是普通 IDENT（Lexer.kt:191-192）。`in` 已于 P51 去关键字化，词法层只是 IDENT，区间成员判断由 ops 表识别（Lexer.kt:44）。
- **逻辑符号不是名字**：`∀ ∃ ∧ ∨ ¬ → ↔ ⊤ ⊥` 是固定单 token（logicalSingletons，Lexer.kt:48-52），`∵ ∴` 同理被排除在符号名之外（Lexer.kt:100-103）。其余非 ASCII 符号字符（数学符号等）由 `isSymbolStart` 收为 SYMBOL。
- **空白与换行**：空格/制表/`\r`/`\n`、`//` 注释、BOM 一律跳过——**换行不是 token**；每个 token 记录 `precededBySpace`，为后续邻接消歧（紧贴名字的 `<` 是实例化、带空格的 `<` 是比较）提供依据（Lexer.kt:19-22、68-84）。
- **全角标点**：误输入全角符号（`（）＝，` 等）时词法直接报错并提示换成半角（Lexer.kt:140-141）。

### 绑定名字的文法位置

## 语义

### 词法作用域

- 名称解析按**静态嵌套**进行：函数检查期有独立的局部帧（Frame/FunType，_langfacts §5），内层构造（lambda 参数、量词绑定、`var`）遮蔽外层同名。遮蔽的边界细节（如是否允许形参与外层全局同名、有无专属警告码）未见专门诊断，`待核`。
- **作用域弥散**：下文命题（如 `<$ = 7>`）在体内兑现后弥散进作用域供后续消费；`axiom` 语句把命题注入对应作用域——顶层注入全域事实 Γ，函数内注入局部帧（_langfacts §4/§5）。量词 `∀` 的实例化从命题池全局供给（_langfacts §4）。
- **闭包捕获是快照**：lambda 在**创建时**对捕获变量沿父链逐值深拷（`ClosureFun.copyCapture` + `copiedFrame`，Evaluator.kt:833-863）——词法上捕获外层名字，值上是创建瞬间的快照；JS 侧 `__dc` 对函数穿透为既定边界（_langfacts §6）。捕获与可变性的冲突见 [函数类型](02-类型-函数类型.md) 捕获语义。

### `_` 隐式形参

判定：大括号深度 1 内**没有 `=>`（显式参数表）也没有 `:`（类型测/类型标注）** → 隐式单参体，编译为 `LambdaExpr(["_"], 体)`（Parser.kt:1699-1702、1747-1764），体里的 `_` 引用该形参（Kotlin `{ it + 1 }` 同款）。括号 lambda 的分界：

| 写法 | 参数 | 判定依据 |
|---|---|---|
| `{ => 7 }` | 零参 | braceIsLambda：深度 1 遇 `=>` 且其前只有名字/逗号（Parser.kt:1721-1745） |
| `{ n + 1 }` | 隐式单参 `_`（此例未用 `_`，参数被忽略） | braceHasImplicitBody（Parser.kt:1749-1764） |
| `{ n => n + 1 }` | 显式 n | braceIsLambda |
| `{ (a, b) => a + b }` | 解构 (a,b) | 括号配对计数 pd（Parser.kt:1723、1734-1736） |
| `{ 1 => x }` | **不是 lambda** | `=>` 前出现数字等非名字 token → sawBad（Parser.kt:1719、1739） |

注意 `{ n + 1 }`：若体中不出现 `_`，隐式形参就是「声明了但没用」，`n` 只是对外层名字的闭包。显式参数表里把参数命名为 `_` 是否合法、与隐式形参语义是否冲突：`待核`。

### `$n` 与 `$`

- `$` 后**紧跟**数字才粘连为一个 DOLLAR token（Lexer.kt:146-150）——`$ 1`（中间有空格）不是参数引用。
- `$n` 解析为 `ParamRefExpr(n)`，指当前函数的第 n 个形参，**从 1 起**，只在**前后件/上下文位**有意义（Parser.kt:1321-1326；_langfacts §5）。典型形态是上下文函数类型 `(T)<$1 ∈ xs> => Null`（见 [函数类型](02-类型-函数类型.md) 上下文函数类型节）。
- 单独 `$` 是返回值符号 `ReturnSym`（Parser.kt:1325），用于后件引用本函数的返回值（`$ == 7` 类原子，_langfacts §4）。
- 标识符**内部**的 `$` 段会粘连成普通 IDENT（如安卓注解处理器生成的合成名 `recomposion$Box$1`，Lexer.kt:214-225），与独立的 `$n` 参数引用是两条路径——手写名字时别把两者混了。
- 字符串插值 `$name` 与 `${expr}` 走串内通道（_langfacts §1），与词法 DOLLAR 无关；串转义支持 `\n \t \r \" \\`，其余字符按原样保留（Lexer.kt:180-184）。

### 名字类别与消歧

- 反引号名一律产 IDENT（不进关键字表），是把保留字/逻辑符号「当普通名用」的合法手段：`` `when` ``、`` `∀` ``（反引号内可是任意字符，含逻辑符号）。
- SYMBOL 名（如 `∈`、`≠`）可作命题名与函数名：def 命题名允许 IDENT/SYMBOL 及若干运算符 token（defNameKinds，Parser.kt:63-69）；运算符名另有前缀调用通道（opPrefixKinds/symbolCallStart，Parser.kt:56-61）。
- 中缀糖 `a f b` 要求 `f` 前后**均带空格**（_langfacts §2 D-5）——空白敏感虽属邻接规则而非名字规则，但命名与书写时须顾忌，否则 `a f b` 会被解析成别的形态。

## 示例

```subl
// 1) 四种词法形态同台：Unicode 名、_ 起首、反引号名
fun `加一`(n: Nat): Nat = n + 1            // 反引号名（任意字符，含中文）
@impure fun main() {
    var 整数 = 3                            // Unicode 名：中文也是字母
    var _缓存 = `加一`(整数)                 // _ 起首的普通名
    var `一个 名字` = 4                      // 反引号名：含空格
    print(_缓存 + `一个 名字`)               // 8
}
```

```subl
// 2) 反引号名绕开关键字表
fun `when`(): Nat = 7                      // `when` 是普通标识符，不与保留字冲突
@impure fun main() { print(`when`()) }     // 7
```

```subl
// 3) 隐式单参 / 显式参数 / 零参
fun twice(f: (Nat) => Nat, x: Nat): Nat = f(f(x))
fun once(f: () => Nat): Nat = f()
@impure fun main() {
    print(twice({ _ * 2 }, 5))             // 20：_ 引用隐式形参
    print(twice({ n => n * 3 }, 5))        // 45：显式参数名 n
    print(once({ => 7 }))                  // 7：零参 lambda
}
```

```subl
// 4) $n 参数引用（上下文位）+ axiom 注入作用域（上下文函数类型节选）
enum List[T] { Nil(), Cons(T, List[T]) }
fun forEach[T](xs: List[T], f: (T)<$1 ∈ xs> => Null): Null {
    when(xs) { Nil => null
               is Cons(h, t) => { f(h); forEach(t, f) } }
    return null
}
fun needNotZero(n: Nat)<n ≠ 0> { }
@impure fun main() {
    var xs = Cons(1, Cons(2, Nil()))
    axiom ∀ e. e ∈ xs → (e ≠ 0)            // 注入作用域，供给 $1 ∈ xs
    xs.forEach { _.needNotZero() }          // 尾随 lambda：_ 引用元素
}
```

```subl
// 5) 词法捕获是快照（解释器语义）
fun snap(): Nat {
    var x = 1
    var f = { _ + x }                       // 捕获 x：lambda 创建时深拷
    return f(10)                            // 11
}
@impure fun main() { print(snap()) }        // 11
```

## 陷阱

- **`->` 全位非法**：lambda 参数表里写 `{ a, b -> … }` 不解析；程序位一律 `=>`，命题蕴含用 Unicode `→`（详见 [箭头家族](01-基础-箭头家族.md)）
- **`{ 7 }` 不是零参 lambda**：它是隐式单参（形参 `_` 被忽略）；零参必须写 `{ => 7 }`。反过来，把 `{ _ }` 传给 `() => Nat` 形参是元数错——隐式单参与零参只差一个 `=>`
- **`$1` 粘连且限位**：`$` 与数字之间不能有空格；`$n` 只在前后件/上下文位有效，写到普通表达式位没有参数引用语义（_langfacts §5）
- **反引号名的两条硬限**：不能跨行、不能内嵌反引号，违者词法直接报「反引号标识符未闭合/不能跨行」（Lexer.kt:198-202）
- **逻辑符号不能当名字**：`∀`/`→`/`∧` 等是固定 token，`∵`/`∴` 也不能作符号名首字符；想要这类名字只能加反引号（`` `∀` ``）
- **SYMBOL 会合并**：连续符号字符被读成**一个** SYMBOL——`≤≥` 是一个名字而非两个，想分开用空格或反引号隔开
- **换行不是 token**：不能靠换行断语句或续行；中缀糖 `a f b` 的 `f` 前后空格是硬要求，跨行写糖会失效
- **闭包不是回传通道**：捕获在创建时深拷快照（Evaluator.kt:833-863），想传出结果走返回值；给捕获的 `@mut` 变量赋值还会把 lambda 推导为不纯（[函数类型](02-类型-函数类型.md) 捕获语义）
- **`in` 不是保留字**（P51 去关键字化），不必再因避讳它而改命名；但把 `in` 用作变量名会与成员判断混淆，不建议（有无冲突诊断 `待核`）
- **合成名的 `$` 是内部粘连**：`recomposion$Box$1` 一类合成名是注解处理器产物（Lexer.kt:214-225）；手写的 `a$1` 被当普通 IDENT，与参数引用 `$1` 是两回事
- **串内插值不是词法 `$`**：`$name` 与 `${expr}` 只在字符串内有效，两条通道互不通用
- **lambda 参数表只许名字/逗号**：`{ 1 => x }` 不是 lambda（防与 when 分支混淆，Parser.kt:1719、1739）；参数表要塞怪名字（关键字、符号串）用反引号名
