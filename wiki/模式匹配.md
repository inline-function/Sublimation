# 模式匹配

凝华的 `when` 是真模式匹配——支持构造子解构、嵌套、守卫、区间模板，且编译器能**自动证明穷尽性**。

## 基本用法

```subl
when (x) {
    0       -> print("零")           // 字面量
    n if n > 10 -> print("大数")     // 带守卫的变量绑定
    else    -> print("其他")          // 兜底分支
}
```

> `when` 必须穷尽所有可能值，否则编译报 `W-NON-EXHAUSTIVE`。

## 构造子解构

```subl
enum Color { Red; Green; Blue }
when (color) {
    Red   -> print("红")
    Green -> print("绿")
    Blue  -> print("蓝")        // 枚举必然穷尽，不需要 else
}
```

对 `Optional[T]` 解构：

```subl
when (maybe) {
    Some(v) -> print(v)            // 绑定 v，作用域在分支内
    None    -> print("缺值")
}
```

嵌套构造子：

```subl
when (result) {
    Ok(Some(v)) -> print(v)        // 两层构造子同时解构
    Ok(None)    -> print("空")
    Err(e)      -> print("错: " + e)
}
```

## 区间穷尽（when(n in _)）

这是凝华的杀手特性：把区间分支交给编译器证明覆盖。

```subl
fun grade(score: Nat)<score ∈ (0..100)>: Str {
    when(score in _) {                        // _ = 从上下文推断区间
        (0 .. 59)  -> return "不及格"
        (60 .. 69) -> return "及格"
        (70 .. 79) -> return "中等"
        (80 .. 89) -> return "良好"
        (90 .. 100)-> return "优秀"
    }
}
```

编译器会自动收集每个分支的端点（0, 59, 60, 69, …），排序后检查相邻衔接。这四个分支覆盖了 (0..100)，**无需 else 也不需要自己写边界检查**。

```subl
// 有前置条件告知区间：
+∵ score ∈ (0..30)
when(score in _) {
    (0 .. 10)  -> print("低")
    (11 .. 20) -> print("中")
    (21 .. 30) -> print("高")
}
```

> `when(n in _)` 的 `_` 充当通配符：编译器从 Γ 中的 `n ∈ (l..r)` 事实推断区间端点。

## ifis 智能解构（if 条件里的模式匹配）

只关心**一种**形状、只取**一层**值时，不必写完整 `when`——像 Rust 的 `if let` 一样，把模式条件直接写进 `if`：

```subl
fun describe(o: Optional[Nat]): Nat =
    if (o is Some(e)) e else 0      // 匹配 Some 则进入分支，e 绑定内部值

fun first(o: Optional[Nat]): Nat {
    if (o is Some(e)) { return e }  // 提前 return 照常退出函数
    return 0
}
```

- 主题可以是任意表达式，模式与 `when` 分支**完全同构**：构造子解构（枚举 `Some(e)` / 结构体 `Point(x, y)` / 路径 `E::A(x)`）、嵌套 `Some(is Some(v))`、通配 `_`、`as` 绑定，都能用。
- 语义是脱糖成 `when`：`if (o is Some(e)) A else B` ≡ `when (o) { is Some(e) -> A; else -> B }`，因此穷尽性提示、分支命题与智能转换规则全部复用。
- 不带 `else` 时与普通 `if` 无 else 同义（值退化）；枚举主题会按既有规则给 `W-NON-EXHAUSTIVE` 提示——补 `else` 或按需忽略。
- 条件必须是**单独的模式判断**：`if (o is Some(e) && e > 0)` 不被接受（绑定的 e 也没有作用域），组合条件请改用 `when` 分支守卫。
- 普通布尔条件 `if (c)`、纯类型测 `if (o is Rat)`（分支内智能转换）不受影响。

## 无主题 when（条件分支）

没有 subject 的 `when` 按条件链执行，不需要 else：

```subl
when {
    n < 0  -> print("负")
    n == 0 -> print("零")
    n > 0  -> print("正")
}
```

## 守卫（if 条件）

```subl
when (n) {
    x if x > 100 && x <= 200 -> print("大")       // 多条件守卫
    x if x > 0               -> print("正")
    else                     -> print("非正")
}
```

## 穷尽性

凝华**强制执行穷尽性**：每个 `when` 的 arm 合集必须覆盖所有可能的值。缺失分支报 `W-NON-EXHAUSTIVE`。

枚举、构造子族、区间 `when(n in _)`——编译器有专门的穷尽性策略，大多数场景不需要手动写 `else`。

```subl
// ❌ 编译错误：覆盖不完整
when (color) {
    Red -> print("红")
}
// → W-NON-EXHAUSTIVE: 缺少 Green, Blue

// ✅ 穷尽
when (color) {
    Red   -> print("红")
    Green -> print("绿")
    Blue  -> print("蓝")
}
```
