# 副作用与可变性控制

## 默认纯函数

函数默认无副作用。副作用必须显式标注，从类型上可见。

| 标注 | 含义 |
| --- | --- |
| `@impure` | 允许副作用（IO、打印、可变全局等） |
| `@mut` | 就地修改参数对象 |

```subl
@impure fun main() { print("hello") }         // 程序入口需要 IO

@mut fun bump(counter: Cell[Nat]) { ... }     // 就地改 counter
fun sum(xs: List[Nat]): Nat = ...             // 纯：不修改参数
```

## 标注影响证明

- 标注 `@impure` / 参数 `@mut` 的函数**不会被登记为定理**（定理判据 = 无 @impure + 无 @mut 参数 + 返回 Null）。
- 伴生命题、`∴`、`if[p]` 里的表达式必须是**纯的**：证明系统拒绝有副作用的表达式。

## 可变集合方法（形态）

```subl
class Collection {
    @mut  fun add(e: T)
    @mut  fun removeAll(e: T)
    @impure fun forEach(f: @impure (T) => Null)
    fun filter(f: (T) => Bool)   // 纯：返回新容器
}
```

- `add` / `removeAll` 就地修改；
- `forEach` 接受纯函数但自身 `@impure`；
- `filter` 不改原对象。

## 局部可变

块内 `var` 可重新赋值；跨模块/纯函数边界的可变状态受标注纪律约束。
