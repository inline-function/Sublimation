# 手动证明

自动证明失败时，用 ∴（求证）、《前提注入》、定理库手动构造证明。证明是编译期的事；定理函数的代码仍生成，但证明过程本身不发射 JS。

## 工具

| 语法 | 作用 |
| --- | --- |
| ∵ | 从当前已证事实推导 |
| +∵ p | 先验证 p 在上下文中成立再注入；否则 E-CANNOT-PROVE |
| ∴ q | 求证 q；失败报 E-CANNOT-PROVE（列出尝试过的定理） |
| if[p] | 命题守卫：只有 p 可真才进入 |
| <前件> | 声明前提，注入函数体 |
| <$后件> | 声明结论，$ 指代返回值，调用点可享 |

## 例：证明区间下界

```subl
+∵ n ∈ (0..30)
∴ n ≥ 0
```
推理路径：n ∈ (0..30) 展开为 n ≥ 0 ∧ n ≤ 30（区间界），左项目由 core.logic.rangeLowerBound 或直接合取左消。也可显式引用定理：

```subl
// core/logic.subl
fun rangeLowerBound[x, l, r]: Null <x ∈ (l..r) -> x >= l>
// 使用（证明搜索自动合一 x:=n, l:=0, r:=30）
+∵ n ∈ (0..30)
∴ n >= 0
```

## 蕴含链与传递

```subl
fun leqTrans[x, y, z]: Null <x <= y -> y <= z -> x <= z>
+∵ a <= b
+∵ b <= c
∴ a <= c        // 自动应用 leqTrans
```

## 经典逻辑（core.logic.classic，@classic）

```subl
@classic
fun tertiumNonDatur[p]: Null <p ∨ ¬p>
```
经典定理在 @classic 标记的文件/模块内可用（默认内核不假设排中律）。

## 失败时排查

1. 事实是否真的在 Γ（+∵ 位置影响后续作用域）？
2. 定理是否满足判据（无 @impure、无 @mut 参数、返回 Null）？不满足就不是定理。
3. 跨模块：可见路径（mount 链）的定理空间自动参与，无需额外导入。
4. 表达式是否纯（上下文表达式必须纯）。
