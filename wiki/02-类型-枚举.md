# 枚举（enum）

> wiki/02-类型-枚举 · 主题域：枚举 / 构造子 / 递归 / when 配合
> 事实来源：_langfacts.md §2/§3/§4；Parser.kt（parseEnum :911、parseCtorFields :931、parseWhen :1492、parsePattern :1557、parseEntry :195）；WhenCheck.kt（checkWhen :112、bindingCovered :193）；Checker.kt（:183 预注册 Bool/Null/Optional、:921 构造子名解析）；examples/结构体与枚举.subl、模式匹配.subl、空安全.subl、错误处理.subl、日常-数列与区间.subl、高阶函数与lambda.subl；core/collection/optional.subl；compiler/src/test/.../CheckerTest.kt（:382 起 Optional/穷尽用例）

枚举是语言的 ADT（代数数据类型）载体：一个**名义和类型**加一组**构造子**，每个构造子带一串位置字段。枚举本身只声明形状，所有「取值」动作都靠 when 解构完成——所以枚举与 when 是配套设施，分开理解没有意义。

## 语法

### 声明

```subl
enum Shape { Circle(Nat), Rect(Nat, Nat) }          // 构造子带位置字段
enum Color { Red, Green, Blue }                     // 无字段构造子（括号可省）
enum List[T] { Nil(), Cons(T, List[T]) }            // 泛型 + 自引用（递归）
enum Result[T, E] { Ok(T), Err(E) }
enum E                                              // 无构造子可省花括号（≡ enum E {}）
```

文法要点（Parser.kt :911-929）：

- `enum 名 类型参数? { 构造子, … }`；类型参数走方括号 `[T]`（parseTheory）
- 构造子形如 `名(类型, 类型, …)`；**字段只有位置类型，没有字段名、没有默认值**（parseCtorFields :931 只解析类型列表；命名字段构造 `User(name = "x")` 是 struct 的形态）
- 分隔符逗号可省；**尾随逗号合法**（遇 `)`/`]`/`}` 自动收尾）
- 顶层声明：enum 只能写在顶层（parseEntry :195），不可加注解（注解分支只接收 fun/struct/class，:199-205）；函数体内不能声明枚举

### 构造子作值

```subl
var s : Shape = Circle(3)            // 位置实参构造调用
var n : Optional[Nat] = None         // 零参构造子可作裸名值引用
var m : Optional[Nat] = None()       // 加空括号等价
var xs : List[Nat] = Cons(1, Nil())  // 嵌套构造
var r : Result[Nat, Str] = Ok(42)
var path = Optional::Some(5)          // v2.1 路径形态 E::A / E::A(实参)
```

零参构造子作裸名引用时带多态类型（`None : Optional[T]` 对任意 T，Checker.kt :921-925）；`E::A` 折叠为复合名 `E::A`，后随 `(` 仍是普通构造调用（Parser.kt :1174-1182）。

### when 配合（模式）

```subl
fun area(s: Shape): Nat = when(s) {
    is Circle(r) => 3 * r * r          // 构造子解构（必须显式 is）
    is Rect(w, h) => w * h
}

fun name(c: Color): Str = when(c) {
    Red => "红"                         // 无字段构造子：裸名模式
    Green => "绿"
    Blue => "蓝"
}

fun f(b: Bool): Nat = when(b) { true => 1  false => 0 }   // true/false 也是构造子
```

模式文法（parsePattern :1557-1653）：

| 模式 | 形态 | 说明 |
|---|---|---|
| 构造子解构 | `is Ctor(x, _)`、`is E::A(x)` | **解构必须显式 is**；支持嵌套 `is Some(is Some(y))` |
| 无参构造子 | `Red`、`None` | 裸名与绑定变量同形，由语义层按符号表判定（:1650） |
| 无 is 括号 | `A()` | 仅允许空参值比较；带实参则解析报错（:1644-1648） |
| 通配 | `_`、`else` | 兜底 |
| 字面量 | `0`、`"s"` | Int/Str 字面量模式 |
| 元组 | `(a, b)` | 至少一个逗号；`(p)` 退化为子模式 |
| 类型分支 | `is T as x` | PatIs 可选 `as` 绑定 |
| 守卫 | `模式 if 表达式 =>` | 运行期值位条件（用 `!=`、`&` 等值位算符，不用命题算符） |

when 主题除了 `when(x)` 还有三种变体（parseWhen :1492-1554）：绑定主题 `when(var x = expr)`、无主题 `when { cond => body }`（布尔条件分支）、模板 when `when(t in _)`（每支脱糖为 `t in p`）。分支分隔符是 `=>`（修正案后 `->` 全位非法，程序位一律 `=>`）；分支体可以是单表达式或 `{ 语句 }` 块。

## 语义

**枚举 = 和类型，when = 唯一的消去器。** 构造子把值注入类型，when 按构造子把值拆开，两边的连接由命题系统而不是运行时标签保证：

- 每个分支产生**分支命题**：字面/构造子模式 → `subj = pat`；`is T` → `subj : T`；`else`/`_` → ⊤（WhenCheck.kt :102-104）
- **顺序敏感**：后分支的帧里注入了前面所有分支命题的否定（:129），所以 `true => … false => …` 之外不需要写守卫就能区分
- **穷尽 = Γ ⊢ p₁ ∨ … ∨ pₙ**（决策 43，析取恒真），由通用证明器判定（含算术通道）

### 穷尽性是提示，不是要求（决策 66）

这是最容易被误用的一点（WhenCheck.kt :155-180）：

1. 主题**有覆盖律**（名义枚举）却覆盖不全 → 发 `W-NON-EXHAUSTIVE` 警告，when 作为表达式时**值类型退化为 Null**
2. 主题无覆盖律（元组、函数类型等）→ 判不出不是用户写错，**静默退化**，不警告
3. 退化后的非 Null 值流向需要非 Null 的上下文（如函数返回类型）→ `E-NON-SEALED-MATCH` 兜底报错；返回 Null 则只警告不报错（CheckerTest.kt :407-419）

### 绑定式吸收（假阳性修复）

构造子模式实参**全为裸绑定/通配且无守卫**时，在值空间恒覆盖该构造子的全部值——与字段类型无关：`is B(t)` 吸收 `B` 的所有值，`is Some(xs)` 配 `None` 即穷尽（bindingCovered :193）。反过来：

- 嵌套模式 `is B(is Leaf(x))` 不吸收 `B`（实参不全为绑定），缺 `Node` 分支仍判非穷尽（CheckerTest.kt :493-498）
- 带字面量的 `is Some(0)` 保守判非穷尽——不覆盖所有 Some（:396-399）
- **守卫破坏吸收**：`is B(t) if …` 的分支不参与吸收判定（:197）

### 其他

- `Bool`、`Null`、`Optional` 是 checker 预注册的内建枚举（Checker.kt :183-186），`true`/`false`/`null`/`Some`/`None` 都是构造子；标准库 `Result[T, E]`、`List[T]` 同样是枚举（core/collection/optional.subl、examples/错误处理.subl）
- 分支返回类型 = 各分支类型 join（决策 37）；`else` 对联合主题做反收窄（v2.0，:139-143）
- 枚举可递归：`Cons(T, List[T])` 在声明体内引用自身类型（日常-数列与区间.subl）
- 智能解构：`if (o is Some(v))` 作为 if 整条件时脱糖为 when（IsPatExpr，Checker.kt :952 的诊断说明）；命题 when（`when[p ∨ q]`）是另一支文法，与枚举解构无关（_langfacts.md §2）

## 示例

**ADT 与穷尽**（综合 examples/结构体与枚举.subl 与 模式匹配.subl）：

```subl
enum Shape { Circle(Nat), Rect(Nat, Nat) }
enum Color { Red, Green, Blue }

fun area(s: Shape): Nat = when(s) {
    is Circle(r) => 3 * r * r
    is Rect(w, h) => w * h
}

// 覆盖律穷尽：Red∨Green∨Blue 可证，无需 else
fun name(c: Color): Str = when(c) {
    Red => "红"
    Green => "绿"
    Blue => "蓝"
}

// 非穷尽只发 W-NON-EXHAUSTIVE：值退化为 Null，不报错
fun partial(c: Color) {
    when(c) { Red => 1  Green => 2 }
}

@impure
fun main() {
    unchecked print(area(Circle(3)))   // 27
    unchecked print(area(Rect(2, 4)))  // 8
    unchecked print(name(Blue))        // 蓝
    partial(Red)
}
```

**递归枚举**（examples/日常-数列与区间.subl，缩写）：

```subl
enum List[T] { Nil(), Cons(T, List[T]) }

fun size[T](xs: List[T]): Nat = when(xs) {
    Nil => 0
    is Cons(_, t) => 1 + size(t)
}

fun map[T, U](xs: List[T], f: (T) => U): List[U] = when(xs) {
    Nil => Nil()
    is Cons(h, t) => Cons(f(h), map(t, f))
}

fun fold[T, U](xs: List[T], init: U, f: (T, U) => U): U = when(xs) {
    Nil => init
    is Cons(h, t) => fold(t, f(h, init), f)
}
```

**嵌套解构与守卫**（examples/模式匹配.subl + 空安全.subl）：

```subl
// Optional[Optional[Nat]] 覆盖律深展开：三层分支才穷尽
fun flatten(oo: Optional[Optional[Nat]]): Nat = when(oo) {
    is Some(is Some(y)) => y
    is Some(None) => 0
    None => 0
}

// 守卫是运行期值位：用 != 前缀调用与 &，不用命题算符
fun range(n: Nat): Str = when(n) {
    0 => "zero"
    m if !=(m, 0) & !=(m, 1) => "many"
    else => "small"
}

fun elvis[T](o: Optional[T], d: T): T = when(o) {
    is Some(v) => v
    None => d
}
```

**Result 风格**（examples/错误处理.subl）：

```subl
enum Result[T, E] { Ok(T), Err(E) }

fun unwrapOr[T, E](r: Result[T, E], d: T): T = when(r) {
    is Ok(v) => v
    is Err(_) => d
}

fun mapResult[T, E, U](r: Result[T, E], f: (T) => U): Result[U, E] = when(r) {
    is Ok(v) => Ok(f(v))
    is Err(e) => Err(e)
}
```

## 陷阱

1. **非穷尽不报错，只警告**——when 表达式值类型悄悄退化为 Null；写 `fun f(c: Color): Nat = when(c) { Red => 1 }` 会拿到 `E-NON-SEALED-MATCH`（流向非 Null），而返回 `Null` 的只有警告。以为「编译器会拦住漏分支」是错的，穷尽要自己补全或加 `else`
2. **解构必须显式 is**：`is Cons(h, t)` 正确；`Cons(h, t)` 作为模式直接解析报错（「以 is 开头的构造子解构」，Parser.kt :1646）。只有空参形态 `A()` 可以无 is
3. **裸名模式二义性**：无字段构造子（`Red`、`None`）与绑定变量同形，按符号表判定（:1650）。若构造子与变量同名，或把带字段的构造子裸写（`Cons`），语义会与直觉不符——带字段的一律写 `is Ctor(...)`
4. **守卫破坏穷尽吸收**：`is B(t) if cond =>` 不参与绑定式吸收，也不再保证覆盖 `B` 的全部值；带守卫的 when 要重新数穷尽性
5. **嵌套/字面量模式偏保守**：`is Some(0)` 不覆盖所有 Some，`is B(is Leaf(x))` 不吸收 Node——深模式要补齐内层所有分支，或退一层用绑定式
6. **无覆盖律主题静默退化**：元组、函数类型等主题判不出穷尽**不警告**（不是用户写错）；别把「没有 W-NON-EXHAUSTIVE」当作「已经穷尽」的证据
7. **分支分隔符是 `=>` 不是 `->`**：修正案后 `->` 全位非法（lexer 出 ARROW 仅供诊断）；写 `Red -> "红"` 直接解析失败
8. **构造子字段只有位置参数**：`User(name = "x")` 式命名字段构造是 struct 专属（StructCtorExpr）；枚举只能 `Circle(3)`。同理枚举无字段默认值
9. **枚举只能在顶层、不能加注解**：函数内想「局部定义一个枚举」不行（顶层声明限定，parseEntry :195）；`@mut`/`@impure` 之类注解也挂不上
10. **`E::A(...)` 路径形态的括号限制**：裸 `E::A(` 后必须立刻是 `)`——`E::A(x)` 作模式时解析器要求先 is（:1636）；表达式位则不受此限
11. **枚举值是普通不可变值**：按语言默认 `T` 形态处理，走拷贝规则（见 [拷贝规则](02-类型-拷贝规则.md)）；构造子字段类型能否写 `@mut`/`@ref`：待核
12. **`true`/`false`/`null` 是构造子**：`when(b) { true => … false => … }` 靠顺序否定（后分支持有 `b ≠ true`），不需要守卫；Bool 已是内建枚举，不要再自己声明
