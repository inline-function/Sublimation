# Sublimation 术语表

> **用途**：把散落在各 wiki 页与设计文档里的**专门术语**收拢成一页，供按图索骥。每条给**定义**，
> 不重复定义通用编程/PL/数学术语（函数、类型、多态、合一、命题等）——只收本项目**自己的概念**
> 或对通用词的**特定用法**。
>
> 维护：本表随语言演进**追加**，不删条目；废弃概念标 `[废弃]` 保留在最后一节。

## 一、语言哲学层

| 术语 | 定义 |
|---|---|
| **凝华** | 语言名字的来源：命题不经运行时，直接在编译期“凝结”为静态保证。与物理现象“气→固”同构。 |
| **上下文系统** | 本语言的灵魂：命题作为独立存在弥散在作用域 Γ 里，函数的**上文/下文**描述“调用前空气里必须有什么、调用后空气里会多出什么”。不是参数、不是值。 |
| **命题 / 值 二分** | 值世界（可求值、可 print、可传参）；命题世界（住 Γ，编译期证明，**不进 JS**）。两个世界**不通**：`x != 0` 是值，`x ≠ 0` 是命题。 |
| **弥散** | 命题像气体一样在作用域里流动。事实来源有三：显式注入（`axiom`/`var`）、函数下文、`if`/`when` 分支条件。**`if`/`when` 是值世界 → 命题世界的唯一桥**。 |
| **零成本擦除** | 命题、类型、理论参数全部**不落入 JS**。例外：类型类字典。`unchecked.axiom[q]` 只留 `// axiom: q` 注释供审计。 |
| **unchecked** | 唯一的逃逸口。三种形态：`unchecked.axiom[q]`（逃证明义务）、`unchecked f(x)`（逃纯度）、`unchecked v = 1`（逃可变性）。 |
| **风味纲领** | 语法像 Kotlin；基础概念像 Rust；创新概念像定理证明器与函数式语言（Koka/Lean 圈）。 |
| **健全但不完备** | 证明器的承诺边界：所有规则保真（健全），但**不承诺证明一切**（不完备）。证不出 ≠ 假，用 `axiom` 补。 |

## 二、上下文系统

| 术语 | 定义 |
|---|---|
| **Γ（Gamma）** | 作用域内**命题事实的多重集**。条目：`e:τ`、`e₁=e₂`、谓词原子、命题绑定、伴生记录 `f<args>`。 |
| **上文（preps / 前置）** | `fun f(...) <p> : T` 中的 `<p>`。调用前必须在 Γ 里找到 `p` 的证明。缺 → `E-PRE-UNPROVEN`。 |
| **下文（posts / 后置）** | `fun f(...) : T <q>` 中的 `<q>`。函数体的**证明义务**：体末尾 Γ 必须蕴含 `q`。缺 → `E-POST-UNPROVEN`。 |
| **函数体是证明义务** | 声明不是可信公理：体结束时 Γ ⊇ 下文；逃生门只有 `unchecked.axiom`。 |
| **`$`（返回值指代）** | 下文/调用注入中指代返回值。体内 `$` ≡ 末表达式；调用点 `$` ≡ 调用表达式本身。 |
| **`$n`（参数引用）** | 具名函数的**上/下文**里指第 n 个形参；声明期统一改写为参数名并给提示。函数体内禁用（`E-PARAM-REF-IN-BODY`）。 |
| **伴生命题 `f<args>`** | 函数被调用 ⇔ 此命题被证明。配公理 `f<args> → ps₂` 可推出下文；也可用于证明“参数被调用过”。 |
| **供给（supply）** | 调用点向上文/命题参数提供证据。两种：**自动**（从 Γ 检索，0 元候选；歧义报 `E-PROP-AMBIGUOUS`）、**显式**（`f<q>()` 尖括号）。 |
| **`unchecked.axiom[q]`** | 命题逃逸：直接往 Γ 注入 `q`，不经证明器检验。留 `// axiom: q` 注释。 |
| **`by [q]`** | 辅助策略（语句式/后缀式）：把人给的中间命题注入 Γ。 |
| **`pure<f>` 命题** | 单参命题。持有它 → 编译器认为调用 `f` 是纯的，无需 `unchecked` 逃逸。未标 `@impure` 的函数自动注册 `pure<name>`。 |
| **上下文驱动行为** | 命题不只是传参用，还能改变编译行为：`e : Nat` 智能转换、`pure<f>` 放行非纯调用、`T: Show` 类型类约束。 |

## 三、类型系统

| 术语 | 定义 |
|---|---|
| **类型 sealed** | 类型是 sealed interface，三个实现：`NamedType`（名义/参数）、`FunType`（函数）、`TupleType`（元组）。 |
| **名义类型** | 首字母大写的具名类型（`Nat`/`Optional[Nat]`）。函数/元组不是名义类型，判定一律走 `isNominal()`。 |
| **类型别名** | `type MyNat = Nat`、`type NatOpt = Optional[Nat]`、`type Box[a] = Optional[a]`、`type Dict[k, v] = Map[k, v]`。泛型头逐位对应目标类型参数，使用点展开（`Box[Nat]` ≡ `Optional[Nat]`）。 |
| **类型类（class）** | Haskell 的 typeclass 换 Rust 的 impl 机制：声明 `class Show[T] { fun show(): Str }`，实现 `impl Show for Int { ... }`。 |
| **隐式 self** | impl 方法**不写接收者参数**；体内裸用字段名 `name` ≡ `self.name`。形参可遮蔽字段（发 `H-FIELD-SHADOW`）。 |
| **字典传递** | 类型类方法调用按**实参类型**在 impl 表找唯一实例，把字典作为隐藏首参传入。**取代了早期的单态化方案**。 |
| **`dictHits`** | 语义层的字典解析留痕：键是**调用点实例**（不是方法名），否则同名方法多类型实例时分发会错。 |
| **`Any` 严苛准入** | 顶类型。声明合法，但禁止直接调用涉 Any 的函数、禁止创建含 Any 成员的结构体——一律 `unchecked`；涉 Any 的推导失效须手动标注（`E-ANY-CALL`/`E-ANY-STRUCT`）。 |
| **`Nothing`** | 空类型。返回 Nothing 的函数后接代码发 `W-UNREACHABLE`。 |
| **`Null`** | 单值类型（Unit 职责），唯一值 `null`。与 `Optional` 的 `None` **严格区分**。 |
| **`syntheticT`** | 推导失败时的占位类型。宽松比较放行 synthetic（推导不出时不误报）。 |
| **数值提升** | `Nat ⊆ Int ⊆ Rat` 的 join，先于名字相等判定，否则 `Nat` vs `Int` 误报。 |
| **`@tuple` 形参** | 变长参数 = 同类型变长元组：`fun sum(@tuple xs: (Nat, Nat)): Nat = …`。调用时传元组字面量（`sum((1, 2))`）。 |
| **容器** | `List[T]` `Set[T]` `Map[K,V]` `Optional[T]` `Result[T,E]` 与元组，自举实现于 `core/collection/`。 |

## 四、模式匹配

| 术语 | 定义 |
|---|---|
| **when** | 真模式匹配（Kotlin 拼写）。**臂的分隔符是 `=>`**（旧 `->` 已废除）：`when (x) { is Some(v) => v  None => 0  else => 1 }`。支持解构、嵌套、`is T [as x]`、守卫 `if`、通配 `_`、`else`。 |
| **无主题 when** | 不写 subject 的条件链：`when { n < 0 => print("负") ; n == 0 => print("零") }`。 |
| **区间模板** | `when(n in _) { (0 .. 10) => r = 1  (11 .. 20) => r = 2 }`：从 Γ 的 `n ∈ (l..r)` 事实推断区间端点，分支端点衔接即穷尽。 |
| **分类讨论命题语句** | `when[p ∨ q] { p => { … } q => { … } }`：按命题成立与否分情况写**块**（臂=条件+块，没有 else 臂）。 |
| **分支命题** | 每个分支注入的命题。构造子/字面量 → `subj = pat`；`is T` → `subj : T`；`else`/`_` → ⊤。后分支继承前分支的**否定**。 |
| **穷尽性判定** | 判据 = 分支命题的**析取**在 Γ 里可证恒真（不是合取）。 |
| **覆盖律** | 枚举的穷尽析取，按 when 主题的**具体类型就地生成**（不用全局 `∀`——泛型枚举 `Optional` vs `Optional[Nat]` 会失配）。 |
| **`coverShapes`** | 覆盖律的递归深展开；内层形状给单等式 `v=term` 时代入外层，与分支命题的 ∃ 形态同构。 |
| **α-等价** | 命题比较时按绑定变量出现序重命名为 `#k` 再比结构——覆盖律与分支用的变量名必然不同，不能退回字符串比较。 |
| **析取子集规则** | `(A∨B) ⊢ (A∨B∨C)` 有效（子集方向），反向无效；方向反了会让缺分支的 when 误判穷尽。 |
| **构造子单射** | `C<a> = C<b> → a = b`，用于嵌套穷尽性。 |
| **穷尽性降级** | 穷尽性是**提示**不是要求：判不出 → 值类型退化为 `unsealedT`；有覆盖律但覆盖不全 → `W-NON-EXHAUSTIVE`；流向非 Null 报 `E-NON-SEALED-MATCH`。 |
| **ifis 智能解构** | `if (o is Some(e)) e else 0`——if 条件里直接写模式，等同 Rust 的 if let，脱糖成 when。 |

## 五、编译期证明

| 术语 | 定义 |
|---|---|
| **饱和闭包** | 从 Γ 迭代推出新事实至不动点：合取分解、双否消去、∀ 单名实例化、**MP 前向链接**、矛盾检测 `p ∧ ¬p → ⊥`。 |
| **合一（matchTerm）** | ∀ 实例化时做谓词头匹配 + 项的一阶合一（变量单向实例化，**不合一算术**）。 |
| **modus ponens** | `p ∈ Γ` 且 `p → q ∈ Γ` ⇒ 加入 `q`。用户点名的自动证明核心。 |
| **深度上限** | 饱和的深度/轮数上限（经验值）。超限报 `E-DEEP-SATURATION`；需右嵌套 `→` 链才能触发。 |
| **目标项作候选** | 饱和闭包的第二参数只贡献**实例化候选**、不加入事实——否则目标平凡可证，破坏健全性。 |
| **等式推理** | 对称、传递（等式图 BFS）、等量代换（浅层）、类型事实的等式传播；**在目标侧做**，不修改 Γ。 |
| **`E-DEEP-SATURATION`** | 饱和超深度上限——健全性保证（宁可不证也不猜）的代价。 |

## 六、实体层

| 术语 | 定义 |
|---|---|
| **struct（结构体）** | 圆括号声明：`struct Point(x: Nat, y: Nat = 0)`。字段可带**默认值**（函数形参不允许，报 `E-DEFAULT-PARAM`）。 |
| **命名字段构造** | `Point(x = 1)`——大写名 + `(IDENT =` 前瞻触发独立 AST 节点；`()` 空括号不算，留给 `None()` 零参构造子。 |
| **enum（枚举）** | `enum Color { Red(), Green() }`；带字段构造子即 ADT（`Circle(Nat)`）。零参构造子作值引用时生成调用（`None` → `None()`）。 |
| **impl 完整性** | impl 成员默认**必须实现** class 的全部方法；额外函数必须 `@new`（反向 override）。 |
| **`@mut`** | 变量/字段/结构体可变（JS `let`）。**不注入初值等式**：可变变量仅保有自反相等 `v = v`。 |
| **`@impure`** | 声明非纯函数。纯作用域调用需 `unchecked` 或供给 `pure<f>`（旧文档里的 `@unpure` 已统一改为 `@impure`）。 |
| **`@new`** | impl 成员声明“这不是实现类方法集的函数”。 |
| **main 入口** | 具名零参 `fun main()` 自动作为入口调用（codegen 尾部追加 `main();`）；整个工程全局唯一，多模块声明会报 `E-DUP-DECL`；带形参报 `E-MAIN-PARAMS`。 |
| **显式 return** | `return e` / 裸 `return` **仅函数体块顶层语句位**合法；lambda/嵌套块里报 `E-RETURN-OUTSIDE`——它们是 IIFE，return 逃不出去。 |

## 七、模块系统

| 术语 | 定义 |
|---|---|
| **目录即模块** | 一个目录 = 一个模块，同目录所有 `.subl` 共享一个符号表；编译入口目录是根模块（根模块没有 settings）。 |
| **可见性方向** | 父→子可见（限定名，**传递**）；子→父不可见；兄弟默认不可见，靠挂载建立。 |
| **挂载（mount）** | `<模块名>.settings` 里的 `mount <路径> [as <别名>]`——在当前模块命名空间里加一条指针，**不复制代码**。 |
| **完整包名挂载** | `mount core.math` 与 `mount core/math` 等价；多段目标的**前缀包一并隐式挂载**，短名 `math.gcd(...)` 即可达。 |
| **core 统一标准库** | 标准库是 core **包**（只含子包目录、无直接源文件），位于编译入口下 `core/`（备选布局 `test/core/` 嫁接）；对每个非 core 模块**隐式挂载**（等价自动写 `mount core` + 各子包）。 |
| **默认导入** | 裸名可见集 = 本模块 + core 整包 + 自身及祖先挂载的传递闭包。子模块的函数在父模块里裸调不到，得限定或挂载。 |
| **引用路径** | 相对当前模块视角：`project/data/x.subl` 引用标准库同样写 `core.math.gcd`（core 经挂载传递可见）。 |
| **mangle / 模块前缀** | JS 名字改写：模块 absPath 的 `/` → `_` 再合法化（`core/math` 的 gcd → `core_math__gcd`），根模块不加前缀。 |
| **`E-CIRCULAR-MOUNT`** | 挂载链成环（settings 里的 mount 链形成循环）。 |
| **`E-PARSE-SETTINGS`** | settings 文件出现 `mount <路径> [as <别名>]` 以外的东西。 |

## 八、编译管线与脚本模式

| 术语 | 定义 |
|---|---|
| **四段管线** | 词法 → 语法 → 语义 → JS 生成，全部手写 Kotlin、零第三方依赖。 |
| **邻接规则** | 词法器记录 `precededBySpace`：**紧贴的 `<` = 实例化**（类型实参/供给/命题项），**带空格的 `<` = 比较中缀**。`a<b` 与 `a < b` 含义不同。 |
| **擦除映射** | 命题层、类型、理论参数全部擦除；值层映射到原生 JS。 |
| **prelude / 内建** | 编译期注入的基础类型和函数（`Nat`/`Int`/`Rat`/`Str`/`Bool`/`Null`/`Optional`/`print`/`toStr`…）；标 `@root` 的声明由 codegen 特判翻译为原生 JS，发 `H-ROOT-BUILTIN` 提示。 |
| **脚本模式** | `.subs` 文件：顶层语句直接执行（无需 `main`），经 Checker 类型检查后由解释器求值，不生成 JS；多个脚本互不共享声明。 |
| **注解处理器** | 用 Sublimation 脚本（`.subs`）写的编译期扩展：解释执行、加/删注解、报诊断，先于语义检查跑；默认目录 `annotation processer/`，`-p` 追加。 |

## 九、诊断

| 术语 | 定义 |
|---|---|
| **四级诊断** | 错误（无法编译）／警告（能编译但可能有问题）／提示（建议改）／补充（默认不输出，`-v` 显示）。 |
| **诊断码** | `E-*`（错误）、`W-*`（警告）、`H-*`（提示）、`D-*`（补充）。 |
| **explain** | `explain <CODE>` 子命令：打印诊断码含义与修复建议，不区分大小写；未收录的码会列出全部现有码。 |
| **源码片段上下文** | 带位置的诊断自动附源码行 + 行号 + 上箭头（`[行:列]`）。 |
| **诊断归属过滤** | 目录编译时补充级诊断只保留根模块的（挂进来的 core 等模块的推导过程被视为噪声）。 |

## 十、异步

| 术语 | 定义 |
|---|---|
| **`@async`** | 函数的异步标记；`readFile`/`sleep` 这类异步调用只能在 `@async` 函数里用（`main` 天然是 async）。 |
| **`Task`** | 协程任务：`t.start()` 启动，`await`/`join` 等待（未启动就 await 报 `E-NOT-STARTED`）。 |
| **`Channel`** | 协程间通道：`send`/`receive`，`close()` 后再操作报 `E-CHANNEL-CLOSED`。 |
| **`Flow`** | 冷流：`emit` 产出、`collect` 消费。 |
| **`Mutex`** | 异步互斥锁：`withMutex { … }` 保护临界区。 |
| **自动 await** | 检测到 `@async` 函数调用时自动等待完成（不用写 await），发 `D-AUTO-AWAIT` 提示。 |

## 附一：废弃与改名（别再翻到旧文档里）

- **`->` when 臂分隔符**：已废除，一律写 `=>`（lambda 的 `->` 仍被接受，但文档统一 `=>`）。
- **`stdlib`**：标准库改名 **`core`**（`stdlib/` 目录 → `core/` 包目录布局）。
- **`@unpure`**：统一为 **`@impure`**。
- **`switch`/`case`**：全废，改用 **`when`**。
- **单态化**：类型类按具体类型生成特化函数的方案，被**字典传递**取代。
- **`@vararg`**：被 **`@list`** 形参取代（Kotlin vararg 语义：形参声明元素类型 `T`，函数体内即 `List[T]`，调用端剩余位置实参自动打包）。
- **`uncheck.law`**：改为 **`unchecked.axiom[q]`**。
- **大括号 struct 体**：struct 改圆括号声明 `struct P(x: Nat)`。
