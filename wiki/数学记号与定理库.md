# 数学记号与定理库

## 记号（源码内直接用）

| 记号 | 含义 |
| --- | --- |
| ∈ | 属于（两参命题） |
| ≥ ≤ | 不小于 / 不大于 |
| ∀n. p | 全称量化 |
| ∃n. p | 存在量化 |
| ¬p / p ∨ q / p ∧ q / p → q | 否定 / 析取 / 合取 / 蕴含 |
| $ | 后件里指代返回值 |
| null | Null 值（定理返回） |

## 区间与 ..

```subl
@root fun ..(l: Int, r: Int): Range[Int]
    <∀n. n ∈ $ → n ≥ l, ∀n. n ∈ $ → n ≤ r>
```

## core.logic（直觉主义常用定理）

| 定理 | 命题 |
| --- | --- |
| rangeLowerBound | x ∈ (l..r) → x ≥ l |
| rangeUpperBound | x ∈ (l..r) → x ≤ r |
| leqRefl | x ≤ x |
| leqTrans | x ≤ y → y ≤ z → x ≤ z |
| andLeft / andRight / andIntro | 合取消入 / 消去 / 引入 |
| modusPonens | p → q, p ⊢ q |
| rangeSplitRight | 区间右拆 |
| natNonNeg | n ≥ 0（自然数自然命题） |

## core.logic.classic（经典逻辑，@classic）

| 定理 | 命题 |
| --- | --- |
| tertiumNonDatur | p ∨ ¬p（排中律） |
| doubleNegation | ¬¬p → p |
| contraposition | (p → q) → (¬q → ¬p) |

## 使用

Mount core/logic（std 已含则免）；+∵ 注入事实、∴ 求证——自动证明会把证明目标与这些定理合一。
