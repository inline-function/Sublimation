# 拷贝规则（可变视图的深拷贝判据）

> wiki/02-类型-拷贝规则.md · 语言基础→类型→效应 · 事实来源：实现（Checker.binderNeedsCopy / Evaluator.bindCopy 同一谓词，修正案提交 9beb63b）与 root doc《副作用与可变性控制》16 例矩阵

## 语法

拷贝发生在**绑定**时——变量声明、参数传递、元组解构、when 模式绑定：

```subl
var b : T = a              // 目标标注 T / @mut T / @ref T / @ref @mut T
@mut var b : @mut T = a    // @var 式注解：目标 = @mut T
fun f(x: @mut T): Null { … }   // 实参传递同样走拷贝判据
when(xs) { is Cons(h, t) => … } // h、t 的绑定同样走拷贝判据
```

目标与源的类型只由 **`@mut` / `@ref` 两个注解决定**，底层 `T` 不参与判据。

## 语义

拷贝 ⟺ 以下三条任一成立：

1. 目标含 `@mut`，**且**（目标不带 `@ref` **或** 源是纯类型）
2. 源含 `@mut`，**且** 目标是纯类型（既无 `@ref` 也无 `@mut`）
3. 源带 `@ref`，**且** 目标不带 `@ref`

（源纯 = 源既无 `@mut` 也无 `@ref`；目标纯 = 目标既无 `@mut` 也无 `@ref`）

完整矩阵（@m=@mut，@r=@ref；拷=深拷贝，享=共享同一对象）：

| 目标 ＼ 源 | T | @mut T | @ref T | @ref @mut T |
|---|---|---|---|---|
| **T** | 享 | 拷 | 拷 | 拷 |
| **@mut T** | 拷 | 拷 | 拷 | 拷 |
| **@ref T** | 享 | 享 | 享 | 享 |
| **@ref @mut T** | 拷 | 享 | 拷 | 享 |

读法：
- **@mut 目标永远拷贝**——唯一所有权不容共享（规则 1）
- **@ref（非 @mut）目标永远共享**——引用就是来看的，不复制（例外见下行）
- **@ref @mut 目标**：源是 `@mut T` 或同为 `@ref @mut T` 时**别名共享**（此时可安全共享可变性），源是纯值或 `@ref T` 时深拷
- **@ref 出现在源侧而目标不带 @ref**：一律深拷（不可变引用转所有权，必须落袋为安——规则 3）

### 函数闭包捕获

lambda / 匿名函数在**创建时**深拷贝其捕获的所有变量（沿父作用域链逐值拷贝；`@mut` 捕获因此不会被多个闭包共享别名）。闭包独立、捕获不可变。

### JS 边界

JS 代码生成的 `__dc`（深拷贝运行时）对**函数值直接穿透**——JS 闭包不透明，无法深拷其捕获；解释器侧（Evaluator）的闭包捕获深拷是完整实现的。领域不同，此差异为既定边界。

## 示例

```subl
@mut struct T(@mut n: Nat)

// @mut 目标 ← 纯源：深拷贝
var a : T = T(0)
var b : @mut T = a
b.n = 1
print(a.n)              // 0

// @ref @mut 目标 ← @mut 源：别名共享
var c : @mut T = T(0)
@ref var d : @mut T = c
c.n = 1
print(d.n)              // 1

// @ref 目标 ← @mut 源：共享只读视图
var e : @mut T = T(0)
var f : @ref T = e
e.n = 1
print(f.n)              // 1（共享）；f.n = 2 非法——@ref T 不可写）

// 纯目标 ← @ref 源：深拷贝
var g : @ref T = T(0)
var h : T = g
g = T(5)                // 注：@ref 重新绑定不影响 h
print(h.n)              // 0（拷贝独立）
```

## 陷阱

- **`@ref @mut` 的别名最反直觉**：`@ref var d : @mut T = c` 之后 `c` 与 `d` 是同一个对象——想分离必须显式构造 `@mut T` 副本
- **深拷不是引用换绑**：`var h : T = g` 之后重新给 `g` 赋值（`g = T(5)`）与 `h` 无关；深拷影响的是**对象内容快照**
- **参数同样拷贝**：`fun f(x: @mut T)` 每次调用都深拷实参——在循环里传大数据会放大代价，可用 `@ref` 形参避免
- **闭包捕获是创建时拷贝**，不是调用时：闭包多次调用看到的是同一份捕获快照
- **`@ref T` ← `@ref T` 是共享**，两过不可变引用看同一对象，不要期待独立
- JS 侧运行的程序里，捕获含函数的深拷**不复制函数体/其捕获**（`__dc` 穿透）；解释器侧则复制——跨执行后端时行为可能不同
