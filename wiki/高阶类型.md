# 高阶类型（HKT）

## 动机

容器抽象（Functor / Monad / Applicative）需要「类型构造子」作类型参数，而不只是具体类型。

## 语法

```subl
class Functor[F[_]] {
    fun map[A, B](fa: F[A], f: (A) => B): F[B]
}
```

- `F[_]`：kind-1 型参数（可被 `List`、`Optional`、`Set` 等实例化）。
- kind 检查在类声明期进行：`Functor[F[_]]` 要求 F 是 kind-1；传出 `F[A]` 应用位必须与 F 的 arity 匹配。

## 实例与字典

```subl
impl Functor for List[a] {
    fun map[A, B](fa: List[A], f: (A) => B): List[B] = when (fa) {
        Nil -> Nil()
        Cons(h, t) -> Cons(f(h), t.map(f))     // 方法糖优先自由函数
    }
}
```

- 字典名以 impl 的自类型为准，不含占位符；
- HKT 方法调用：接收者在 **kind 应用位**（如 `fa`）而非首参位，codegen 按此重排实参。

## 约束与泛型

类型参数约束（如 `T: Show`）通过字典槽在调用点查找，不查询全局 impl（T 未实例化时不误报 `E-NO-INSTANCE`）。

## 通用容器 API

`List` `Set` `Optional` `Result` 都提供 `map`（自由函数 + 方法糖）；联合使用：

```subl
var ys = xs.map({ v -> v * 2 })
var zs = opt.flatMap({ v -> Some(v + 1) })
```
