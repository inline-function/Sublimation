# 类型系统总览

> wiki/02-类型-类型系统总览 · 事实来源：TypeInfer.kt（137 行）、Checker.kt、_langfacts.md §3/§6

语言的类型系统由**两个正交的注解**叠加在底层类型 T 之上，描述「谁能改、谁共享」。

## 语法

```subl
var a : T
var b : @mut T
var c : @ref T
@ref var d : @mut T      // 目标 = @ref @mut T（变量注解 + 类型注解可叠加）
fun f(x: @mut T, y: @ref T): (T) => Null { … }
```

四个组合的形态与语义：

| 类型 | 名称 | 所有权 |
|---|---|---|
| `T` | 纯类型 | 共享只读；永不变（同一对象被多个 `T` 绑定也安全） |
| `@mut T` | 可变类型 | **唯一所有权**：同一时刻只有一个 `@mut` 句柄指向对象 |
| `@ref T` | 引用类型 | 共享只读视图：可能别处会改，但你不能通过它改 |
| `@ref @mut T` | 可变引用 | 共享可变：别名（多人可改同一对象） |

## 语义

**不可变默认，变化要显式争取。** `T` 与 `@mut` 的对立不是「编译器可以检查」的便利，而是语言的核心契约：

- `T` 永远不会变——如果不可变对象之间共享，不会出现别名问题。`var b : T = a` 后 `a` 与 `b` 是同一对象，互不影响地读
- `@mut T` 必须唯一——赋值即版本前进，旧绑定看到旧值（旧值等式事实进入 Γ 供给证明用）
- `@ref T` 承认「现在看的值可能将来变」——因此引用与可变一样**不可预测**，在上下文（证明）里享有与 @mut 相同的待遇

### 与拷贝规则的接口

绑定（声明/参数/解构）是否深拷贝，仅由这两个注解决定——见 [拷贝规则](02-类型-拷贝规则.md)：

- `@mut` 目标：永远深拷（唯一所有权不容共享）
- `@ref` 目标（无 @mut）：永远共享
- `@ref @mut` 目标：源为 `@mut T`/`@ref @mut T` 时别名共享，否则深拷
- 源带 `@ref` 而目标不带：深拷

### 其他类型形态

- 函数类型 `(T) => U`、零参 `() => Null`（[箭头家族](01-基础-箭头家族.md)）
- 泛型 `[T]`；类型别名 `type F[a] = T[a]`；联合 `Nat | Str`
- 枚举 `enum E { Nil(), Cons(T, E) }`；结构体 `@mut struct T(@mut n: Nat)`
- 类型类（typeclass）：约束式泛型与 `impl T { … }` 成员提升

## 示例

```subl
@mut struct T(@mut n: Nat)

@impure fun main() {
    var a : T = T(0)           // 纯类型的共享对象
    var b : @mut T = a         // @mut 目标：深拷贝，a 与 b 无关
    b.n = 1
    print(a.n)                 // 0

    var c : @mut T = T(0)
    @ref var d : @mut T = c    // @ref @mut ← @mut：别名共享
    c.n = 1
    print(d.n)                 // 1

    var e : @mut T = T(2)
    var f : @ref T = e         // @ref 目标：共享只读视图
    print(f.n)                 // 2；f.n = 3 非法：@ref T 不可写
}
```

## 陷阱

- **`@ref @mut` 是别名不是拷贝**：最常见的坑详见拷贝规则条目
- **`T` 不代表值快照**：`var b : T = a` 是共享；要独立副本须显式经 `@mut` 转一道（`var b : @mut T = a` 再 `.n` 读取，或用 `@ref` → `T` 深拷规则）
- **引用进证明要小心**：`@ref` 与 `@mut` 在上下文系统里同等待遇（不可预测性），涉及 `$`/`$n` 的后件若读引用值需注意其可能变化
- **不可变再赋值报 E-IMMUT-ASSIGN**：除非整体在 `unchecked <语句>` 局部豁免内
- **Optional 的 `Some` 视图已删除**（修正案）：相关形态以枚举/方法（`map`/`getOrElse`）为主
