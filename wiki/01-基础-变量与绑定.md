# 变量与绑定

> wiki/01-基础-变量与绑定 · 事实来源：Parser.kt parseVar/parseVarDestruct（805-845）、Checker.kt 赋值闸 E-IMMUT-ASSIGN（612 附近）

## 语法

```subl
var n = 0                  // 声明（不可变值为默认语义）
var n: T = e               // 带类型标注
var m = var k = 0          // @var 表达式：内层 var 的赋值前进，外层不可变
var (a, b) = pair          // 元组解构声明
@mut var w : @mut T = e    // 变量注解（@mut / @ref）与类型注解叠加
n = 5                      // 赋值（仅当 n 的类型含 @mut）
```

「值不可变」由**变量注解**控制而非声明修饰：可再赋值 ⟺ 变量以 @mut var 声明（实测：类型位的 @mut T 不赋予重绑权，见陷阱节）；赋值权限认 declareMut 登记，不读类型位。

## 语义

- 声明时右边表达式求值后，按 [拷贝规则](02-类型-拷贝规则.md) 决定深拷还是共享
- 不可变变量再赋值 → 报 **E-IMMUT-ASSIGN**（Checker 的赋值闸只在 `uncheckedDepth == 0` 时开启——包在 `unchecked <语句>` 里时局部豁免）
- @var 表达式（var m = var k = 0）：内层产生一个可变槽，前进是纯运行时语义——外层 m 绑定到当前快照；版本等式弥散进 Γ 未实现（实测 k == 41 证不出，E-CANNOT-PROVE）
- 元组解构：右值按结构逐元匹配（模式（0 元组/2 元组/…）），每个分量同样走拷贝判据

## 示例

```subl
@impure fun main() {
    var a = 1              // 纯 Nat，不可再赋值（a = 2 报 E-IMMUT-ASSIGN）
    var m = var k = 0      // k 可在 var 表达式内前进
    print((a, m))          // (1, 0)

    var (x, y) = (1, 2)    // 解构声明
    print(x + y)           // 3

    // 只在显式 @mut 时可写
    var box : @mut T = T(0)
    box.n = 7
    print(box.n)           // 7
}
```

## 陷阱

- var ≠ 可变：再赋值能力来自 @mut var 注解，与 var 关键字、类型位的 @mut T 都无关（实测 var b : @mut T = T(0) 后 b = T(5) 仍报 E-IMMUT-ASSIGN，正解是 @mut var b）；新写手最常踩
- **不可变再赋值报错名称**：E-IMMUT-ASSIGN，且 `unchecked { a = 2 }` 局部豁免是唯一正路（别改类型去绕）
- **纯类型之间的 `var b = a` 是共享**：不是快照；修改任何一方（若类型允许）会互相可见
- @var 的版本等式弥散未实现（实测 E-CANNOT-PROVE）：@var 语义是纯运行时绑定，证明层无版本等式可用
- **解构元数必须匹配**：`var (x) = (1, 2)` 报元数错；多返回值场景注意
