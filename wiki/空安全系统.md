# 空安全系统

## 没有裸 null

一切可能缺失的值都用 `Optional[T]`（`Some` / `None`）显式表示。类型系统层面不存在隐式 `null` 穿透。

```subl
var o: Optional[Nat] = Some(5)        // 有值
var p: Optional[Nat] = None()         // 无值
```

## 消费 Optional

1. 模式匹配（穷尽）：

```subl
when (o) {
    Some(x) -> print(x)
    None    -> print("none")          // 必须处理 None：编译器保证穷尽
}
```

2. 安全调用 `?`：

```subl
var y = o?.field         // None 时结果为 Null（短路）
```

3. 函数式接续：`o.map({...})` / `o.flatMap({...})` / `o.filter({...})`。

## 容器与 Optional 的 size

`Optional` 也实现 `Collection`：`Some` 的 size 为 1、`None` 为 0；`isEmpty` 同理。

## 转换与错误处理

`Result[T, E]`（`Ok` / `Err`）用于可预期的失败，同样实现 `Collection`（size 0/1）。
与 `Optional` 互相转换：`toOptional()` 等（stdlib 提供）。

## 边界

- 内部实现允许 `@mut` 与局部 `var`，但公开 API 表面不泄漏裸 `null`。
- JS 端 `Optional` 形态：`{ '0': v, tag: 'Some' }` / `{ tag: 'None' }`。
