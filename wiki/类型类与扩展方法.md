# 类型类与扩展方法

## 类型类（class + impl）

```subl
class Show {
    fun show(): Str
}
impl Show for Nat {
    fun show(): Str = ...      // 数字转字符串
}
print(42.show())
```

- 成员可带默认实现（impl 可覆写）。
- 断言约束：`fun f[T](x: T): Str <...> : Str` 之类可通过约束类型类参数限定（见 `doc/类型类与结构体.md`）。

## 扩展方法（impl 无类型类）

```subl
impl List[a] {
    fun head(): Optional[a] = when (self) {
        Nil -> None()
        Cons(h, _) -> Some(h)
    }
}
var xs = Cons(1, Cons(2, Nil()))
print(xs.head())               // Some(1)
```

- 脱糖为带 `self` 首参的自由函数，可被方法糖（`x.f()`）与普通调用法（`head(xs)`）共用。
- **多形态（重载）的推荐写法**：同作用域同名单一；不同接收者的同名方法用不同 impl 承载。

## 方法糖分派次序

`x.f(args)`：
1. 同名自由函数（含扩展方法），按接收者类型匹配首个形参；
2. 未命中 → 类型类字典（按 impl 声明自类型匹配）；
3. 都没有 → `E-NO-INSTANCE`。

`class` 声明本身不劫持方法名：只有实现了 impl 的类型才参与字典分派。

## Collection 体系

所有容器实现 `Collection`：

```subl
class Collection {
    fun contains[T](element: T): Bool
    fun size(): Nat
    fun isEmpty(): Bool
}
```

List/Set/Map/Optional/Result 及 Tuple 族都提供 impl；并有 `map` `filter` `flatMap` `forEach` `fold` 等函数式 API（自由函数 + 方法糖两用）。

## 高阶类型

```subl
class Functor[F[_]] {
    fun map[A, B](fa: F[A], f: (A) => B): F[B]
}
```

`F[_]` 是 kind-1 型参数；kind 在类声明期检查（`HKT-S5` 等规则见 `doc/高阶类型.md`）。
