## 语法

完整骨架（方括号表示可省略，类型参数/形参/上下文都可缺省）：

```subl
[@注解…] fun 名字 [理论参数] [(形参表)] [<上文>][: 返回类型 [<下文>]] = 表达式
[@注解…] fun 名字 [理论参数] [(形参表)] [<上文>][: 返回类型 [<下文>]] { 语句… }
```

- **注解**：`@impure fun f`，可叠加多个（parseAnnotations：Parser.kt:261）。声明位注解属于行为层：@impure（容许副作用调用）、@theorem（证明义务函数）、@root（原生内置声明）、@host（脚本模式：体由宿主运行时注入）、@async（异步函数）、@mut（仅 impl 成员：体内 self 持可变视图）、@axiom（下文签名即公理）
- **名字**：ASCII 标识符、反引号名「任意字符」（可含空格，如标准库 core.logic 的 `modus ponens`）、符号名与运算符符号（`fun +(a, b)` 形态被 nameToken 接受，Parser.kt:81-92）
- **理论参数**（方括号，parseTheory）：`fun f[T]`；带类型类约束 `[T: Num]`；命题参数 `[@p]`；高阶类型 `[F[_]]`（arity=1）、`[F[_, _]]`（arity=2）、`[F[_]: Foldable]`
- **形参**：`名字: 类型`，逗号分隔，允许尾随逗号。形参位注解如 `@list items: T`（Kotlin vararg 语义）；元组/结构体解构形参 `fun f((a, b): Point)`；默认值 `y: Nat = 1`（见语义节）。形参类型省略仅脚本模式解析器接受（allowUntyped → 占位类型，Parser.kt:396）
- **上下文角表**：以冒号分界 —— 冒号**前**的 <…> 是上文（调用方须已证明）；返回类型**后**的 <…> 是下文（函数体兑现后弥散进作用域）。返回类型可省略：`fun need()<p>: Null { }` 与 `fun need(): <p> { }` 等价（Parser.kt:283-295）
- **约束表**（v3.0）：`fun f<score <= 100>` —— 角括内首项是「IDENT + 带空格的比较运算」判为约束表（constraintListAhead：Parser.kt:311-316），与上文命题 <p> 按形状分派
- **函数体两形态互斥**：`= 表达式` 或 `{ 语句… }`；`= {…}` 混写直接报错并指向改法（Parser.kt:298-301）。体可整个省略（无体函数，语义见下）
- **函数类型字面量**（类型位写法，Parser.kt:485-585）：零参 `() => Null`；多参 `(A, B) => C`；多态函数类型 `[T](T) => T`（理论前缀仅服务函数类型）；携带上下文 `(T)<$1 ∈ xs> => Null`；纯度标注 `@impure (A) => Null`（类型位注解只支持 @mut / @atomic / @impure）。无 `=>` 的 `(T, U)` 是元组类型
- **局部函数**：块内可以直接 `fun`（v3.0，Parser.kt:635）；顶层只允许声明，执行代码必须放进 `fun main()`（Parser.kt:194-212）

## 语义

**纯度与副作用**

- 默认纯：未标 @impure 的函数注册 `pure<f>` 事实（Symbols.kt:26），其体内调用 impure 函数（print 等）报 **E-IMPURE-CALL**；逃逸方式三选一：给函数标 @impure、`unchecked` 语句局部豁免、上下文供给 `pure<f>`（CallCheck.kt:755-763）
- 形参含 `@mut` 可变类型的纯函数必须标 @impure（**E-IMPURE-REQUIRED**，Checker.kt:293）
- 纯度随函数值传递：体内含 impure 调用 → 函数值类型 `FunType.purity = "impure"`，纯上下文调用该函数值同样报 E-IMPURE-CALL（Checker.kt:1082-1142；CallCheck.kt:476-486）。类型位可显式写出：`f: @impure (A) => Null`（Parser.kt:513-519）

**返回类型**

- 显式标注取之；省略时块体 = `Null`（Kotlin Unit 语义），表达式体由体推导（Checker.kt:379-392）
- 块体 + 显式非 Null 返回类型 ⇒ 所有路径必须 `return`（**E-MISSING-RETURN**，Checker.kt:394-396）；`fun f(): Nat = 5` 这类表达式体不受此约束

**默认参数**

- 允许且只允许「尾部连续」：首个带默认值的形参之后必须全部带默认值（**E-DEFAULT-PARAM**，Symbols.kt:234-236）；默认值表达式类型须与形参一致（E-TYPE-MISMATCH，237-242）
- 调用 arity 放宽为「首个默认位 ~ 形参总数」（**E-ARITY**，CallCheck.kt:776-782）；命名参数 `f(y = 1)` 按名落位（Parser.kt:1233-1256；重复占用报 E-NAMED-ARG）
- 类型类成员与 impl 方法**禁止**默认值（Symbols.kt:272、281）
- 实现差异：JS 生成在声明侧与调用侧都填默认值（JsCodeGen.kt:713、1113）；解释器 run 路径把缺位实参填为 `Null` 而非默认值（Evaluator.kt:587-591）——check/compile 与 run 行为不一致，依赖默认参时注意

**重载与入口**

- 同名函数按**首个形参类型**不同重载（Symbols.kt:192-197）；零参函数无首参，同名即 **E-DUP-DECL**
- `main` 必须零形参、零类型参数（**E-MAIN-PARAMS**，Symbols.kt:243-245）；main 天然 @async（Checker.kt:316）；@async 函数的调用点必须处于 @async 上下文（**E-NEED-ASYNC**，CallCheck.kt:769）

**无体函数（body = null）的合法性**（Symbols.kt:246-268）

- @theorem 无体函数 = 公理（签名即定理）；有体定理函数照常类型检查与代码生成
- @host（脚本模式，宿关注入）、@android（白名单门 + 无体豁免）
- @root：签名告知编译器「该名对应编译期内建 JS 实现」，仅白名单名字允许（ROOT_WHITELIST：print/readLine/rand/toStr/jsonParse…，Types.kt:277-296），否则 **E-ROOT-NOT-ALLOWED**；有体函数标 @root 只给提示 H-ROOT-BUILTIN
- 其余无体函数一律 **E-FUN-NO-BODY**

**上下文（上文/下文）**

- 上文：调用点必须先证出（**E-PRE-UNPROVEN**，CallCheck.kt:921-925）；下文：函数体必须证出（**E-POST-UNPROVEN**，Checker.kt:414-418）；@axiom 注解的函数下文被信任、不证（Checker.kt:410-412）
- 下文里的 `$` 指代返回值（`fun get7(): Int <$ = 7>`）；前件/后件里的 `$n` 引用第 n 个形参（1 起），体内使用 `$n` 报 **E-PARAM-REF-IN-BODY**（Checker.kt:906）；`this` 在上下文里指代函数本体（`p<this>` → `p<f>`，Checker.kt:276-278）
- 命题参数 `[@q]` 走供给机制：调用点自动匹配作用域中的 0 元命题，多候选 **E-PROP-AMBIGUOUS**、无候选 E-PROP-UNBOUND，也可 `f<prop>()` 显式供给（CallCheck.kt:898-918）
- 形参进帧时自动注入事实：类型事实 `x: T`、Nat 形参蕴含 `x >= 0`（Checker.kt:354-357）、结构体形参的伴生命题逐字段替换后注入（Checker.kt:360-372）
- 约束表（`fun f<score <= 100>`）由调用点实参承担：确凿违反报 **E-CONSTRAINT-VIOLATED**，静态证不出降级 **W-CONSTRAINT-UNPROVEN**（CallCheck.kt:927-937）

**其他**

- 纯函数自递归须至少一个实参「变小」（结构子项或数值递减），否则 **E-NON-STRUCTURAL-REC**；@impure / unchecked / 方法路径不受此约束（CallCheck.kt:747-751）
- @theorem 函数编译期擦除、不生成 JS（JsCodeGen.kt:576）；**值级调用已解封** —— 正常调用并注入其下文事实（CallCheck.kt:743；CheckerTest.kt:1445-1447）

## 示例

```subl
// 基本形态：表达式体 / 块体
fun add(a: Nat, b: Nat): Nat = a + b
fun greet(name: Str): Str {
    return "hello, ${name}"                  // 字符串插值（${expr} / $name）
}

// 默认参数（尾部连续）+ 命名参数
fun pow(base: Nat, exp: Nat = 2): Nat =
    if (exp == 0) { 1 } else { base * pow(base, exp - 1) }

// 类型参数与类型类约束（core.num 文档原例：copy(1)、copy(1.5) 合法，copy(true) 报 E-NO-INSTANCE）
fun copy[T: Num](n: T): T = n

// 函数类型形参 + 尾随 lambda / 隐式单参 lambda
fun twice[T](x: T, f: (T) => T): T = f(f(x))
fun bump(): Nat = twice(2) { _ * 10 }         // 200

// 函数类型作为返回类型（零参函数类型 () => Nat 与零参 lambda { => 7 }）
fun apply(x: Nat, f: (Nat) => Nat): Nat = f(x)
fun make(): () => Nat { return { => 7 } }

// 变长实参（@list）与解构形参（标准库写法）
// fun listOf[T](@list items: T): List[T] = items          // core/collection/list.subl:40
struct Point(x: Nat, y: Nat)
fun sqNorm((x, y): Point): Nat = x * x + y * y

// 上下文：上文由调用方证明，下文由函数体兑现
fun half(a: Nat)<a > 0>: Nat = a / 2          // 上文：调用点须证 a > 0
fun get7(): Int <$ = 7> { return 7 }          // 下文：返回值 == 7，调用后弥散进作用域

fun use(): Null {
    half(4)                                   // 4 > 0 由算术通道自动证出
    get7()
    ∴ get7() = 7                              // 下文已弥散，后续证明可直接引用
    return
}

// 命题参数 + 自动供给
fun witness[@q]<q>: Null { }
fun supply(): Null {
    axiom torch
    witness()                                 // 自动供给 torch
    return
}

// 副作用：@impure 解锁纯度闸（纯函数体内须改用 unchecked 语句）
@impure fun log(m: Str): Null { print(m) }

// 定理函数：无体 = 签名即定理（标准库 core.logic 风格）
@theorem fun addComm(): <∀ a b . a + b = b + a>

// 局部函数（块内 fun）+ 统一演练（整个文件只有一个 main）
@impure fun main() {
    print(add(2, 3))                          // 5
    print(greet("subl"))                      // hello, subl
    print(pow(3))                             // 9（exp 取默认值；解释器执行下的差异见陷阱）
    print(pow(3, 3))                          // 27
    print(pow(base = 3))                      // 命名参数：9
    print(bump())                             // 200
    print(apply(4) { _ + 1 })                 // 5
    print(make()())                           // 7
    print(sqNorm(Point(3, 4)))                // 25
    use()
    supply()
    addComm()                                 // 值级调用解封，下文（全称交换律）注入作用域
    ∴ 1 + 2 = 2 + 1                           // 由注入的 ∀ 实例化可证
    fun helper(n: Nat): Nat = n * 2
    print(helper(21))                         // 42
    log("done")
}
```

## 陷阱

- **`= {…}` 混写被禁止**：表达式体去掉花括号、块体去掉等号；解析器直接报错并给出改法（Parser.kt:298-301）
- **默认参的 run/check 不一致**：checker 与 JS 生成按 Kotlin 规则填默认值，但解释器把缺位实参填 `Null`（Evaluator.kt:588）——解释执行时默认值不生效；另外部分旧诊断文案（CLI explain、语言服务提示）仍写「函数形参不允许默认值」，那是决策 69 扩展前的过期文案，以 Symbols.kt:231-242 为准
- **块体 + 非 Null 返回类型必须显式 return**：`fun f(): Nat { 5 }` 报 E-MISSING-RETURN；想省 return 就改用 `= 表达式` 体
- **纯度闸比想象中严**：纯函数体内直接调 print/rand 等 impure 函数即 E-IMPURE-CALL；`@mut` 形参的函数必须标 @impure（E-IMPURE-REQUIRED）；纯 lambda 里调了 impure 函数，该 lambda 的类型就变成 `impure`，传出去照样受闸
- **上下文位置以冒号分界**：`fun f()<p>: T <q>` 中 <p> 是上文（调用方证明）、<q> 是下文（体内证明）；写反位置语义完全相反
- **`$n` 只能写在前件/后件位**：函数体内用 `$1` 引用形参报 E-PARAM-REF-IN-BODY，体内请直接用参数名
- **零参函数不能重载**：重载按首形参类型分派，零参无首参，同名重复直接 E-DUP-DECL；也别指望靠「不同返回类型」区分同名函数
- **@root 不是自由注解**：只有 ROOT_WHITELIST（print/toStr/rand/jsonParse…）内的名字允许 @root 无体声明，否则 E-ROOT-NOT-ALLOWED；普通函数别加 @root
- **@theorem 的值级调用是允许的**：部分标准库注释仍写「禁止值级调用（E-THEOREM-VALUE-CALL）」，该警告已随修复 #3 移除（CheckerTest.kt:1445-1447）；@theorem 的实际效果是编译期擦除 + 调用注入下文
- **main 有隐形规则**：零形参零类型参（E-MAIN-PARAMS），且天然 @async —— main 里调 @async 函数合法，别的同步函数里调则报 E-NEED-ASYNC
- **形参类型省略只在脚本模式**：工程模式解析器要求每个形参带 `: 类型`（Parser.kt:395-397），缺标注报「期望COLON」
