# 视频录制清单（可照抄执行）

> 所有命令在 `F:\KotlinProject\sublimation`（项目根）下执行。
> 推荐录制方式：OBS 全屏窗口；左边编辑器开 `show/show.subl`，右边终端跑命令。

## 场景 A：一键演示（主场景，30s 素材）

```bat
cd F:\KotlinProject\sublimation\show
run.bat
```

期望终端输出：

```
[1/3] Compiling this show dir (show.subl + stdlib) ...
[1/3] compile OK.
[2/3] Running show.js ...
[2/3] run OK - result appended to show.log.

[DONE] artifacts: show.js + show.log
```

然后让镜头停 2 秒在这个输出上，切到 show.log。

## 场景 C：源码讲解（口播对应，切屏到 show.subl）

高亮片段（在 show/show.subl 里）：

```sublimation
struct Student(name: Str, scores: List[Nat])
enum Grade { A(), B(), C(), D() }

class Show[T] { fun show(): Str }
impl Show for Grade { ... }
```

另一段（命题）：

```sublimation
@unpure fun main() {
    // 命题层：上文/下文自动供给
    giveP()
    takeP()          // 编译期在作用域中检索到 p，通过
}
```

## 场景 D：命令行裸跑（可选，展示"零依赖 jar"）

```bat
java -jar build\libs\sublimation.jar check examples/showcase.subl
java -jar build\libs\sublimation.jar compile examples/showcase.subl -o out.js
node out.js
```

期望：check 无错误；compile 打出 `[完成]`；node 打印 showcase 的 15 行输出。

## 剪辑提示

- 口播"命题"时，画面放大 show.log 最后一行 `命题供给 = OK`
- 讲模块系统时配合文件树（项目里 `examples/json-studio/` 目录结构截图即可）
- 封面可用黑底 + 白色 `Sublimation` 字体 + 一行 `v1.0 · 零依赖编译器 → JS`
