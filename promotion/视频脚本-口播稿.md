## 它是什么（0:45–1:20）

🎬 切 PPT：三个关键词卡片

📢 三个关键词说清楚 Sublimation：

1. **编译到 JS**：`fun add(a: Nat, b: Nat): Nat = a + b` 直接变成 node 能跑的 JavaScript，没有运行时库，产物是纯文本。
2. **命题系统**：Kotlin 有智能转换——`if (x is String)` 里编译器自动知道 x 是字符串。我们把它**泛化到任意命题**：赋值、分支、函数前后置条件，全都自动吸收、自动推理。
3. **零依赖编译器**：整个编译器就一个 fat jar，`java -jar` 就能跑。

📢 一句话：**别人检查类型，我们证明命题。**

## 核心特性（2:40–3:40）

🎬 卡片式罗列，每张一句 + 芙芙表情包

📢 讲几个它真正独到的点：

1. **上下文弥散**：函数类型携带前置/后置命题，调用后自动注入作用域。目标是 500 行真实程序里，手动写证明不超过 5 次。
2. **目录即模块**：一个目录 = 一个模块，`模块名.settings` 显式挂载；根目录的 `stdlib/` 自动挂给所有模块。
3. **类型类走 Rust 机制**：`class Show[T]` + `impl Show for Grade`，字典分发、隐式 self。
4. **真模式匹配**：`when` 支持解构、嵌套、守卫、穷尽判定——Java 式 switch 全废。
5. **纯度受控**：函数默认必须纯；想逃只有 `unchecked` 一个口子，还留注释供审计。
6. **运算符即函数**：`1 + 1` 就是 `+(1,1)`，可自定义运算符，没优先级、一律左结合。
