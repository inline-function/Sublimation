# Sublimation 示例集（按特性分文件，中文文件名）

> 每个文件演示一个语言特性，头部注释标明**预期输出**，全部经过 compile + node 实测。
> 用法：`java -jar build/libs/sublimation.jar compile examples/<文件>.subl -o out.js` 然后 `node out.js`。

| 文件 | 特性 |
|---|---|
| 结构体与枚举.subl | struct 默认值/命名字段构造、enum ADT、if/var |
| 上下文弥散.subl | 命题系统：上文/下文/∀ 实例化/显式供给/$ 指代返回值 |
| 模式匹配.subl | when 真模式匹配：解构/嵌套/守卫/顺序否定/元组解构 |
| 空安全.subl | Optional、T?、>: 安全转换、?T 类型测智能转换 |
| 类型类.subl | class/impl、字典分发、隐式 self、双形态调用 |
| 高阶函数与lambda.subl | 函数类型、显式/隐式单参 lambda、函数作值 |
| 标准库集合.subl | List 常用高阶：size/map/filter/fold/range/joinToString |
| 错误处理.subl | Result[T,E]：解构/unwrapOr/isOk/mapResult |
| JSON内建.subl | jsonParse 系 11 个内建，全部空安全 |
| 字符串与插值.subl | concat/length/charAt/substring/strCmp/parseNat/插值/命名参数/元组解构 |
| 异步与并发.subl | Task/Channel/@async 自动 await、receive 智能转换 |
| 可变性控制.subl | @mut、immutable<T>、untouch<param> 自动注入 |
| 高阶类型.subl | HKT：[F[_]] kind 形参、impl for List[a]、kind 合一 |
| 特性巡礼.subl | 一文件覆盖大部分特性（15 行输出） |
| 模块系统/ | 目录即模块：根模块跨模块调用子模块 tool.triple |

> 单文件模式不挂载 stdlib（List/Set/Map/Result 需在文件内自声明）；
> 目录模式会自动把编译入口下的 `stdlib/` 隐式挂给所有模块（见仓库 `show/` 演示包）。
> 标识符目前仅支持 ASCII（中文仅用于文件名，见 模块系统/ 的 tool 子模块）。
> **已知问题**：`@tuple` 形参 + when 元组解构的运行时行为与预期不符（`sum((12,30))` 输出数组而非结果，T4 测试仅锁类型检查）；示例改用常规元组参数演示解构，`@tuple` 语义待修（见 CheckerTest T4）。
