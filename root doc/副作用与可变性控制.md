# 变量

> 可变变量除了自反外，不承认它与其他表达式的相等命题

变量默认是不可变的，除非注解`@mut`。

如果你真的想让可变变量配合上下文系统，我们建议直接写一个新的不可变变量赋值它。下面也是一样的道理，证明不可变的最好办法，就是让编译器看见你亲自把可变性割掉。

## 函数

> 不纯函数的调用是不纯表达式，不承认不纯表达式的相等命题，包括自反

函数在没有标注`@impure`的时候，默认就是纯函数。

纯函数有它的自然命题`pure<f>`，若不纯函数证明该命题，则认为是纯函数。

纯函数必须做到如下三个要求：

+ 体内不能有不纯的表达式

+ 不能捕获外部的可变变量

+ 必须证明自己停机

标注时，解除上述限制。

关于递归对的停机证明有两：

其一是证明每次递归的时候，递归的函数参数是原先的子结构，并且在递归到空结构时停止。

其二是证明每次递归的时候，递归的函数参数向着某个数值靠拢，并且在递归到那个数值的时候停止。

函数的参数类型可变时，函数必须标注`@impure`。

# 可变结构体

> 不承认可变结构体与其他表达式的相等命题

为结构体标注@mut，表示允许结构体声明可变属性。

结构体的属性可以注解`@mut`，此时结构体的属性可变。

```
@mut
struct T(@mut n : Nat)
```

修改结构体的可变属性，需要变量对的结构体类型可变，在结构体类型前面加上`@mut`表示变量的结构体可变。

```
var a : @mut T = T(0)
var b : T = T(0)
a.n = 1 //正常
//b.n = 1 编译不通过
```

# 可变类型

> 不承认可变类型与其他表达式的相等命题

为类型类注解`@mut` ，表示允许类型类声明可变函数。

类型类的函数可以注解`@mut`，即可变函数，这表示这个函数只能在类型可变的时候调用，可变函数可以修改实现时结构体的可变属性。

类型可以注解`@mut`，这表示类型是**可变类型**

```
@mut
class T {
    @mut
    fun add(n : Nat)
}
```

# 可变拷贝

> 对函数深拷贝时，深拷贝函数闭包捕获的变量

可变类型赋值给其他变量时会进行深拷贝。

```
var a : @mut T = T(0)
var b : T = a //[补充]a将被深拷贝并不可变化后赋值于b
a.n = 1
print(b.n) //此时仍然是0
```

```
var a : T = T(0)
var b : @mut T = a //[补充]a将被深拷贝并可变化后赋值于b
b.n = 1
print(a.n) //此时仍然是0
```

```
var a : @mut T = T(0)
var b : @mut T = a //[补充]a将被深拷贝后赋值于b
b.n = 1
print(a.n) //此时仍然是0
```

对于可变类型变量，如果明确想分享同一个对象，需要为接收方的类型标注`@ref`。

```
var a : @mut T = T(0)
var b : @ref @mut T = a //[补充]b将代表a的值
b.n = 1
print(a.n) //此时是1
```

```
var a : @mut T = T(0)
var b : @ref T = a //[补充]b将共享a的不可变视图
// b.n = 1 无法赋值
```

```
var a : @ref T = T(0)
var b : @ref T = a //[补充]b将引用a所引用的值
```

```
var a : @ref @mut T = T(0)
var b : @ref @mut T = a //[补充]b将引用a所引用的值
```

```
var a : @ref @mut T = T(0)
var b : @ref T = a //[补充]b将引用a所引用值的不可变视图
a.n = 1
print(b.n) //此时是1
```

引用与可变一样不可预测，因此在上下文中享有和可变相同的待遇。

一个类型`T`和一个类型的引用`@ref T`，区别在于`T`永远不会变，而`@ref T`可能会变，因为可能其他地方会修改所引用的值，只是你不能通过非可变引用去修改而已。

将不可变类型传给不可变类型引用时不会深拷贝，而是共享同一个对象；就和不可变对象传给不可变对象一样，共享同一个对象。

```
var a : T = T(0)
var b : @ref T = a //不拷贝
```

```
var a : T = T(0)
var b : T = a //不拷贝
```

不可变引用类型转非不可变引用类型时深拷贝。

```
var a : @ref T = T(0)
var b : T = a //深拷贝
```
