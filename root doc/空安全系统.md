## 可选类型

`Optional[T]`是一个两值枚举，分别是用于表示有值的`Some[T]`和表示空值的`None`。

`T?`是`Optional[T]`的语法糖，因为隔壁kotlin的原因，我们也可以叫它可空类型。

可空类型语法糖可以像`Optional[Optional[T]]`一样嵌套：`T??`

Some[T]可以直接赋值给T类型的变量，此时会发生隐式转换。

# 空安全函数

## 安全替换函数

```
fun ?:[T](a : T?,b : T) : T =
    if(a == None)
        b
    else
        a
```

## 安全调用符

```
o?.f()
```

如果o是空的，则表达式返回None

## 安全转换运算符

> as是内置关键词

```
o as T
```

如果o是T的实例，则转换成功，否则返回None
