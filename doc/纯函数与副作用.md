# 纯函数与副作用

## 纯度标注

- 函数默认**纯**（可被证明系统收录为定理的前提条件之一）。
- `@impure`：允许副作用（IO、打印、可变状态）。标了 `@impure` 的函数**不是定理**。
- `@mut`：可变参数；`@mut` 参数说明函数会就地修改该对象，也排除在定理判据外。

## 上下文中的表达式必须是纯的

伴生命题、`∴`、`if[p]` 里出现的表达式必须是纯表达式——证明系统不处理副作用。副作用只能出现在语句/表达式体里。

## Collection 的可变与副作用方法形态

```subl
class Collection {
    @mut  fun add(e: T)
    @mut  fun removeAll(e: T)
    @impure
fun forEach(f: @impure (T) => Null)
    fun filter(f: (T) => Bool): /* 各容器决定返回类型 */
}
```

- `add`/`removeAll` 就地修改集合（`@mut`）；
- `forEach` 接受纯函数但本身 `@impure`（会调用外部效应）；
- `filter` 纯：返回新容器，不修改原对象。

## 私有可变状态的边界

模块内部允许 `@mut` 对象与局部 `var`；跨模块/纯函数边界自动收束。
