# 术语表

> 按字母序。所有条目以现行实现为准（2025 年 v3.0 语义）。

- **伴生命题**：挂在声明上的命题（前件 `<...>` / 后件 `<...>`）。后件里 `$` 指代返回值。示例：`..(l,r)` 的 `<∀n. n ∈ $ → n ≥ l, ∀n. n ∈ $ → n ≤ r>`。
- **定理函数**：无 `@impure`、参数无 `@mut`、返回 `Null` 的函数。**自动**登记进定理空间，无需注解；代码生成照常进行（定理体内可能经 `unchecked` 逃离检查）。
- **类型类实现（impl）**：`impl Trait for T { ... }` 为类型 `T` 提供 `Trait` 的方法字典。字典名以自类型为准。
- **扩展方法**：没有实现类型类的 impl（`impl List[a] { fun head() ... }`）。成员脱糖为带 `self` 首参的自由函数，是多形态的唯一推荐承载方式。
- **结构体（struct）**：值类型字段集合；`struct Point { x: Nat, y: Nat }`；构造 `Point(1,2)`。
- **纯函数**：无副作用、不修改参数、可被证明系统信任的函数。上下文中（命题、`∴`、`if[p]`）的表达式必须是纯的。
- **上下文系统**：`∵`/`+∵`（事实注入）、`∴`（求证）、`if[p]`（命题守卫）、`when(n in _)`（区间穷尽）组成的命题环境。
- **关键表达式**：穷尽判定收集的区间端点（`when(n in _)` 收集 0,10,11,20,21,30…），排序衔接覆盖判断穷尽。
- **方法糖优先**：`x.f()` 先找同名自由函数（含扩展方法）按接收者匹配，未命中再查类型类字典。
- **自动自反**：结构相同的表达式自动相等（`1+2 = 1+2` 可证；`1+2 = 3` 不自动证）。
- **自然命题**：每个自然数恒有 `n ≥ 0`。
- **定理库**：`core.logic`（区间界/传递/合取/MP 等）与 `core.logic.classic`（排中律/双重否定/换质位，`@classic` 标记）。
- **模块/挂载**：目录即模块；settings 文件 `<模块名>.settings`，`mount <path> [as <alias>]`；std 隐式挂载；跨模块定理搜索按可见路径。
