## R1 显式 return（决策 71）

一次性令牌模型（定稿勿再摇摆）：`checkFun` 发放 `pendingFunReturn`，只被**函数体自身的块**领走；
嵌套块（if/when 分支、lambda 体、块当值用）领不到令牌 → `E-RETURN-OUTSIDE`。
与 codegen 严格对齐：只有函数体块/字典方法体展平成真正的 JS 函数（return 即函数返回）；
其余块全是 IIFE（return 只能退出 IIFE，静默错位不如明确拒绝）。
要点：裸 `return` 仅 Null 函数；带值 return 核对声明返回类型（`E-RETURN-TYPE`）；
return 之后语句触发 `W-UNREACHABLE`（复用 Nothing 标记）；`dollarOf` 认唯一带值 return。
字典块体方法必须是 `function (d, __self, …) { … }` 形态（箭头 IIFE 会吞 return）。

## R3 诊断码全覆盖体检（决策 72）

`DiagCoverageTest`：39 个码逐一构造触发场景。钉出的事实：
- 解析错误走 `ParseFailure` 异常通道，不进 DiagBag（断言异常而非码）；
- `E-ANY-INFER` 是预留码，断言其不触发；
- `E-DEEP-SATURATION` 需**右嵌套**蕴含链（`u->` 左结合一次下钻即转查原子目标）；
- `p.x = 2` 触发 `E-ASSIGN-TARGET`（左值仅名字）。
