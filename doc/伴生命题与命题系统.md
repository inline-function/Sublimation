# 伴生命题与命题系统

> 术语表见 `doc/术语表.md`；公开教程见 `wiki/上下文系统.md`。

## 声明形态

```subl
@root fun ..(l: Int, r: Int): Range[Int]
    <∀n. n ∈ $ → n ≥ l, ∀n. n ∈ $ → n ≤ r>
```

- 形参后、冒号前的 `<...>` 是**前件**（前提）；返回类型后的 `<...>` 是**后件**（结论），后件里 `$` 指代返回值。
- 伴生命题写成「命题列表」，逻辑链接词是**蕴含**：`x ∈ $ → x ≥ l` 表示「结果里的每个元素都有下界」。

## 命题类型

- 原子命题：`e = e'`、`e ∈ c`（∈ 是两参命题，不做元素类型检查）、`n ≥ m` / `n ≤ m`、`p`（恒真事实）。
- 复合：`p → q`、`p ∨ q`、`p ∧ q`、`¬p`、`∀n.p`、`∃n.p`、`n < ts`（自然数实例化）。
- 自然数恒有自然命题 `n ≥ 0`。

## 事实注入与验证

- `∵ p` / `+∵ p` **不是公理注入**：p 必须先**在上下文中成立**（从 Γ 推导，或由常数值判定为真，如 `15 ∈ (0..30)`），证明成功才注入 Γ；否则报 `E-CANNOT-PROVE`。
```subl
+∵ 15 ∈ (0..30)   // 数值成立 → 可证 → 注入；不可证只会报错，不会像 unchecked.axiom 那样无条件接受
```
- 函数的前件（前提，`<p>` 写在形参后、返回类型前）注入函数体事实，是区间事实的主要来源：
```subl
fun demo(n: Nat)<n ∈ (0..30)>: Nat { ... }   // 体内 Γ 含 n ∈ (0..30)
```
- `∴ q` 从当前 Γ（事实多重集）求证 q；自动证明失败报 `E-CANNOT-PROVE`。
- 想要「无条件令命题成立」只走显式逃逸 `unchecked.axiom[...]`。

## 自反性与范围

- 结构完全相同的表达式自动相等（自反）：`1 + 2 = 1 + 2` 可证；`1 + 2 = 3` **不**自动证（没有决策过程）。
- 区间判断：`a ∈ (l..r)` 展开为 `a ≥ l ∧ a ≤ r`；`when(n in _)` 的穷尽判定依赖区间端点的**关键表达式**收集与衔接覆盖。

## 自动证明的搜索空间

`proveOrDeep` 按序尝试：
1. 前件化简（const 前提直接判真/假）。
2. 结构自反、区间边界（`rangeBounds`）、`n ≥ 0`。
3. `rangeExhaustive`：纯 `in` 区间析取 + 前提里同变量的 domain → 排序相邻衔接覆盖。
4. 定理空间：本模块 `theorems` + 可见路径各模块 `theorems`（`searchTheorems`），合一搜索（深度受限）。
5. `if[p]` / 蕴含前件递推。

## 关键表达式（`when(n in _)` 的穷尽）

```subl
+∵ n ∈ (0..30)
when(n in _) {
    (0 .. 10) -> print(1)
    (11 .. 20) -> print(2)
    (21 .. 30) -> print(3)
}
```
收集 `0, 10, 11, 20, 21, 30` 作为关键表达式，排序后相邻衔接判定覆盖 `(0..30)`；
自动证明系统应足够强大到证明此类分支是穷尽的，否则说明自动证明还不可用于实践。
