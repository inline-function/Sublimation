## 轨道 T：理论 / 性质研究

### T-0 定理证明器完善清单

当前证明器 = 正向饱和（合取分解 / 双否 / ∀ 单名实例化 / MP 前向链接 / 矛盾检测）+ 目标判定（同一 / 等式自反 / ∃ 单见证 / ∨ 子集 / ⊥ 爆炸）+ 构造子单射 + α-等价。

**已知缺口（按对 when 穷尽性的影响排序）**：

1. ✅ **嵌套 ∃ 展开**（决策 64，第 1 轮完成）——覆盖律深展开 + 分支命题 ∃ 封闭 + 同构匹配，`Prop.kt` 零改动
2. ⬜ **多名字量词**：`∀x,y. p<x,y>` 当前 `names.size != 1` 直接跳过
3. ⬜ **∃! 唯一量化**：只解析不推理（决策 39 要求做消去 + 单见证）
4. ⬜ **等式合同闭包**：等式只做语法同一 + 自反 + 构造子单射；缺**对称 / 传递 / 浅层代换 / 类型事实等式传播**——**P4 落地浅层部分**
5. ⬜ **算术片段**：`abs≥0`、`n<0 → n≠0` 全不可证（需定可判定子集，P4 后仍不做）
6. ⬜ **∨/¬/→ 待证侧引入**：目前只做语法匹配或子集
7. ⬜ **饱和终止性**：∀ 实例化候选项靠 maxRounds 截断，需论证有界性
8. ⬜ **深度上限策略**：现 maxDepth=6 / maxRounds=3 是经验值（`E-DEEP-SATURATION` 需右嵌套才触发，见决策 72）

### T 轨其余

- ✅ T-2 伴生命题与下文注入的共存表述（决策 55）
- ✅ T-3 ∃! 解析（推理待 P4 后）
- ✅ T-4 证明器报错话术（决策 40）
