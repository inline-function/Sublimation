# 类型类与结构体

> 术语表见 `doc/术语表.md`。

## 类型类（class + impl）

```subl
class Collection {
    fun contains[T](element: T): Bool
    fun size(): Nat
    fun isEmpty(): Bool
}
impl Collection for List[a] {
    fun contains[T](element: T): Bool = when (self) { Nil -> false; Cons(h, t) -> if (h == element) { true } else { t.contains(element) } }
    fun size(): Nat = when (self) { Nil -> 0; Cons(_, t) -> 1 + t.size() }
    fun isEmpty(): Bool = self.size() == 0
}
```

- 字典按「impl 声明的自类型」成立；方法调用 `x.f()` 先自由函数（含扩展方法）、后类型类字典。
- **扩展方法** = 没有实现类型类的 impl：`impl List[a] { fun head(): Optional[a] = ... }` —— 成员脱糖为带 `self` 首参的自由函数，是语言里多形态（同名不同接收者）的**首选承载方式**。
- 同作用域同名单一：首参相同即 `E-DUP-DECL`；同名不同形态尽量交给扩展方法/类型类 impl。

## 结构体（struct）

```subl
struct Point { x: Nat, y: Nat }
```
- 字段 = 形参加默认值；构造 `Point(1, 2)`；字段访问 `p.x`。
- struct 是值类型；`enum` 是代数数据类型（ADT，构造子即标签）。
- 名称空间：类型名（class/enum/struct）与函数名各自成表，不冲突。

## 常用容器 API（stdlib/collection.subl）

- `List[a]`：Nil/Cons；size/isEmpty/contains/head/last/map/filter/flatMap/forEach/fold/append/reverse/take/drop/zip/any/all/indexOf/slice/sortBy/distinct/joinToString…
- `Set[a]`：SetNil/SetCons；size/isEmpty/contains/add/remove/map/forEach/union/intersect/toList…
- `Map[k, v]`：MapNil/MapCons；size/isEmpty/get/put/remove/containsKey/keys/values…
- `Optional[a]` / `Result[a, e]`：Some/None、Ok/Err；size/isEmpty/map/filter/flatMap…
- Tuple 族（EmptyTuple/SingleTuple/(a,b)/(a,b,c)）统一抽象为 `Tuple` 型类（size/isEmpty）。

## 高阶类型

```subl
class Functor[F[_]] {
    fun map[A, B](fa: F[A], f: (A) => B): F[B]
}
```
- `F[_]` 声明 kind-1 型参数；kind 检查在类声明期进行。
- 字典名不含占位；HKT 方法按「kind 应用位」重排实参（点号式字典调用装配为增量项）。

## 规划中的类型（设计形态，尚未实装）

- `Range[Int]`：`..` 中缀的返回类型，伴生命题 `<∀n. n ∈ $ → n ≥ l, ∀n. n ∈ $ → n ≤ r>`。当前区间以字面量形态用于 pattern（`when(n in _)`）与命题（`n ∈ (0..30)`），穷尽判定已收敛端点证明；Range 类型化与 `Collection impl for Range` 为后续增量。
- `Any` 类型类（`in[T](Collection[T])` / `==` / `!=` 伴生命题形态）：受限顶类型设计已文档化；`==`/`!=` 与内建运算符的整合为后续增量。
