## 1. 词法

### 关键字（保留）

```
fun class struct enum var impl for if else when is unchecked by type return
```

非关键字（prelude 名字/上下文字符，可作普通标识符，语法位特殊识别）：`true false null forall exists exists1 not`。
`other` 已从兜底语法移除——兜底用 `_` 或 `else`（`else` 是关键字，case 位识别 PatElse）。

`self` **不是关键字**——它是 impl 方法体内隐式注入的变量名（O2），用户也可以写出，但会被内层参数/局部变量遮蔽。

### 符号

| 符号 | 用途 |
|---|---|
| `( ) [ ] { } , ; : . @ \ $` | 分组、理论参数、lambda/尾随调用、分隔、可变标记、lambda 头、返回值 |
| `+ - * / % = : == != < > <= >= ! & \|` | 算术；`=` 命题等式、`:` 类型测（均可中缀）；`==`/`!=` 是**函数禁中缀**（决策 32）；比较、逻辑 ascii 别名（`&`合取 `\|`析取 `!`非） |
| `-> <-> =>` | 蕴含、等价、lambda 箭头、when 分支箭头（`->`） |
| `∀ ∃ ∃! ∧ ∨ ¬ → ↔ ⊤ ⊥` | 命题层 Unicode 主写法（逻辑符固定单 token，不做标识符；`→↔∧∨¬` 为命题算符） |

### 字面量

- 整数：十进制数字串（Nat/Int 字面量；`1/2` 就是 `/(1,2)` 的普通调用，Rat 由类型层约定）。
- 字符串：`"..."`，转义支持 `\n \t \r \" \\`。
- 注释：`//` 到行尾。

### 标识符

ASCII 字母/下划线开头，后接字母数字下划线；**符号名也是合法标识符**（`+`、`<` 可作声明名与调用名，`+(1,2)` 与 `1 + 2` 等价；Unicode 数学符号如 `○`、`≠` 亦可作名字，`∀∃∧∨¬→↔⊤⊥` 保留为逻辑 token 不可作名字）。

**✅ 跨模块引用用点号限定路径**（P0 引入）：
- 同模块内直接写裸名：`func(...)`
- 跨模块写路径：`core.math.gcd(...)`、`c.Point`
- 路径从当前模块的**可见集合**起算（详见 §3.6）

### 邻接规则（消歧的核心）

词法器为每个 token 记录"前面是否有空白"。规则：

- **紧贴名字/闭括号的 `<` 是实例化**：命题项 `p<v>`、调用供给 `witness<torch>()`、类型实例化 `Optional[Nat]`、声明上下文中置/下文 `fun f()<p>: T<q>`。
- **带空格的 `<` `>` 是比较函数**：`a < b`。写成 `a<b` 会被解析成实例化，语言服务应提示加空格。
- 声明结构位（形参表之后、返回类型之后）的 `<...>` 是上文/下文列表，按语法位置识别；类型实参的 `<` 必须紧贴类型名，否则回落为下文位（解析器带失败回退）。
- 嵌套尖括号按计数配对：`fun test[v]<p<v>>` 合法。

## 2. 文法（EBNF）

```
file        ::= entry (';' entry)*
entry       ::= decl | stmt                       顶层语句即主序列（隐式 main）

decl        ::= '@' IDENT* 'fun' NAME theory? params? preps? (':' type)? postps? ('=' blockExpr | blockExpr)
              # 体两种写法等价（O1，决策 68）：`T = {…}` 与 `T {…}`；class 成员的无体签名不接块体
              # 两形态互斥（决策 73）：`= 表达式`（无花括号）vs `{ 语句… }`（无等号）；`= {` 混写报 E-PARSE
              | 'class' NAME theory? '{' funDecl (';' funDecl)* '}'
              | 'impl' type 'for' type '{' funDecl (';' funDecl)* '}'
              # impl 方法带隐式 self（O2，决策 68）：签名不写接收者，体内可裸用自类型的字段名
              | 'struct' NAME theory? '(' fields ')'      圆括号体（决策 69；大括号体报错并给改写指引）
              | 'enum' NAME theory? '{' ctor ((','|';') ctor)* '}'
              | 'type' NAME theory? '=' type                类型别名（决策 30）

theory      ::= '[' tparam (',' tparam)* ']'      tparam ::= NAME (':' NAME)? | '@' NAME
params      ::= '(' (annParam (',' annParam)*)? ')'   annParam ::= '@' IDENT* NAME ':' type    形参可带注解（@tuple，决策 61）
fields      ::= (annParam (',' annParam)*)?           struct 字段 = 形参加默认值：NAME ':' type ('=' expr)?（决策 69）
              # 默认值只属于 struct 字段；函数形参带 `=` 报 E-DEFAULT-PARAM
preps/postps::= '<' expr (',' expr)* '>'          上文在前、下文在后；下文可用 $ 指代返回值、$n 指第 n 个形参（决策 58）
blockExpr   ::= block | expr
block       ::= '{' (stmt (';'? stmt)*)? '}'      末表达式即返回值；空块为 Null 结果
ctor        ::= NAME ('(' type (',' type)* ')')?  带字段构造子即 ADT（决策 46）

type        ::= NAME ('<' type (',' type)* '>')?  尖括号须紧贴类型名
              | '(' (type (',' type)*)? ')' '=>' type     函数类型 (A,B)=>C / ()=>C（决策 57，v1 无前后件）
              | '(' type (',' type)+ ')'                  元组类型 (T,U)（决策 61；()=>T 归函数类型）
              # 基本类型：Nat Int Rat Str Bool Null Nothing Any EmptyTuple SingleTuple；别名见 type 声明

stmt        ::= ('@' IDENT*) 'var' NAME (':' type)? '=' expr
              | postfix '=' expr                   @mut 赋值（语句位左值为名字/字段的 `=`；其余位置 = 是命题等式）
              | 'return' expr?                     显式返回（决策 71）：裸形仅返回 Null 的函数合法；位置见 §8
              | 'unchecked' '.' 'axiom' '[' expr (',' expr)* ']'   命题逃逸
              | 'by' '[' expr (',' expr)* ']'      辅助策略（决策 48，暂缓推广，能自动证明的不用手写）
              | 'unchecked' stmt                   逃逸前缀：unchecked 调用 / 赋值
              | block | expr

expr        ::= unary (BINOP unary)*               无优先级，全部左结合
              | expr 'by' '[' expr (',' expr)* ']' 后缀辅助策略（ByExpr）
BINOP       ::= + - * / = : <= >= & | -> <-> ∧ ∨ → ↔
              ; `<`/`>` 仅带空格时是比较中缀（邻接规则）；SYMBOL 名带空格即中缀（两参解糖 ○，决策 50 归档）
unary       ::= ('-' | '!' | '¬' | 'not') unary | postfix
postfix     ::= primary ( '.' NAME | callTail | instTail | braceLambdaTail )*
callTail    ::= '(' (expr (',' expr)*)? ')'        应用；实参可含 varExpr（声明皆表达式，A3）
instTail    ::= '<' expr (',' expr)* '>'            紧贴的 <：命题项 p<ts> / 显式供给 witness<torch>()
braceLambdaTail ::= '{' NAME (',' NAME)* '=>' expr '}'   尾随 lambda（大括号内含 => 才判 lambda）

primary     ::= INT | STR | '$' | DOLLAR_N | '⊤' | '⊥' | NAME | 符号'(' 形式 | '(' expr ')'
              | '(' expr ',' expr (',' expr)* ')'          元组字面量 (a,b)（判据=逗号；(a) 仍是括号表达式，决策 62）
              | '\' '(' NAME (',' NAME)* ')' '=>' expr     反斜杠 lambda
              | '{' NAME (',' NAME)* '=>' expr '}'         大括号 lambda
              | 'var' NAME (':' type)? '=' expr            var 声明即表达式，值=初值（A3）
              | 'fun' NAME? theory? params? preps? (':' type)? postps? '=' blockExpr
                # 匿名函数表达式（A3，指导§52-56）；NAME 为 `_` 或省略；省略式 `fun[T](a:T):T = a`
              | 'if' expr block ('else' block)?
              | 'when' whenHead '{' whenArm (';'? whenArm)* '}'
              | QUANT NAME (',' NAME)* '.' expr
DOLLAR_N    ::= '$' DIGIT+                                  $n 参数引用（决策 58，词法粘连；仅上/下文合法，体内报错）
whenHead    ::= '(' expr ')' | '(' 'var' NAME '=' expr ')'     绑定主题（指导§51）
whenArm     ::= pattern ('if' expr)? '->' (block | expr)       守卫内蕴含需加括号（-> 与分支箭头消歧）
pattern     ::= 'else' | '_' | NAME | lit | ctorPat | tupPat | 'is' NAME ('as' NAME)?
              ; lit      = INT | STR                       分支命题 subj = lit
              ; ctorPat  = NAME ('(' pattern (',' pattern)* ')')?   分支命题 ∃绑定变量. subj = C(…)（嵌套递归）
              ; tupPat   = '(' pattern (',' pattern)+ ')'  元组解构（决策 61；判不出穷尽时按决策 66 静默退化为 Null）
              ; 裸名无括号：已知构造子→零元模式；未知→绑定变量（语义层裁决）
QUANT       ::= '∀' | '∃' | '∃!' | 'forall' | 'exists' | 'exists1'
```

### 2.1 ✅ settings 文件语法（P0 引入）

**模块目录下的 `<模块名>.settings` 文件**，用于声明该模块对其他模块的挂载。**不是 `.subl` 文件**，有自己的行式语法：

```
# 每行一个 mount 声明；空行与 `#` 注释忽略
mount <绝对路径> [as <别名>]

# 例（project/project.settings）
mount core
mount lib/parser
mount core/math as math
mount someuser/json as json
```

规则：
- 路径**绝对**（从根 `/` 起）：`mount core` 指挂载 `/core`
- `as <别名>` 可选；挂载后别名成为当前模块（及其所有后代）的本地可见名
- **引用式**：挂载不复制代码，只在命名空间里加一条映射；同一模块被多父挂载时是同一份符号
- **传递性**：`project` 挂 `core`，`core` 挂 `foo` → `project` 能看到 `foo`
- **循环禁止**：挂载链成环报 `E-CIRCULAR-MOUNT`
- **命名冲突**：本地目录名与挂载别名冲突 → `E-DUP-DECL`（`as` 别名可解决）
- settings 文件语法错 → `E-PARSE-SETTINGS`

### 2.2 ✅ 跨模块引用（P0 引入）

**引用的路径相对当前模块视角**——从当前模块的**可见集合**里找起点名字，剩下的按路径走。

| 场景 | 写法 |
|---|---|
| 同模块内引用（文件共享符号表） | `func(...)`（裸名） |
| 引用子模块 | `data.func(...)`（`data` 是当前模块的子模块） |
| 引用挂载的模块 | `core.math.gcd(...)`（`core` 通过挂载或传递可见） |
| 引用跨模块的类型 | `c.Point`（类型名同样支持点号限定） |

**关键**：挂载传递后，`project` 及其所有后代引用 `core` 时**写法一致**——都是 `core.math.gcd`；不会因为引用点在不同深度的子模块而改变路径。

**根模块边界**：`/` 能看所有后代；但**后代看不到根模块**。根模块里的函数不能被子模块引用（设计意图——根模块只是编译入口容器）。`main` 函数是唯一例外——codegen 扫全树找它，不走可见性检查。

## 3. 基本类型与 prelude

| 类型 | 说明 |
|---|---|
| `Nat` | 自然数（0,1,2,…） |
| `Int` | 整数 |
| `Rat` | 有理数（v1 运行期为 IEEE double 近似；未来由实数/复数类型接管精确语义） |
| `Str` | 字符串 |
| `Bool` | 标准库枚举 `enum Bool { true, false }`（编译期内建注入，源码无需声明） |
| `Null` | 单值类型，即传统语言的 Unit；唯一值 `null` |
| `Nothing` | 空类型。返回 Nothing 的函数后接代码 → W-UNREACHABLE |
| `Any` | 顶类型（决策 31/59）。**使用严苛**：声明合法，但调用含 Any 参数/返回值的函数、创建/赋值含 Any 成员结构体均需 `unchecked`；涉 Any 推导失效须手动标注。`Any` 形参/字段可接受任意实参（受限顶类型） |
| `EmptyTuple` | 零元组类型（决策 62）。**无字面量**，只能 `emptyTuple()` 构造；JS 形态 `[]`。≠ `Null`：Null 是单元类型，EmptyTuple 携带元组共有函数 |
| `SingleTuple[T]` | 一元组类型（决策 62）。**无字面量**，只能 `singleTuple(a)` 构造（`(a)` 是括号表达式）；JS 形态 `[a]` |
| `Task[T]` | 异步任务（v2.0 异步 §1）。`Task { 体 }` 创建惰性任务（对象 `{ start, join, isAlive }`）；`t.start()` 启动、`t.join()` 挂起等待（@async 上下文）、`t.isAlive()` 查存活；`join` 前未 `start` → `E-NOT-STARTED` |
| `Channel[T]` | 异步通道（v2.0 异步 §3）。`Channel[T](cap)` 创建（cap=0 无缓冲）；`send`→Bool / `receive`→T?（智能转换可收窄为 T）/ `close` / `isClosed`；`close` 后 `send` → `E-CHANNEL-CLOSED` |

prelude 另有 `enum Optional[T] { None(), Some(T) }`（决策 45：None 专属 Optional）。
v2.0 异步：`main` 天然 `@async`；`@async` 函数体内调用其它 `@async` 函数为挂起点 → 自动 `await`（异步 §2/决策 93）。

**内建纯函数**：`emptyTuple(): EmptyTuple`、`singleTuple[T](a: T): SingleTuple[T]`（决策 62）。
**内建非纯函数**：`print(v): Null`（决策 27）。

**元组类型 `(T,U)`**（决策 61）与**函数类型 `(A,B)=>C` / `()=>C`**（决策 57）是结构化类型（非名义类型），不参与 `==` 结构相等的字段展开；v1 函数类型不带前后件。

## 4. 注解

`@` 前缀，紧跟声明。当前约定：

| 注解 | 目标 | 含义 | 状态 |
|---|---|---|---|
| `@mut` | var | 变量可变（JS 用 `let`），否则 `const` | ✅ 已实现 |
| `@async` | fun | 异步函数（v2.0 异步 §2）：编译为 JS `async function`；体内调用其它 `@async` 函数为挂起点 → 自动 `await`；同步函数调用 `@async` 函数报 `E-NEED-ASYNC`；`main` 天然 `@async` | ✅ 已实现（决策 93） |
| `@unpure` | fun | 显式声明非纯；纯作用域调用需 `unchecked` 或供给 `pure<f>`（决策 54） | ✅ 已实现（决策 25 曾作废后恢复，本版本为恢复后状态） |
| `@new` | impl 成员 | 声明这不是实现类方法集的函数（反向 override） | ✅ 已实现 |
| `@tuple` | 形参 | 变长参数=同类型变长元组（决策 61，取代 `@vararg`）。**只接受元组字面量实参**，裸变量需先 `(x,)` 打包；JS 里从该位起的实参打包成数组 | ✅ 已实现（第 2 轮 T4） |
| `@lazy` | var | 惰性初始化（Kotlin `by lazy` 语义） | 📋 未实现 |
| `@unsafe` | fun | 预留：内存/外部交互类危险操作 | 📋 未启用 |

未知注解 → 警告级。

**⏳ 后续可能引入**（P0 之后，未定）：
- `@pub`（成员级可见性）——P0 明确**不做**，当前全部 public

## 5. unchecked 的三种形态 与 pure 命题

```sublimation
unchecked.axiom[q]          // 命题逃逸：直接令 q 成立（law 已决议改 axiom）
unchecked print("ok")       // 纯度逃逸：调用非纯函数
unchecked counter = 1       // 可变性逃逸：写非本地/不可变状态

pure<f>                     // 上下文单参命题（决策 54）：持有它 ⇒ 编译器认为调用 f 是纯的
                            // 每个未标 @unpure 的函数自动获得 pure<name>（决策 34）
```

**逃逸语义贯通所有求值通道**（第 2 轮 T4 踩坑）：块体尾表达式、lambda 体、if 分支、when 分支体都继承 `uncheckedDepth`——`unchecked P(1)` 形式的构造在任意表达式通道内都放行。

## 6. 诊断码（各层汇总）

- 解析层：`E-PARSE`
- ✅ settings 解析层（P0）：`E-PARSE-SETTINGS`
- 类型层：`E-TYPE-MISMATCH`、`E-NON-SEALED-MATCH`（非密封 when 流向非 Null）
- 命题层：`E-PRE-UNPROVEN`、`E-POST-UNPROVEN`、`E-PROP-UNBOUND`、`E-PROP-AMBIGUOUS`、`E-DEEP-SATURATION`
- 实体层：`E-DUP-DECL`、`E-UNBOUND-NAME`、`E-IMPURE-CALL`、`E-IMMUT-ASSIGN`、`E-ASSIGN-TARGET`、`E-IMPL-INCOMPLETE`、`E-IMPL-EXTRA`、`E-IMPL-MISMATCH`
- 型类字典（决策 60，T5）：`E-NO-INSTANCE`、`E-AMBIGUOUS-INSTANCE`
- 对象与方法（决策 68/69/70，第 3 轮）：`E-NO-SELF`、`E-METHOD-ARGS`、`E-FIELD-MISSING`、`E-DUP-FIELD`、`E-DEFAULT-PARAM`、`E-MAIN-PARAMS`、提示级 `H-FIELD-SHADOW`、补充级 `D-MAIN-CALL`
- Any 准入（决策 59，T4）：`E-ANY-STRUCT`、`E-ANY-CALL`、`E-ANY-INFER`（预留）

## 8. v1 已知限制（语法侧）

**当前版本仍受限的**：

- **穷尽性不是要求**（决策 66）：判不出穷尽的 `when` 直接按默认值返回 `Null`。有覆盖律（名义枚举）却覆盖不全 → `W-NON-EXHAUSTIVE`；无覆盖律（元组/函数类型）→ 静默退化、不警告。非穷尽值流向非 Null 上下文报 `E-NON-SEALED-MATCH`。
- **元组成员访问未实现**：`t.0` / `t.length` 这类 Tuple 型类成员未接入，v1 靠 `PatTuple` 解构取分量。
- **泛型约束的字典透传未实现**：`fun f[T: Show](x: T)` 形式（P6）尚不做；只支持"无约束型类方法按实参类型查字典分发"。
- **函数命名传参未实现**（决策 41 语法糖批，P8 落地）：`f(x = 1)` 是命题等式中缀；struct 命名字段构造是另一回事（O3 已实现）。
- **函数形参默认值未实现**（决策 69）：`= expr` 只出现在 struct 字段上。
- **字符串模板未实现**（决策 41，P8 落地）。
- **语句位 `if`/`when` 展平未做**（第 5 轮候选）：`if c { return 1 }` 报 `E-RETURN-OUTSIDE`，需改写为 `return if c { 1 } else { … }`。
- **显式 return 仅函数体顶层语句位**（决策 71）：`return e` / 裸 `return` 只在具名函数/方法体块的直接语句合法；`if`/`when` 分支块、lambda 体、块当值用一律拒绝。
- **顶层只能写声明**（决策 74）：执行代码必须进 `main()` 或顶层主序列（`fun main()` 与顶层语句共存时 main 排最后）。脚本模式（类 kts）未支持。
- **函数体是独立作用域帧**（第 4 轮体检钉实）：顶层 `var` 与顶层 `unchecked.axiom` 不进函数体。
- **@unpure 函数不自动注册 `pure<name>`**（决策 34 的另一面）：`pure<side>` 类前件需调用点 `unchecked.axiom[pure<side>]` 显式供给。

**✅ P0 已落地**（多文件 + 目录即模块 + 挂载 §2.1/§2.2；`compile`/`check` 接受目录；跨模块类型引用 `c.Point`）。

**⏳ P1–P10 逐步解除的限制**：

| 阶段 | 解除 |
|---|---|
| P1 | 字符串操作（`concat` 等 7 个） |
| P2 | 集合（`Array[T]` + `List` stdlib） |
| P3 | IO（`readLine` / `readFile` / `writeFile` / `getArgs`） |
| P5 | 错误处理 `Result[T, E]` |
| P6 | 泛型约束字典透传（`fun f[T: Show]`） |
| P8 | 字符串插值 + 命名参数 |
| P9 | 递归停机判定（`E-NON-STRUCTURAL-REC`） |
| P10 | `Rat` 语义定案 |
