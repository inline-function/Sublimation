## 一之二、待执行的技术修订（无需拍板，等 P0 文档同步完后执行）

### 修-1 删除 u-系算符，源码只接受 Unicode

**背景**：`u->` / `u&` / `u|` / `u<->` / `u!=` 不是语言的一部分——它们是打不出 Unicode 时的心理替代，由语言服务在录入时替换为 `→` / `∧` / `∨` / `↔` / `¬`。**编译器不该认识它们。**

**当前误实现**：
- `lexer/Lexer.kt` 的 `uOps` 列表（5 条映射）
- `Language 语法 §1` 把 u-系与 Unicode 列为两个并列类别
- `形式化规范 §1.1` 的 u-系行
- `LexerTest.kt` 里对 u-系的断言

**改动**：
1. `Lexer.kt` 删 `uOps` 及 `readToken` 里对应的分支（`'u'` 开头的粘连识别）
2. 源码里出现 `u->` 等 → 报 `E-PARSE`（"未知符号 u->，请写 →"），或词法错误 `LexFailure`
3. `语言语法.md §1`：把 u-系从"符号表"移到"语言服务替换表"，明确**不进编译器**
4. `形式化规范.md §1.1`：合并 u-系与 Unicode 为"命题层算符（Unicode 主写法）"，删去替代写法行
5. `LexerTest.kt`：删 u-系断言，加一条"`u->` 报错"的负向测试
6. `快速上手.md`：如果提到了 u-系写法，改成 Unicode

**影响面**：小（词法器 5 行 + 4 份文档），但**越早改越好**——趁现有 `.subl` 示例还没用 u-系（我印象里没有），改动零回归。
