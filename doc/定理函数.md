# 定理函数

> 定义（与用户约定一致）：**定理是一种特殊的函数，它没有副作用、不修改参数、返回值为 Null。**

## 判据（自动登记，无注解）

一个函数是定理，当且仅当满足全部条件：
1. 没有 `@impure`；
2. 所有参数没有 `@mut`；
3. 返回类型为缺省（Null）或显式 `Null`。

满足判据的普通函数**自动**进入该模块的 `theorems` 表，供证明搜索（`searchTheorems`）使用。

```subl
// core/logic：范围下界
fun rangeLowerBound[x, l, r]: Null <x ∈ (l..r) -> x >= l>
// 无函数体 = 公理（合法）
```

```subl
// 有函数体的定理照常生成运行时代码
fun leqTrans[x, y, z]: Null <x <= y -> y <= z -> x <= z> { return null }
```

## 为什么定理也要生成运行时代码

> 不能保证定理函数内部是否有函数通过 `unchecked` 逃离检查——它可能含有无法静态保证的副作用。因此**代码生成照常进行**，不是编译期只标记。

## 定理库

- `core.logic`：`rangeLowerBound` / `rangeUpperBound` / `leqRefl` / `leqTrans` / `andLeft` / `andRight` / `andIntro` / `modusPonens` / `rangeSplitRight` / `natNonNeg`。
- `core.logic.classic`（`@classic` 标记，经典逻辑）：`tertiumNonDatur`（排中律）`<p ∨ ¬p>`、`doubleNegation`、`contraposition`。

## 与旧版的关系

历史版本曾用 `@theorem` 注解。**已废弃**：注解不存在，判据自动。文档与示例不得再使用 `@theorem`。
