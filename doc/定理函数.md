# 定理函数

> 定义（与用户约定一致）：**定理是一种特殊的函数，它没有副作用、不修改参数、返回值为 Null。**
> 定理与 `∵`/`∴` 的关系：**`∵`/`∴` 语句是调用定理的语法糖**——`∴ q` 等价于「在 Γ ∪ 定理空间里（无需定理名）找到一个实例化，得出 q」；`∵ p` 是「在上下文中成立 p」。区别：**定理函数需要定理名 + 上文（前件），不需要下文（后件）**；**`∵`/`∴` 需要上文 + 下文（目标），不需要定理名**。

## 判据：只有 `@theorem` 标注的才是定理函数

1. **`@theorem` 显式标注**（推荐）：强制登记为定理函数，并在**编译器擦除其代码**（不生成 JS）。
   - 擦除的定理只能用于**证明位**：`∴` 合一、前件供给。值级调用擦除后函数会悬空，故编译器报 `E-THEOREM-VALUE-CALL` 禁止。
   ```subl
   @theorem
   fun rangeLowerBound[x, l, r]: Null <x ∈ (l..r) -> x >= l>   // 无体 = 公理；编译器擦除
   @theorem
   fun leqTrans[x, y, z]: Null <x <= y & y <= z -> x <= z> { return null }   // 有体也擦除
   ```
> **只有 `@theorem` 标注的函数才是定理函数**（无 `@impure`、参数无 `@mut`、返回 `Null` 是定理函数的**性质**，不是判据）：未标注者即使纯+Null 也不进定理空间、不是定理，代码照常生成、可被值级调用。

## 定理搜索与合一

- `∴ q` 在 `local 定理 + 全局 theorems + 可见路径 theorems` 中，把定理**后件**与 `q` 做结构合一（theory 参数为元变量，实例化后后件 ≡ q）；深度默认两跳，超限报 `E-THEOREM-SEARCH-DEPTH`。
- 定理函数/函数体里的 `unchecked` 只影响安全检查，不改变"定理只读于证明位"的事实。

## 定理库

- `core.logic`：`rangeLowerBound` / `rangeUpperBound` / `leqRefl` / `leqTrans` / `andLeft` / `andRight` / `andIntro` / `modusPonens` / `rangeSplitRight` / `natNonNeg`（均已加 `@theorem`，编译期擦除）。
- `core.logic.classic`（`@classic` 标记，经典逻辑）：`tertiumNonDatur`（排中律）`<p ∨ ¬p>`、`doubleNegation`、`contraposition`（均 `@theorem` 擦除）。

## 与旧版的关系

历史版本曾试图**取消** `@theorem`、仅靠自动判据。现按约定**恢复且唯一化**：**只有 `@theorem` 标注的才是定理函数**（擦除代码、只供证明位）；未标注者一律不是定理。
