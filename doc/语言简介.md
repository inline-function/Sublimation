
# Sublimation（凝华）语言简介

## 定位

Sublimation 是一门把**类型系统与程序逻辑融合**的编程语言，编译目标为 JavaScript（源到源，纯文本生成，零运行时库）。它的名字取自物理现象"凝华"——气态不经液态直接成固态，正如本文的命题不经运行时、直接在编译期析出为程序的静态保证。

形式化内核见同目录《上下文系统》：函数类型不仅描述参数与返回值，还携带**前置命题（上文）与后置命题（下文）**，即"调用前必须满足什么、调用后能保证什么"写进类型本身。

Sublimation 的上下文系统，本质是 Kotlin 智能转换的泛化。Kotlin 让编译器在 if (x is T) 分支内知道 x 的类型；Sublimation 让编译器在任何语句结构里吸收任何命题——var 声明吸收值和类型，if/when 分支吸收条件和约束，函数调用吸收后件。用户写普通代码，编译器自动推理；只有需要接口保证时才写前后件，只有推理失败时才用 unchecked.axiom。

## 核心特性：上下文弥散

命题像气体一样在作用域里弥散，不需要显式传递：

```sublimation
fun test1(): Null <p> { unchecked.axiom[p] }   // 下文给出 p
fun test2()<p>: Null {}                         // 上文要求 p

fun main() {
    test1()          // 调用后 p 弥散进作用域
    test2()          // 编译期在作用域中检索到 p，通过
}
```

`p = test1(); test2<p>` 这种写法不必要也不可取：命题不是值，显式传递会绕开类型层的静态推理。

命题有三个成立来源：

1. **直接证明**：`unchecked.axiom[q]`（不受检操作，令 q 直接成立）；
2. **下文给出**：函数后文中携带某命题的命题，如 `testProof` 的下文 `q<p>`；
3. **调用弥散**：函数上文被自动从当前作用域供给，调用结束后下文注入作用域。

供给是自动的；只有当作用域同时存在 `p<1>` 与 `p<2>` 这类歧义时，编译器报错并要求调用点显式指定。

## 语言立场

- **没有修饰符，全部是注解**。变量/函数注解小写开头，可复用变量的注解尽量短（`@mut`、`@lazy`），变长参数用 `@tuple`（同类型变长元组，取代早期设想的 `@vararg`），仅函数可用的不设长度要求（`@new`）。
- **纯度受控**。函数默认且只能为纯；禁止调用非纯内建、禁止写外部变量，除非用 `unchecked` 前缀逃逸：`unchecked print("ok")`、`unchecked counter = 1`。`unchecked.axiom[q]` 与 `unchecked` 是同一个逃逸关键字的两种形态（`@unpure` 已作废）。
- **一切运算符皆函数**。标识符可用符号（仿 Scala），`1 + 1` 等价 `+(1,1)`，二元函数即可中缀。不设优先级，从左到右结合；`1 + 1 * 1` 就是 `(1+1)*1`，语言服务会提示显式加括号。
- **数值类型不用浮点术语**：`Nat`（自然数）、`Int`（整数）、`Rat`（有理数）。v1 的 `Rat` 运行期本质是 IEEE double（换名不改实质），为的是给后续**不丢精度的实数、复数**类型腾出命名与语义空间。
- **布尔是枚举不是关键字**：`enum Bool { true, false }`，`true/false` 只是构造子；消费用 `if` 与 `when`——`when` 是**真模式匹配**（解构、嵌套、守卫、穷尽性判定），Java 式 switch 已全盘废弃。
- **类型类用 Haskell 的拼写、Rust 的机制**：`class` ≈ trait，`impl Show for Int { ... }`，`impl` 中成员默认必须实现类中方法，新增方法要显式标 `@new`（override 的反向操作）。方法调用按实参类型解析**型类字典**分发（决策 60，取 Kotlin 式便利而非 Rust 级单态化）。
- **命题层优先 Unicode**：`∀ ∃ ∃! ∧ ∨ ¬ → ↔ ⊤ ⊥`；`forall exists exists1 not` 保留为 ASCII 别名；语言服务负责把别名补全成 Unicode 字符。
- **顶层只声明，执行代码进 `main()`**（决策 74）。文件顶层只允许 `fun`/`class`/`struct`/`enum`/`impl`/`type` 与注解，任何执行语句一律进具名 `fun main()`；编译器自动追加 `main();` 调用（决策 70）。凝华脚本模式（类 `.kts`）是将来特性，当前语法层直接拒绝。
- **目录即模块，显式挂载**（决策 76，P0）。一个目录 = 一个模块；同模块内文件共享符号表；父→子可见且传递，子→父不可见，兄弟默认不可见，靠 `<模块名>.settings` 里的 `mount` 建立。**impl 也要挂载**——这是"显式装配"不是"隐式发现"。

## 编译器分级

| 级别 | 含义 | 例 |
|---|---|---|
| 错误 | 写错了，无法编译 | 没有证明命题；纯函数调用非纯函数；不可见模块的符号引用 |
| 警告 | 能编译但大概率出问题 | 返回 `Nothing` 的函数后还有代码；字面量含 `/0`；名义枚举 when 覆盖不全 |
| 提示 | 可能出问题，建议修改 | 易混淆的运算符结合，建议显式括号；`$1` 可直接写参数名 |
| 补充 | 没问题，编译器补充信息（默认不输出） | 某变量被推导为某类型；某类型参数被解出为某类型 |

## 编译管线

```
源码根目录 ─┬─ 目录扫描（模块树 + settings 挂载图）
            │
.subl 源码 → [词法] → [语法] → [语义分析：Γ 弥散 + 饱和 + 合一 + 模块可见性过滤]
            │
            └→ [JS 代码生成：零成本擦除 + 模块名 mangle] → node 直接运行
```

单文件模式仍受支持（向后兼容）：直接给 `.subl` 文件路径即可，不触发模块树扫描。目录模式是 P0 引入的多模块入口：`compile <目录> -o out.js`。

全部手写，零第三方依赖。

## 模块系统（P0）

```
/                          ← 唯一根模块（编译入口目录）
├── main.subl              ← 属于根模块 /
├── project
│   ├── project.settings   ← 挂载声明
│   ├── main.subl
│   ├── data/
│   │   ├── stringData.subl
│   │   └── numberData.subl
│   └── processor/
│       ├── formatter.subl
│       └── printer.subl
├── core
│   ├── core.settings
│   └── math.subl
└── other
```

要点：

- **可见性**：父→子可见（传递）；子→父不可见；兄弟默认不可见；根 `/` 看所有后代，**后代看不到根模块**（根只是入口容器）。
- **挂载**：`project/project.settings` 里写 `mount core`（绝对路径）或 `mount core as c`（别名）。挂载是**传递的**——`project` 挂 `core`、`core` 挂 `foo` → `project` 能访问 `foo`。
- **引用路径相对当前模块视角**：挂载后 `project/main.subl` 和 `project/data/leaf.subl` 引用 core 都写 `core.math.gcd`，不写外层前缀。
- **impl 装配**：`d` 想用 `c` 里的 `impl Show for Point`，**必须挂载 `c`**；不挂载报 `E-NO-INSTANCE`，多源报 `E-AMBIGUOUS-INSTANCE`，环报 `E-CIRCULAR-MOUNT`。
- **codegen mangle**：根模块无前缀（`greet`）；非根模块加模块路径前缀（`core/math.subl` 的 `gcd` → `core__gcd`，深层 `core/math/extra.subl` 的 `deep` → `core_math__deep`）；字典名同前缀（`dict_core_Show_Point`）。
- **main 唯一且可跨模块**：`main` 可位于任意模块，全树唯一；codegen 扫全树找到它，产物末尾追加调用，**不走可见性检查**（特殊通道）。

## v1.0 文档债（压测报告 §4 提出，非阻塞）

- **布尔逻辑用单符号 `|`（或）与 `&`（与）**——不是 `||`/`&&`（`&&`/`||` 会 lexer 报错；`&` 的产物是短路 `&&`，语义正确）。
- **`charAt` 越界返回 `""`**（JS `[...] ?? ""`）；对空串做 `strCmp >= 0` 会得 true（`strCmp("", "0") = -1`）——判字符请用 `==(c, "0")` 字面量比对或先判 `!=(c, "")`。
- **`concat` 恰好两参**；长串拼接用 P8 插值（`"a=$x b=${y}"`）。
- **`==`/`!=` 禁止中缀**（防与命题混淆），值位比较写前缀 `==(a, b)` / `!=(a, b)`。
