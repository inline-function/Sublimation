## 决策 93—99：v3.0 第一批七个特性

| # | 特性 | 决策 |
|---|---|---|
| 93 | 结构体伴生命题 | struct 后 `<…>` 为伴生命题；构造前置证明（E-STRUCT-PROP-UNPROVEN）；成功后注入字段等式与命题；禁止引用 @mut 字段（E-STRUCT-MUT-PROP）；传参自动注入等价于函数签名后件 |
| 94 | impl 委托 | `impl C for T by field` 展开为对 C 每个方法生成 `m() = a.m()`；a 必须为字段名（E-BY-UNBOUND）；不检查字段类型（E-BY-TYPE 可选未做，同特性 2 原状）；转发查表走运行时 dict |
| 95 | `..` 返回 Range | `..` 返回惰性 `Range[Int]`（非 List）：不预生成元素、in 为 O(1) 闭区间、map/fold 迭代式、toList 具体化；`Range[T]` 为内建类型 + 运行时 `__range` 注入（v3.0 第二个运行时组件） |
| 96 | 默认实现 + 受限自动类型类 | 类方法可带体=默认实现；impl 缺方法且类有默认实现则补齐（E-IMPL-INCOMPLETE 仅当类无默认）；自动类型类仅编译器预定义（`Any` 列入受限集合，身份维持"类型"（Q1 裁定）） |
| 97 | ∵/∴/+∵ 语句 | 语句位纯证明零代码；∵ 优证（proveOrDeep+定理）后信任留痕（D-BECAUSE-TRUSTED）；∴ 用 proveOrDeep+定理合一搜索，失败 E-CANNOT-PROVE（错误消息列出尝试的定理+当前 Γ）；连续 ∴ 自动累积；@theorem 函数无体合法，登记进定理空间；V1 搜索深度为单跳合一（E-THEOREM-SEARCH-DEPTH 码与两跳护栏已备，留作 by solve 加深钩子）；普通函数不参与搜索 |
| 98 | if[p] 排中律 | `if[p]` 语句位纯证明；需挂载 core.classic —— 挂载方式裁定为**注解声明式**：文件内任一声明带 `@classic` 即挂载，否则 E-NEED-CLASSIC；then+=p / else+=¬p；两支 ∴ 结论集须相同（E-IF-CONCLUSION-MISMATCH）；块外 Γ+=结论合取；零运行时代码 |
| 99 | 量词 | ∃ 引入 `∃ x = t . P(x)`：替换证明后注入；∃ 消去 `∃ x . P(x) { }`：前提在 Γ（E-PROP-UNBOUND），块内注入 x 与 P(x)，结论用 ∴ 显式（Q5 裁定），块外合取；∀ 引入=局部函数定义（必须有体），登记为局部定理（形参=绑定变元，并入合一 vars）；∀ a => t. P 语法不做（Q4 裁定）；V1 局部函数不生成 JS 值代码 |

## 实现偏差记录（v3.0 第一批）

- **特性 5**：V1 定理搜索为单跳合一（postUnifies 结构合一），E-THEOREM-SEARCH-DEPTH 码存在但当前仅 depth=0 调用不可达，留作 by solve 加深钩子。
- **特性 6**：core.classic 挂载以 `@classic` 注解声明（规格未定挂载语法，自定并留档）；结论比对基于渲染等价。
- **特性 7**：∃ 消去前提匹配要求绑定名一致（V1）；∀ 引入的局部函数不生成 JS 值代码（纯证明角），其体不静态检查（仅要求非空）；∀ 消去经局部定理合一实现（helper 形参作绑定变元）。
- **特性 2（沿用）**：E-BY-TYPE 可选未做；转发体为 checker 合成，共享 delegatedImpls 持久化。

## 实现偏差记录（v3.0 第三批）

- **4.2**：Collection impl 成员体用 when 解构递归（非转发自由函数），字典递归随子结构递减终止；impl 体内 `self.contains(x)` 生成字典自调用，故 impl 体递归用解构变量（如 t.contains(x)）保持结构递归检查通过。
- **4.3**：EmptyTuple/SingleTuple 具名类型与构造（emptyTuple()/singleTuple(a)）T3 已落地；本轮补 Tuple 型类 impl 与元组占位匹配；二元/三元元组无分量下标访问语法（p.0 不支持），元组值访问走解构。
- **funRef 修复**：方法路径作值（`xs.map`）改用 jsOverloadName 带重载首参标签（stdlib__map$List），修复 stdlib 重组后重载组 funRef 绑定 JS 未定义。
