## 1. 文法摘要

```
file    ::= entry (';' entry)*                      顶层只能声明（决策 74）⟨实现⟩
          # 入口：具名零参 `fun main()`（自动调用，决策 70）⟨实现⟩

entry   ::= decl
decl    ::= '@' IDENT* 'fun' n [th] (ps) '<ps₁>'? (: T)? '<ps₂>'? ('=' e | block)
          # 体两形态互斥（决策 73）：`= 表达式` 或 `{ 语句… }`；`= {…}` 报错 ⟨实现⟩
          # `class` 成员是无体签名，不接块体（决策 68）⟨实现⟩
          | 'class' n [th] '{' funSig (';' funSig)* '}'
          | 'impl' T 'for' T '{' funDecl (';' funDecl)* '}'
          # impl 方法带隐式 self（决策 68）：签名不写接收者，体帧先注入 self 与自类型字段 ⟨实现⟩
          | 'struct' n [th] '(' fs ')'                圆括号体（决策 69）⟨实现⟩
          | 'enum' n [th] '{' ctor (',' ctor)* '}'
          | 'type' n [th] '=' T                        类型别名（决策 30）⟨实现⟩
th      ::= '[' (n (':' n)? | '@' n)* ']'             类型参数 / 命题参数
ps      ::= n ':' T                                   形参（默认值禁止，决策 69）⟨实现⟩
fs      ::= n ':' T ('=' e)?                          struct 字段可带默认值（决策 69）⟨实现⟩
stmt    ::= 'var' n (: T)? '=' e | postfix '=' e | 'return' e?
          | 'unchecked' ['.' 'axiom' '[' ps ']' | stmt]
          | 'by' '[' ps ']' | block | expr

# ---- 模块（P0，决策 76）----
root    ::= module ('/' module)*                      目录即模块；根 = 编译入口目录 ⟨P0⟩
module  ::= DIR                                       一个目录 = 一个模块 ⟨P0⟩
          | FILE.subl                                 同模块内所有 .subl 共享符号表 ⟨P0⟩
          | SETTINGS                                  `<模块名>.settings`，声明挂载 ⟨P0⟩
SETTINGS::= ('mount' ABS_PATH ('as' IDENT)?)*         路径绝对（从 / 起）；别名可选 ⟨P0⟩
```

表达式核心：名字（含符号名）、字面量、应用 `f(args)`、实例化 `p<ts>`（紧贴 `<`）、供给 `f<props>(args)`、中缀（无优先级左结合）、`if`、`when`（真模式匹配）、λ、`unchecked` 前缀、`unchecked.axiom[ps]`、元组字面量 `(a,b)`、`var`/`fun` 作为表达式（声明皆表达式，A3）。

**跨模块引用**（P0，决策 76）⟨P0⟩：

```
qualified ::= IDENT ('.' IDENT)*                      点号限定路径
            # 从当前模块的可见集合里找起点名字，剩下的按路径走；
            # 类型名同样支持（c.Point）
```

### 1.1 命题层算符

| 类别 | 记法 | 说明 |
|---|---|---|
| 命题等式 | `e₁ = e₂`（中缀） | 纯命题，编译期概念，不代表运行时相等 ⟨实现⟩ |
| 类型事实 | `e : T`（中缀） | 既是命题也是智能转换 ⟨实现⟩ |

## 2. 类型系统

`Type` 是 **sealed interface**（第 2 轮 T1，决策 57/65）：`NamedType(name, args)` / `FunType(params, ret, purity)` / `TupleType(items)`。兼容层把 `name`/`args` 做成计算属性（`FunType` → `(fn)`、`TupleType` → `(tuple)`），名义性判定一律走 `isNominal()`（要求 `NamedType` 且首字母大写）。**I-15**：哨兵名不与用户类型比较。

```
T ::= Nat | Int | Rat | Str | Bool | Null | Nothing | Any
    | EmptyTuple | SingleTuple[T] | Array[T]             基本类型 ⟨实现⟩
    | n | n[T,...]                                      名义类型/参数 ⟨实现⟩
    | (T,...,T) => T                                    函数类型 ⟨实现⟩（T2）
    | (T,...,T)                                         元组类型 ⟨实现⟩（T3）
    | [th] (T,...)<props> => T <props>                  完美匿名函数 ⟨目标⟩（决策 57）
```

### 2.1 基本类型

| 类型 | 语义 | 状态 |
|---|---|---|
| `Nat` / `Int` / `Rat` | 数值偏序 `Nat ⊆ Int ⊆ Rat`，由推导器做 join（I-10） | ⟨实现⟩ |
| `Str` | 字符串 | ⟨实现⟩ |
| `Bool` | 枚举 `{ true, false }`，prelude 注入 | ⟨实现⟩ |
| `Null` | 单值类型（Unit 职责），唯一值 `null` | ⟨实现⟩ |
| `Nothing` | 空类型；后接代码 → `W-UNREACHABLE` | ⟨实现⟩ |
| `Any` | 受限顶类型（决策 59）：可承载任意值但**推导失效须手动标注**；含 Any 成员结构体禁直接构造、调用涉 Any 受限，一律需 `unchecked` | ⟨实现⟩ |
| `EmptyTuple` | 零元组；**无字面量**，只能 `emptyTuple()` 构造（决策 62） | ⟨实现⟩ |
| `SingleTuple[T]` | 一元组；**无字面量**，只能 `singleTuple(a)` 构造 | ⟨实现⟩ |
| `Array[T]` | 内建数组（P2） | ⟨P2⟩ |

### 2.2 结构化类型

- **函数类型** `(A,B)=>C` / `()=>C`（T2，决策 57）：**结构化**，非名义类型，不参与型类 `impl` 匹配；v1 不带理论参数与前后件。
- **元组类型** `(T,U)`（T3，决策 61）：结构化；JS 形态为数组。

### 2.3 类型推导器

职责：
- 变量类型推导 ⟨实现⟩；
- 泛型解出（具名函数调用）⟨实现⟩；
- 函数类型 `(A,B)=>C` 标注（lambda 实参双向推导）⟨实现⟩（T2）；
- **真正的合一算法**（类型变量求解、`occurs check`、泛型实参反推）⟨P7⟩。

v1 兜底：**名义相等 + 数值 join + synthetic 放行**。

### 2.4 型类

- `class C[T] { fun m(x:T):R }` 声明方法签名集合；成员**无接收者参数**（隐式 self，决策 68）⟨实现⟩。
- `impl C for τ { fun m(...):R = ... }` 提供实现；成员默认必须实现类方法，新增方法须 `@new`（决策 7）⟨实现⟩。
- 方法调用按实参类型解析**型类字典**（决策 60，推翻单态化）：在 impl 表找唯一匹配实例，零匹配 `E-NO-INSTANCE`、多匹配 `E-AMBIGUOUS-INSTANCE` ⟨实现⟩。
- 字典名以 impl 声明的**自类型**为准（数值提升下实参类型可能不同）：`dict_<Trait>_<Type>` ⟨实现⟩；模块前缀在 P0 后升级为 `dict_<mangled_module>_<Trait>_<Type>` ⟨P0⟩。
- **类约束 `T : C` 与命题参数同构**（决策 20）：`Show[Int]` 是可弥散的命题事实 ⟨P6⟩。

## 3. 弥散语义（Γ 系统）

Γ 为作用域内命题事实的多重集，条目 ::= 命题（`p`、`n<ts>`、`e = e'`、`e : T`、`∀x.p`、`p -> q`、伴生记录 `f<args>`、`pure<f>` …）。

### 3.1 规则

```
(var)   Γ ⊢ e : T   Δ 新鲜   e 为纯值表达式
        ───────────────────────────────────────
        Γ ⊢ var n = e ⇒ Γ ∪ {n = e, n : T}              ⟨实现⟩
        # @mut 变量仅保有自反相等，非自反等式论据忽略（决策 35，I-9）⟨实现⟩

(test)  Γ ⊢ n : T 相容
        ─────────────────────────────
        Γ ⊢ (n : T) ⇒ Γ ∪ {n : T}                       智能转换 ⟨实现⟩

(axiom) ----------------------------------
        Γ ⊢ unchecked.axiom[q] ⇒ Γ ∪ {q}                信任承诺（决策 5）⟨实现⟩

(call)  Γ ⊢ f : [th](τs)⟨ps₁⟩ ⇒ T⟨ps₂⟩
        Γ ⊢ args : τs[θ,β]   Γ ⊢* ps₁[θ,β]
        ──────────────────────────────────────────────────────────
        Γ ⊢ f(args) ⇒ Γ ∪ {ps₂[θ,β][$/= call], f<args>}
        # 其中 θ = 类型参数解，β = 命题参数绑定（决策 4：显式 <props> 或 0 元自动供给；歧义 → E-PROP-AMBIGUOUS）
        # 下文注入与伴生记录**共存**（决策 55）：前者用于直接使用，后者用于推理"参数被调用过"⟨实现⟩

(body)  Γ₀ = {形参: 类型, 形参存在性事实} ∪ 上文 ∪ {约束事实 T:C}
        Γ₀ ⊢ body : T ⇒ Γ₁
        Γ₁ ⊇ 下文[$ := 末表达式]                        $ 指代规则见 §3.3
        ───────────────────────────────────────
        fun ... <ps₂> = body 合法                        证明义务 ⟨实现⟩

(if)    Γ ⊢ c : Bool
        Γ ∪ {c = true}  ⊢ then
        Γ ∪ {c = false} ⊢ else
        ────────────────────────
        Γ ⊢ if c { then } else { else } : join(τ_then, τ_else)  ⟨实现⟩

(when)  Γ ⊢ e : T
        每个分支 armᵢ：Γ ∪ {¬p₁, …, ¬p_{i-1}} ∪ {pᵢ} ⊢ armᵢ.body : τᵢ
        # pᵢ 是分支命题：字面/构造子 → ∃绑定. subj = pat；is T → subj : T；else/_ → ⊤
        ────────────────────────────────────────
        Γ ⊢ when e { arm₁; …; armₙ } : join(τ₁, …, τₙ) 或 unsealedT  ⟨实现⟩
        # 穷尽性 = Γ ⊢* p₁ ∨ … ∨ pₙ（决策 43）
        # 不密封 → 值类型退化为带标记 Null（决策 49/66）；流向非 Null 报 E-NON-SEALED-MATCH
```

### 3.2 作用域

- **语句序列线性推进**：`Γ_{i+1} = saturate(Γ_i ∪ 注入(语句ᵢ))`。
- **块事实回溢父帧**（弥散）；**lambda 体、函数体隔离**。
- **函数体是独立帧**：顶层 `var` 与顶层 `unchecked.axiom` 不进函数体（决策 72 体检钉实）⟨实现⟩。
- 内层作用域继承外层；**内层命题不外溢**（除块回溢约定外）。

### 3.3 `$` 与返回值指代

- **体内**：`$ ≡ 末表达式`；若体内有**唯一带值的 `return e`**，`$ := e`（决策 71）⟨实现⟩。
- **调用注入**：`$` 替换为**实际调用表达式**——`var y = f(x)` 时，下文 `<$ : Nat>` 注入的是 `f(x) : Nat`（而非 `y : Nat`，决策 33）⟨实现⟩。
- 多路/裸 `return` 无法归一为单一项 → 保守取尾表达式或 `null`（决策 71：禁止猜测）⟨实现⟩。

### 3.4 纯度与可变性

- 函数**默认纯**；`@unpure` 标非纯（决策 25）。
- **`pure<f>` 是上下文单参命题**（决策 54）：持有它 ⇒ 编译器认为调用 `f` 是纯的。
- 每个**未标 `@unpure`** 的具名函数 / impl 方法，编译器自动注册 `pure<name>` 进全局事实 ⟨实现⟩。
- **@unpure 函数不自动注册 `pure<name>`**：`pure<side>` 类前件需调用点显式 `unchecked.axiom[pure<side>]`（决策 72）⟨实现⟩。

### 3.5 模块可见性（P0，决策 76）

```
visible(M) ::= 后代(M) ∪ ⋃_{T ∈ mount(M)} visible(T)     递归传递，禁止成环 ⟨P0⟩
              # 根模块 / 能看所有后代；后代**不能**看根模块
              # 兄弟默认不可见，靠挂载建立

lookup(name, M) ::= 名字解析时，只在 visible(M) 的符号表里查 ⟨P0⟩
dict_lookup(方法名, 实参类型, M) ::= 只在 visible(M) 里的 impl 中查 ⟨P0⟩
```

**规则**：
- **同模块内**：完全互相可见。
- **父 → 子**：可见，且**传递**（父看任意深度的后代）。
- **子 → 父**：不可见。
- **兄弟 → 兄弟**：默认不可见；通过**挂载**建立。
- **后代 → 根模块**：不可见（子→父规则的特例）。根模块里的函数**不能被子模块引用**——设计意图（根是入口容器）。**例外：`main` 函数**（codegen 扫全树，不走可见性检查）。
- **impl 装配**：`d` 想用 `c` 里定义的 `impl Show for Point`，**必须挂载 `c`**（"显式装配"，非"隐式发现"）。同一条 impl 通过多条挂载路径到达则**按绝对路径去重**；不同 impl 同时可见报 `E-AMBIGUOUS-INSTANCE`。
- **挂载链**：可多父，引用式（不复制代码），按**绝对路径**唯一标识。
- **循环**：挂载链成环 → `E-CIRCULAR-MOUNT`。
- **引用路径**：相对当前模块视角——从 `visible(M)` 里找起点名字，剩下按路径走。挂载后**不写外层模块前缀**（`project` 挂载 `core` 后写 `core.math.gcd`，不写 `project.core.math.gcd`）。

## 4. 自动定理证明器 ⊢*

可判定片段上的正向演算，**健全但不完备**——不承诺证明一切，证不出的用 `unchecked.axiom` 手动补。

### 4.1 饱和闭包（不动点，≤3 轮）

1. **合取分解、双否消去** ⟨实现⟩
2. **`∀x.p` 单名实例化**：候选项 = Γ 的 ground 项 ∪ **目标项**（I-7）⟨实现⟩
3. **前向链接 modus ponens**：`p ∈ Γ` 且 `p → q ∈ Γ` ⇒ 加入 `q` ⟨实现⟩
4. **蕴含前件匹配**（目标侧 `p→q`：`Γ ∪ {p} ⊢ q`）⟨实现⟩
5. **矛盾检测** `p ∧ ¬p → ⊥` ⟨实现⟩

### 4.2 目标判定

- **语法同一** ⟨实现⟩
- **`=`/`==` 自反律** ⟨实现⟩
- **`∃` 单见证**（单名，候选同上）⟨实现⟩
- **`∨` 子集**（方向受限，I-6）：事实的析取子项 ⊆ 目标的析取子项 ⇒ 成立 ⟨实现⟩
- **`⊥` 爆炸**：Γ 含 ⊥ 则一切可证 ⟨实现⟩
- **`PImp` 前件/后件匹配** ⟨实现⟩
- **构造子单射** `C<a> = C<b> → a = b`（`Prop.injective`）⟨实现⟩
- **α-等价**（`PropLogic.alphaEq`，I-5）⟨实现⟩
- **等式对称** `a=b ⊢ b=a` ⟨实现，P4⟩：并入等式图 BFS——无向边天然含对称
- **等式传递** `a=b, b=c ⊢ a=c` ⟨实现，P4⟩：以 Γ 的 `=`/`==` 事实建无向图，BFS 判两端连通（有界 O(V+E)，不递归）
- **等量代换（浅层）** `a=b, p<a> ⊢ p<b>` ⟨实现，P4⟩：目标侧重写一次（目标 PAtom 顶层项与某等式端点结构相等才替换），只在目标侧、不动事实库、`d+1` 参与深度上限；**不连锁代换**（I-24）
- **类型事实的等式推理** `e:T, e=e' ⊢ e':T` ⟨实现，P4⟩：目标 `e':T` 时找 `e:T` 且 e≍e'（等式图连通）
- **证明路径环剪枝**（P4 附属）：同一目标在证明路径上重现（X→…→X）即剪枝——等量代换双侧替换会产生 `=<f(5),5>↔=<x,5>` 横跳，visited 集合防震荡，兼作整体探索剪枝

### 4.3 具体实现位置与深度上限

`Prover`：`maxRounds=3` / `maxDepth=6`；超限 → `E-DEEP-SATURATION`。P4 起：`proves` 入口**一次性预提取** `=`/`==` 事实（`eqs`）供整次证明共享（每个目标不再重扫全部事实）；`proveWithSubst` 先做**端点预筛**（目标项不落在任何等式端点上直接失败）。

### 4.4 明确不做（v1 边界）

- 算术推理（`abs ≥ 0`、`n < 0 → n ≠ 0` 全不可证）⟨P4 后仍不做⟩
- 多名字量词 `∀x,y. p<x,y>`（当前 `names.size != 1` 直接跳过）⟨目标⟩
- `∃!` 唯一性（只解析不推理）⟨P4 后仍不做⟩
- 完整 `∨`/`¬`/`→` 待证侧引入规则 ⟨目标⟩
- **等式合同闭包全量**（递归等量代换、不动点）——P4 只做**浅层**（I-24）
- 类型无关的项合一

## 5. 实体语义

| 规则 | 诊断 | 状态 |
|---|---|---|
| **函数默认纯**；`@unpure` 标非纯；纯作用域调非纯需 `unchecked` 或供给 `pure<f>` | `E-IMPURE-CALL` | ⟨实现⟩ |
| **变量默认不可变**；`@mut` 才可赋值；`unchecked` 逃逸 | `E-IMMUT-ASSIGN` | ⟨实现⟩ |
| **impl 完整性**：成员默认必须实现类方法；额外函数必须 `@new` | `E-IMPL-INCOMPLETE` / `E-IMPL-EXTRA` | ⟨实现⟩ |
| **签名匹配**（类型参数代入后名义相等） | `E-IMPL-MISMATCH` | ⟨实现⟩ |
| **构造子/结构体应用**实参数与类型 | `E-TYPE-MISMATCH` | ⟨实现⟩ |
| **声明皆表达式**：`var n = 0` 的值为 0，可嵌套 `var n = var m = 0`；匿名函数 `fun _`（决策 A3） | ⟨实现⟩ |
| **`when(e){pat -> e}`** 真模式匹配：字面量、构造子解构（含嵌套）、元组解构、`is T [as x]`、`_`、`else`、守卫 `if`、绑定主题 `when(var e = 0)`；穷尽性 = 分支命题**析取**可证（决策 43；覆盖律按主题类型递归深展开，与分支命题 ∃ 形态同构，决策 64）；**穷尽是提示不是要求**（决策 66）：非穷尽 → 值退化为 `unsealedT`；有覆盖律覆盖不全 → `W-NON-EXHAUSTIVE`，无覆盖律 → 静默退化；流向非 Null 报 `E-NON-SEALED-MATCH` | ⟨实现⟩ |
| **型类字典解析**：方法调用按实参类型在 impl 表找唯一实例；零/多匹配分别报错；字典名以 impl 声明自类型为准，codegen 把 `impl` 生成字典对象、命中调用生成分发 | `E-NO-INSTANCE` / `E-AMBIGUOUS-INSTANCE` | ⟨实现⟩（决策 60/65） |
| **隐式 self**：impl 方法不写接收者参数，体帧先注入 `self : 自类型` 与结构体各字段；形参遮蔽字段合法、发提示 | `H-FIELD-SHADOW` | ⟨实现⟩（决策 68，O2） |
| **接收者调用糖**：`o.m(args)` 与 `m(o, args)` 双形态等价；点号位**字段优先**（函数值字段不被同名方法截胡），否则按型类方法解析字典；字典留痕按调用点实例记录（`IdentityHashMap[CallExpr, String]`，I-18） | `E-NO-SELF` / `E-METHOD-ARGS` | ⟨实现⟩（决策 68，O2） |
| **struct 字段默认值与两种构造**：`struct A(name: Str = "u")`；位置式可缺省尾部（须有默认值，否则 `E-FIELD-MISSING`），命名字段式 `A(name = e)` 是独立 AST 节点 `StructCtorExpr`（`E-DUP-FIELD`/`E-UNBOUND-NAME`）；默认值**只属于字段**，函数形参带 `=` 报 `E-DEFAULT-PARAM` | ⟨实现⟩（决策 69，O3） |
| **main 入口**：具名零参 `fun main()` 自动作为入口调用，与顶层主语句共存（main 排最后）；带形参/类型参报 `E-MAIN-PARAMS` | ⟨实现⟩（决策 70，O4） |
| **`Any` 严苛准入**：含 Any 成员结构体禁直接构造；调用涉 Any 受限；均需 `unchecked` 逃逸（逃逸语义贯通语句/表达式/块体尾/lambda 体/if 分支全部通道） | `E-ANY-STRUCT` / `E-ANY-CALL` | ⟨实现⟩（决策 59/65） |
| **`@tuple` 形参**：变长参数=同类型变长元组，只接受元组字面量实参；JS 里从该位起打包成数组 | `E-TUPLE-VARARG` | ⟨实现⟩（决策 61/65） |
| **`$n` 参数引用**：具名函数上/下文里指第 n 个形参，声明期归一为参数名并提示；体内禁用 | `E-PARAM-REF` / `E-PARAM-REF-IN-BODY` / `H-PARAM-REF` | ⟨实现⟩（决策 58/65） |
| **显式 return**：`return e` / 裸 `return` 仅具名函数/方法体块的**顶层语句位**合法（一次性令牌，决策 71 + I-19）；嵌套 if/when 分支块与 lambda 体报 `E-RETURN-OUTSIDE`；带值核对声明返回类型（`E-RETURN-TYPE`）、裸形要求 Null 函数；return 后语句 `W-UNREACHABLE`；`$` 指代认唯一带值 return | ⟨实现⟩（决策 71/75） |
| **顶层只声明**（决策 74）：执行代码进 `fun main()` | `E-PARSE` | ⟨实现⟩ |
| **函数体两形态互斥**（决策 73）：`= 表达式` 或 `{ 语句… }`；`= {…}` 报错 | `E-PARSE` | ⟨实现⟩ |
| **Nothing 后接代码 / 字面量除零** | `W-UNREACHABLE` / `W-DIV-ZERO` | ⟨实现⟩ |

### 5.2 错误处理（P5，待拍板）⟨P5⟩

- **候选 A**：`enum Result[T, E] { Ok(T), Err(E) }`（Max 倾向）
- **候选 B**：`Result` + `?` 传播运算符
- **候选 C**：异常 / 代数效应（依赖决策 56，v1.0 不做）

### 5.3 递归停机（P9）⟨P9⟩

- 纯函数自递归要求实参为某形参的**语法子项**（决策 44，Lean 风格）
- 不满足 → `E-NON-STRUCTURAL-REC`（报错/警告待 P9 拍板）
- 逃逸：`unchecked` 前缀
- 非纯函数（`@unpure`）不受约束
