## 本轮已落地

### 和类型（联合类型 `A | B`）*新增*
- `Str | Nat` 内联联合类型（无 tag 形态，运行值即原生 JS：string/number，零包装）。
- `if(o ? Str)` 类型测（原已支持）现在具备**智能收窄**：then 分支 o 按 Str、else 分支 o 反收窄为剩余变体 Nat（`print(o + 1)` 可算）。
- Kotlin 风格 `when(o) { is Str -> …; is Nat -> … }` 类型匹配分支：分支内收窄 + **else 反收窄** + is 覆盖全部变体判**密封穷尽**（无 else 也可作表达式）；`is T` 须命中联合变体否则 E-TYPE-MISMATCH。
- 调用纪律：联合形参实参须命中某变体（`test(true)` → E-TYPE-MISMATCH: Bool 与 Str | Nat 不符）。
- 设计说明：**枚举本就是和类型**（tagged union：构造子即 tag，Optional/Result/List 都是），`A | B` 是内联无 tag 形式——两者都是和类型，语法形态不同。
