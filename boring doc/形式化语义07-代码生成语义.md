# 形式化语义 07 · 代码生成（JavaScript）语义

> **一句话**：代码生成是**源到源**的纯语法变换（JsCodeGen，不读符号表）——命题层零成本擦除、值层映射到原生 JS；顶层名字按模块前缀 mangle 后合并成**单个** JS 文件。本卷给出翻译判断式，并钉死三条既定边界：__dc 对函数值**穿透**、unchecked 只留 `// unchecked` 注释后透传、@theorem 编译期整体擦除（调用 → null）。

## 1. 生成模型总则

### 1.1 程序级判断式

合并编译（M8，MultiModule.generateJs，MultiModule.kt:150-197）把全部模块单元交给同一个 JsCodeGen 实例：

$$\frac{\text{units} = [(p_1, f_1) \ldots (p_n, f_n)] \qquad p_i = \text{模块 absPath（根} = \epsilon) \qquad \text{各单元声明按序翻译} \qquad \text{StmtEntry 汇成主序列}}{\textsf{compile}(\text{units}) = \text{"use strict"} \oplus \text{IIFE}\big(\text{prelude} \oplus \text{按需运行时} \oplus \text{声明}_1 \oplus \cdots \oplus \text{声明}_n \oplus \text{主序列} \oplus \text{main()}\big)} \quad (\text{G-PROG})$$

- 产物外层是 `(() => { … })();`，顶部再前置 `"use strict";`（JsCodeGen.kt:418-420）——顶层名字全部封在 IIFE 作用域内，不污染全局。
- prelude **恒生成**：`None`/`Some` 工厂（:272-273）、`__dshtoStr`（枚举纯 tag 对象取 tag 名成串，:275-280）、`__isa`（结构类型判定，:283-292）。
- `fun main()`（0 形参、有体）在尾部自动调用：`moduleJsName(单元前缀, "main")();`（:407-413）；main 天然 `async`（:719）。整个工程的主入口由 MultiModule 查重，多于一个报 E-DUP-DECL（MultiModule.kt:139-140）。
- 工程模式的脚本语句（StmtEntry）在声明之后、main 调用之前逐条生成（注释标记「主序列」，:402-406）。

### 1.2 按需注入的运行时片段

$$\frac{\text{触发条件成立}}{\text{注入对应运行时片段}} \qquad \frac{\text{不成立}}{\text{零输出（“未用则零运行时”，决策 22）}} \quad (\text{G-INJECT})$$

| 片段 | 触发条件 | 位置 |
|---|---|---|
| `__eq`（结构相等） | 源码任意位置出现 `==`/`!=`（中缀或前缀符号调用，needEqPreScan） | :294-303 |
| `__dc`（深拷贝） | deepCopyHits 非空，或 @view 结构体字段被赋值（viewMutationPreScan） | :324-332 |
| `Channel` 类 | channelUsed（用到 Channel） | :335-360 |
| `Mutex` 类 | mutexUsed | :365-378 |
| `__flow`（冷流） | flowUsed | :381-386 |
| `__range`（惰性区间） | rangeUsed（`..` 值或 Range 方法） | :389-397 |
| `__dshAndroid` 桩 | androidUsed（@android 内建被调用：预扫描或桥调用点） | :310-318 |

## 2. 名字改写与模块前缀

### 2.1 标识符改写（jsMangle，ModuleTree.kt:150-160；JsCodeGen.mangle 即此实现）

$$\frac{n \text{ 全由字母、数字、_ 或 } $ \text{ 组成} \qquad n \notin \text{JS 保留字}}{\textsf{mangle}(n) = n} \qquad \frac{n \in \text{JS 保留字}}{\textsf{mangle}(n) = $n} \quad (\text{G-MANGLE-PLAIN})$$

$$\frac{n \text{ 含字母、数字、_、} $ \text{ 以外字符（符号名）}}{\textsf{mangle}(n) = \text{"op_"} \oplus \text{逐字符 hex4}} \quad (\text{G-MANGLE-OP})$$

- 保留字表含 `function/return/var/let/const/class/new/this/typeof/in/of/if/else/…/null/true/false/instanceof` 等。
- `$` 在 JS 标识符里合法，直接保留（安卓注解处理器生成的合成名如 `recomposion$Box$1` 原样通过）。

### 2.2 模块前缀（mangleModule + moduleJsName，ModuleTree.kt:146-167）

$$\frac{\textsf{mangleModule}(\text{absPath}) = \text{absPath 去首尾斜杠、’/’→’_’、非法字符→’_’}}{\text{模块前缀 } p} \qquad \frac{p = \epsilon \ (\text{根模块})}{\text{JS 名} = \textsf{mangle}(n)} \qquad \frac{p \neq \epsilon}{\text{JS 名} = p \text{"__"} \oplus \textsf{mangle}(n)} \quad (\text{G-MODULE-PREFIX})$$

例：模块 absPath 为 `tool` 的函数 `triple` → `tool__triple`；`core/collection` 模块的 `map` → `core_collection__map`；根模块的 `main` → `main`（无前缀，用户拍板 Q4a）。

**全局引用的留痕协议**：codegen 是纯语法变换、不查符号表，跨模块/同模块的引用名由 Checker 按调用点实例留痕进 `moduleHits: Map<Expr, String>`（JsCodeGen.kt:55），生成时直接取用——裸名不再被猜测为本模块符号。限定方法调用以哨兵值 `MODULE_METHOD_MARKER`（ModuleTree.kt:180）标记：首实参即接收者，走字典分发。

### 2.3 字典名与重载后缀

$$\frac{\text{impl } T \text{ for Self} \qquad \text{模块前缀 } p}{\text{字典名} = \text{"dict_"} \oplus p \oplus \text{"_"} \oplus T \oplus \text{"_"} \oplus \textsf{sanitize}(\text{Self})} \quad (\text{G-DICT-NAME}, \text{ ImplCheck.kt:77-86})$$

- 根模块（无前缀）保持 `dict_<Trait>_<Type>`；sanitize 把非字母数字压成下划线。
- HKT 简写：Self 是构造子应用占位（`List[a]` 的 `a`）时字典名只取构造子名（`dict_Functor_List`，ImplCheck.kt:79-85）。

$$\frac{\text{模块内同名函数首参类型 render 不同（重载组）}}{\text{声明 JS 名} = \text{moduleJsName}(p, n) \oplus \text{"$"} \oplus \textsf{fnTag}\text{（首参类型基名；0 参 = v0，元组 = tup，函数 = fn）}} \quad (\text{G-OVERLOAD}, \text{ JsCodeGen.kt:716-717、ModuleTree.kt:171-177})$$

例：`core_collection__map$List`（重载组按首参标签唯一化，声明侧与 moduleHits 调用侧共用同一规则）。

### 2.4 枚举构造子工厂名（v2.1）

$$\frac{c \text{ 是枚举 } E \text{ 的构造子}}{\text{主工厂名} = \text{moduleJsName}(p, E \text{"__"} c) \qquad \text{若 ctorOwnerCounts}(c) \leq 1 \text{ 则另发裸名别名}} \quad (\text{G-CTOR-NAME}, \text{ JsCodeGen.kt:585-601})$$

- `E::A` 引用归一化为 `E__A`（NameRef 含 `::` 时 `::`→`__`，:845-853）；同名构造子分属多个枚举时裸名工厂**不生成**，强制 `E::T` 消歧。
- 零参构造子作**值**引用时生成工厂调用 `Name()`（nullaryCtors，:856）；`None` 由 prelude 提供。
- `true`/`false` 跳过工厂生成（Bool 走 JS 字面量，:586）。

### 2.5 合并编译示例

工程布局（目录即模块）：

```
proj/
  app/app.subl          模块 absPath = "app"
  app/app.settings      mount tool
  tool/tool.subl        模块 absPath = "tool"
```

```subl
// proj/tool/tool.subl
fun triple(x: Nat): Nat = x * 3
```

```subl
// proj/app/app.subl
@impure fun main() {
    print(tool.triple(3))        // 限定引用 → moduleHits 留痕 tool__triple
}
```

生成的 JS（节选）：`function tool__triple(x) { return (x * 3); }` … `console.log(__dshtoStr(tool__triple(3)));`

## 3. 声明翻译判断式

### 3.1 函数（genFun，JsCodeGen.kt:702-741）

$$\frac{\text{decl 无体}}{\text{零输出（纯签名不生成）}} \qquad \frac{\text{"theorem"} \in \text{decl.annotations}}{\text{零输出（见 \10）}} \quad (\text{G-FUN-SKIP})$$

$$\frac{\text{有体} \qquad \text{约束槽} = \{d_{C_j}_{T_j} \mid T_j : C_j, \ C_j \neq \text{Any}} \qquad \text{形参（解构参数合成 } \text{__dt0/__dt1/…)} \qquad \text{重载后缀}}{\text{[async] function Name(slots, params…) { 体 }}} \quad (\text{G-FUN})$$

- 约束泛型槽：`fun f[T: Show]` → `f(d_Show_T, …)`（决策 82；Any 是零字典默认类型类，不设槽，:707）。
- 解构参数：形参位用合成名 `__dt0`，函数体入口生成 `const a = __dt0[0]; const b = __dt0[1];`（元组按下标）/ `const a = __dt0.x;`（结构体按字段名，:724-733）。
- 带默认值形参直出 JS 默认值（决策 69 扩展，:711-714）。
- 块体经 genBlockBody 展平：**块式函数不隐式返回尾表达式**——返回值只来自显式 return；尾 if 全路径 return 时展平，其余尾表达式按语句发射后补 `return null;`（:760-768）。

### 3.2 结构体与枚举（genDecl，:577-601）

$$\frac{\text{struct } S(f_1, \ldots, f_n) \text{（字段可带默认值）}}{\text{const } S\text{（mangle 后）} = (f_1 = d_1, \ldots) => (\{ \text{tag: "S"}, f_1: f_1, \ldots \})} \quad (\text{G-STRUCT})$$

$$\frac{\text{enum } E\{c_1(T_{11}), \ldots\}}{\text{function } E\text{__}c_k(a_0, \ldots) \{ \text{return} \{ \text{tag:} \text{"c_k"}, 0: a_0, \ldots \} \}} \quad (\text{G-ENUM})$$

- 结构体字段按**名字**存储，枚举构造子按**位置**存储（下标键 `0/1/…`）——模式匹配据此取键（\6.4）。
- **数组化 List**（v2.0 基本库）：名为 `List` 的枚举，其 `Nil()`/`Cons(h,t)` 形态构造子**不生成工厂**——List 在 JS 层直接是数组：`Nil()` → `[]`、`Cons(h, t)` → `[h, ...t]`（构造调用 :1060-1065、值引用 :854-855、模式解构 :1779-1787）。语义层的 enum 声明与类型检查完全不动，纯表示变换。

### 3.3 类型类字典（genDict，:613-651）

$$\frac{\text{impl } T \text{ for Self} \qquad \text{字典名 } dn}{\text{const } dn = \{ m_k: \text{function}(d, \text{__self}, a_1, \ldots) \{ \ldots \} \}} \quad (\text{G-IMPL-DICT})$$

- 零参类型类方法签名含隐藏字典参数 `d`（字典自身，供体内递归分发）与隐式接收者 `__self`（决策 68）。
- **kind 类型类**（HKT-D2：theory 含 arity>0 形参，如 `Functor[F[_]]`）签名**无 __self**——self 显式在形参表 fa 位：`(d, f, fa…)`（:624-627、:90-92）。
- 块体方法用 `function` 形式展平语句，return 真正退出方法（:636-646）。
- 方法体内裸用字段名 → `__self.字段`（被同名局部绑定遮蔽者除外——保守不重写，宁可 JS 报未定义也不产出静默错值，:629-633）；显式 `self` → `__self` 参数（:862）。
- 无类型类 impl 已在 Parser 阶段脱糖为自由函数，零残留（:604）。

### 3.4 其余声明

$$\frac{\text{ClassDecl 成员有体}}{\text{按 genFun 生成}} \qquad \frac{\text{TypeAliasDecl / PropDefDecl}}{\text{零输出（纯类型/命题层）}} \quad (\text{G-DECL-REST}, \text{ :602-606})$$

## 4. 表达式翻译判断式（值位）

### 4.1 字面量与名字

$$\frac{}{n \Rightarrow n \qquad r \Rightarrow r \ (\text{原文直出，IEEE double}) \qquad \text{"s"} \Rightarrow \text{"s"} \ (\text{控制字符与 U+2028/2029 一律转义})} \quad (\text{G-LIT})$$

$$\frac{}{\text{true} \Rightarrow \text{true} \qquad \text{false} \Rightarrow \text{false} \qquad \text{null} \Rightarrow \text{null} \qquad \top \Rightarrow \text{true} \qquad \bot \Rightarrow \text{false}} \quad (\text{G-BOOL-LIT}, \text{ :843/867-868})$$

NameRef 解析顺序（:842-864）：

$$\frac{\text{① true/false/null} \quad \text{② } E\text{::}A \Rightarrow E\text{__}A \text{（零参则调用）} \quad \text{③ 零参构造子} \Rightarrow \text{Name()} \quad \text{④ moduleHits 留痕名} \quad \text{⑤ 方法体字段} \Rightarrow \text{__self}.f \quad \text{⑥ dictMethod 体内 self} \Rightarrow \text{__self} \quad \text{⑦ 其它} \Rightarrow \textsf{mangle}(n)}{\text{NameRef 翻译}} \quad (\text{G-NAMEREF})$$

- `$n` 参数引用（ParamRefExpr，命题层专用）→ `/* $n */` 注释占位（:866）；`$` 返回值符号（ReturnSym）→ `__ret`（:865，仅出现在命题位）。
- `is T` 类型测试（TypeTestExpr）→ `(__isa(v, "T"))`（:871）。

### 4.2 中缀与一元（bin，:939-962）

$$\frac{e_1 \circ e_2 \qquad \circ \in \{+, -, *, /, %, <, >, <=, >=\}}{(e_1 \circ e_2) \Rightarrow (e_1 \circ e_2)} \qquad \frac{\circ = \text{"=="} / \text{"!="}}{\Rightarrow \text{__eq}(e_1, e_2) \ / \ (\neg \text{__eq}(e_1, e_2))} \quad (\text{G-BIN-ARITH})$$

$$\frac{x \text{ in } lo..hi}{\Rightarrow (lo \leq x \wedge x \leq hi) \ (\text{闭区间})} \qquad \frac{lo..hi}{\Rightarrow \text{__range}(lo, hi)} \qquad \frac{a \text{ ^ } b}{\Rightarrow \text{Math.pow}(a, b)} \quad (\text{G-BIN-RANGE-POW})$$

$$\frac{\circ \in \{\text{&}, \wedge\} / \{\text{|}, \vee\}}{\Rightarrow \text{&&} / \text{||}} \qquad \frac{\circ \in \{=, :, \rightarrow, \leftrightarrow, \text{自定义双参符号}\} \text{（命题位）}}{\Rightarrow \text{true（擦除，见 \11）}} \quad (\text{G-BIN-LOGIC-PROP})$$

- `==`/`!=` 是结构相等（决策 32/53）：`__eq` 递归比较 tag 与全字段，禁重写；未用则不注入助手。
- 符号前缀调用 `==(a,b)`/`<(1,2)` 走 symbolCall（:968-976）：`==`/`!=` → `__eq`，比较符生成中缀运算，其余未收录者生成 `undefined`（解析器 symbolCallStart 已限定不应出现）。

### 4.3 调用级联（call，:1033-1448）

调用翻译是**有序级联**，先命中先生成：

| 序 | 判据 | 产物 |
|---|---|---|
| 1 | 目标名 ∈ theoremJsNames | `null`（\10） |
| 2 | `in(a, b)` 且 b 是 `..` | 闭区间比较；否则 `true`（语义层已拦，兜底） |

| 4 | 名 ∈ listCtorSet（Nil/Cons） | `[]` / `[h, ...t]` |

| 7 | `println`/`print` | `console.log(__dshtoStr(…))`（:1126-1130） |
| 8 | IO/字符串/数值/JSON/异步内建 | 内联 JS 片段：readFile → try/catch 包 Ok/Err、sleep/delay → Promise+setTimeout、runBoth/runSeq/collect*/withMutex/bump*/channel* 等（:1131-1302） |

| 13 | rangeHits 命中（Range 方法） | `recv.name(args)`（__range 对象方法，:1392-1397） |
| 14 | consDicts 命中（约束槽方法） | `slot.m(slot, self, …)`（:1398-1406） |
| 15 | dicts 命中（类型类方法） | `dn.m(dn, self, …)`；HKT 点号式按 kind 应用位插入接收者 `dn.m(dn, f, xs)`（:1407-1427） |
| 16 | 其余 | `calleeJs(实参)`（命名实参重排 + 字典实参前插 + await 包装 + receive 智能解包 `[0]`，:1428-1447） |

$$\frac{\text{awaitHits}[e] = \text{true}}{\text{调用} \Rightarrow \text{await 调用}} \qquad \frac{\text{receiveSmartHits}[e] = \text{true}}{\text{调用} \Rightarrow \text{(调用)[0]}} \quad (\text{G-ASYNC}, \text{ :1445-1447})$$

- `panic()` → `(() => { throw new Error('panic: unreachable') })()`（:1256）。

### 4.4 复合表达式

$$\frac{(e_1, \ldots, e_n)}{[e_1, \ldots, e_n]} \quad (\text{元组 ⇒ JS 数组，决策 61，:920}) \qquad \frac{S(f_1 = e_1, \ldots)}{S\text{（位置实参）}(e_1 \text{ 或 undefined})} \quad (\text{G-STRUCTCTOR}, \text{ 命名实参→位置实参，:1452-1474})$$

$$\frac{\text{值位块}}{\text{IIFE：} (() => \{ \text{语句…; return 尾表达式;} \})()} \qquad \frac{\text{值位 if}}{(c \ ? t : (e \mid \text{null}))} \quad (\text{G-BLOCK-IF}, \text{ :1527-1541})$$

$$\frac{o.m \text{ 作值（funRefTargets 留痕）}}{(\ldots a) \Rightarrow m(o, \ldots a) \ (\text{字典方法补 dict 自身})} \qquad \frac{o\text{::}f}{(\ldots a) \Rightarrow f(o, \ldots a) \ (\text{自由函数引用不注入接收者})} \quad (\text{G-FUNREF}, \text{ :877-895})$$

- `Task { … }` → 惰性任务对象 `{ start, join, isAlive }`（start 惰性建 async 函数，:980-990）；`Flow { … }` → `__flow(async function* () { … })`，体里 `emit(v)` 留痕生成 `yield v`（:1003-1022）。

## 5. 语句翻译判断式（genStmt，:793-834）

$$\frac{\text{var } x = e \qquad \text{"mut"} \in \text{注解}}{\text{let } x = \textsf{dcWrap}(e)\text{;}} \qquad \frac{\text{无 @mut}}{\text{const } x = \textsf{dcWrap}(e)\text{;}} \quad (\text{G-VAR})$$

$$\frac{\text{var } (a, b) = e}{\text{const } [a, b] = \textsf{dcWrap}(e)\text{;}} \quad (\text{G-VAR-DESTRUCT}, \text{ :799-801}) \qquad \frac{x.f = e \ text{且命中 @view 字段}}{(() => \{ \text{const __c = __dc}(x)\text{; __c}.f = e\text{; __c.recomposion(__c);} \})()\text{;}} \quad (\text{G-VIEW-ASSIGN}, \text{ :812-817})$$

$$\frac{\text{赋值（非视图）}}{x = \textsf{dcWrap}(e)\text{;}} \qquad \frac{\text{return } e}{\text{return } e\text{;}} \quad (\text{G-ASSIGN-RETURN})$$

$$\frac{\text{语句位 if}}{\text{展平为真 JS if/else（return 真正退出函数，决策 75）}} \qquad \frac{\text{语句位 when}}{\text{展平为真 if 链（\6.2）}} \qquad \frac{\text{其它表达式语句}}{e\text{;}} \quad (\text{G-EXPRSTMT}, \text{ :823-830})$$

$$\frac{\text{BTSStmt / WhenPropStmt / StrategyStmt / IfPropStmt / ExistIntroStmt / ExistsElimStmt / FunStmt}}{\text{零输出（纯证明构造）}} \quad (\text{G-PROOF-STMT}, \text{ :796})$$

$$\frac{\text{VarExpr（值位 var）}}{\text{IIFE：} (() => \{ \text{const x = dcWrap(e); return x;} \})()} \quad (\text{G-VAREXPR}, \text{ :934-937})$$

## 6. when 翻译

### 6.1 值位 when（whenExpr，:1712-1753）

$$\frac{\text{主题 } s \qquad \text{const __s<k> = s（k 为嵌套计数）} \qquad \text{各 arm → if (模式条件) { 绑定; return 体 }} \qquad \text{无兜底则补 return null}}{\textsf{whenExpr} = \text{IIFE}} \quad (\text{G-WHEN-VAL})$$

- 无主题 when（v3.0）：分支 cond 直接进条件位（PatCond 不参与模式匹配）。
- 守卫与模式绑定并存的 arm 生成 `if (cond) { const 绑定…; if (守卫) return 体; }`——**先绑定、再判守卫**（守卫可能引用模式绑定变量，:1740-1748）。
- 兜底分支（无条件无守卫）直接 `return 体`，并标记链已闭合；穷尽时尾 `return null;` 不可达（语义层已保证，:1751）。

### 6.2 语句位 when（whenStmtFlatten，:1608-1655）

$$\frac{\text{语句位 when}}{\text{const 主题；顺序 if / else if / else 链；模式绑定 const 在分支内；分支体的 return 真正退出函数}} \quad (\text{G-WHEN-STMT})$$

- 首分支即兜底（无条件无守卫）时直发分支体、立即返回（:1620-1623）。
- 有绑定 + 守卫的 arm：`if (cond) { 绑定; if (守卫) 体 }`，守卫失败落到下一分支（:1624-1635）。
- 嵌套 if/when 在分支体内递归展平（genStmt 分派）。

### 6.3 lambda 体内语句位 when（lambdaWhenLines，:1665-1704）

同 6.2 的语句流版本：展平为真 JS if 链，return 穿透 lambda 体。

### 6.4 模式翻译（matchJs，:1760-1807；isCond，:1809-1820）

$$\frac{c(\ldots) \Rightarrow \text{tag === "c"} \qquad \text{结构体解构} \Rightarrow \text{按字段名取} \qquad \text{枚举构造子} \Rightarrow \text{按下标取} \qquad \text{元组} \Rightarrow \text{Array.isArray} \wedge \text{length} = n \text{ 后逐元递归}}{\text{模式条件 + 绑定}} \quad (\text{G-MATCH-STRUCT})$$

- 裸名：已知构造子（ctorNames，含 prelude 的 true/false/null/None/Some）按标签比较，否则按绑定变量（与语义层 patternBoundNames 同规则）。
- `true`/`false` → `=== true/false`；`null` → `=== null`（:1789-1792）。
- 数组化 List：`Nil` → `length === 0`；`Cons(h, t)` → `length >= 1` 且 `h = s[0]`、`t = s.slice(1)`（:1779-1787）。
- `is T`（PatIs）：Nat/Int/Rat → `typeof === "number"`、Str → `"string"`、Bool → `"boolean"`；其余 → `__isa(v, "T")`（tag 名义判定；List 特判 Array.isArray）。
- PatLit → `path === 字面量`；PatBind（非 _）→ 绑定；PatElse/PatCond 不产生条件。

## 7. lambda 翻译（:898-919、1546-1559）

$$\frac{\text{params} \qquad \text{解构参数} (a, b) \Rightarrow \text{__dt-i 合成形参 + 体首 const 拆解}}{\text{箭头函数}} \quad (\text{G-LAMBDA-PARAM})$$

- 解构分量键：静态已知（lambdaDestructKeys）用字段键 `__dt0.x` 并双兜底 `!== undefined ? .x : [j]`；键未知（无注解 lambda）回落下标 `[j]`（:901-909）。
- 表达式体 → `(params) => 体`；块体 → `(params) => { … return 尾表达式; }`（lambda 默认返回最后表达式；尾 if 全路径 return 时展平，:1546-1559）。
- 体内语句位 if/when 展平为真 JS 语句（lambdaIfLines/lambdaWhenLines），return 穿透 lambda。
- 零参 lambda `{ => 7 }` → `() => 7`；隐式单参 `{ x + 1 }` 的形参在解析期已确定，此处只见具名 params。

## 8. __dc 深拷运行时与函数穿透边界

### 8.1 注入与包装

$$\frac{\text{deepCopyHits} \neq \emptyset \ \vee\ \text{viewMutationUsed}}{\text{注入 __dc}} \qquad \frac{\text{deepCopyHits}[k] = \text{true}}{\textsf{dcWrap}(k, v) = \text{__dc}(v)} \qquad \frac{\text{否则}}{\textsf{dcWrap}(k, v) = v} \quad (\text{G-DC-INJECT-WRAP}, \text{ :319-332/790-791})$$

deepCopyHits 由 Checker 按拷贝四条款谓词（binderNeedsCopy/bindCopy 同一谓词，_langfacts \6）在绑定/赋值点留痕——**何时拷**两端一致，**怎么拷**不同（下节）。

### 8.2 __dc 的语义（:325-331）

$$\frac{v = \text{null} \ \vee\ \text{typeof}(v) \neq \text{"object"}}{\text{__dc}(v) = v} \quad (\text{G-DC-PRIM}) \qquad \frac{v \text{ 为数组}}{\text{__dc}(v) = v\text{.map(__dc)}} \quad (\text{G-DC-ARR}) \qquad \frac{v \text{ 为普通对象}}{\text{__dc}(v) = \{ k \mapsto \text{__dc}(v[k]) \}} \quad (\text{G-DC-OBJ})$$

### 8.3 函数穿透边界（既定边界）

$$\frac{\text{typeof}(v) = \text{"function"}}{\text{__dc}(v) = v \qquad (\text{穿透：JS 闭包不透明，无法深拷其捕获})} \quad (\text{G-DC-FUN})$$

G-DC-FUN 是 G-DC-PRIM 的推论（`typeof function !== "object"` 早退）。JsCodeGen 的注释明示这是**既定边界**（:322-323）：修正案要求「深拷贝闭包捕获变量」，该要求在**脚本模式**由解释器完整实现——

$$\frac{v = \text{Fun( ClosureFun )}}{\text{deepCopy}(v) = v\text{.copyCapture()} \qquad (\text{沿父链逐值深拷全部捕获变量与局部函数，装新帧})} \quad (\text{V-DC-CLOSURE}, \text{ Evaluator.kt:130-143/156/833-865})$$

**结论**：编译产物里，捕获含函数的深拷不复制函数体与其捕获（__dc 穿透）；解释器里复制。跨执行后端时行为可能不同——领域不同，此差异为既定边界（wiki/02-类型-拷贝规则.md「JS 边界」节）。非函数值的深拷两端语义一致（Struct 逐字段、数组/ListV 逐项、Optional/Result 递归）。

示例（两端一致的部分）：

```subl
@mut struct Box(@mut n: Nat)

@impure fun main() {
    var a: @mut Box = Box(0)
    var b: @mut Box = a          // @mut 目标 ← 纯源：深拷 → const b = __dc(a);
    b.n = 1
    print(a.n)                   // 0
}
```

## 9. unchecked 的代码生成

$$\frac{}{\textsf{genStmt}(\textsf{unchecked}\ s) = \text{// unchecked} \oplus \textsf{genStmt}(s)} \quad (\text{G-UNCHECKED}, \text{ JsCodeGen.kt:822})$$

- 生成器里 UncheckedStmt 共 7 处分派，**全部按 inner 归约**：视图突变预扫描（:462）、安卓调用预扫描（:515）、等式漫游（:557）、binder 收集（:676）、语句串化 stmtStr（:1520，IIFE 内联用——此分支注释也丢，只留 inner）、genStmt（:822）、lambda 体（:1587）。
- 产物里 `// unchecked` 注释可 grep 审计；语义与去掉 unchecked 完全相同——unchecked 是纯编译期开关（uncheckedDepth 闸门，_langfacts \6）。
- 解释器侧同样零成本：`evalStmt(UncheckedStmt) → evalStmt(inner)`（Evaluator.kt:194）。
- 详见 wiki/04-效应-unchecked语句.md（38 = 25 + 13 穿透点盘点）。

```subl
fun main() {
    var n = 0
    unchecked n = n + 1        // // unchecked  ←  n = n + 1;
    unchecked print(n)         // // unchecked  ←  console.log(__dshtoStr(n));
}
```

## 10. @theorem 擦除（编译期）

$$\frac{\text{"theorem"} \in \text{decl.annotations} \qquad \text{全工程预扫描}}{\text{theoremJsNames += moduleJsName}(p, \text{name})} \quad (\text{G-THEOREM-COLLECT}, \text{ JsCodeGen.kt:203-207})$$

$$\frac{\text{decl.annotations 含 theorem}}{\textsf{genDecl} \text{跳过该函数（零输出，无论有体无体）}} \quad (\text{G-THEOREM-DECL}, \text{ JsCodeGen.kt:576})$$

$$\frac{\text{调用点的 JS 名} \in \text{theoremJsNames}}{\text{该调用} \Rightarrow \text{null（编译期已注入后件事实）}} \quad (\text{G-THEOREM-CALL}, \text{ JsCodeGen.kt:1042-1046})$$

- 语义层（Checker）对 @theorem **不擦除**：登记进全局定理空间供 `∴` 搜索（Diffusion.kt:340 isTheoremFun：判据只有注解含 theorem 一条），调用点正常做上文强校验与下文注入，且**解封值级调用**（CallCheck.kt:743）——@theorem 可以「当程序调用」。
- **解释器照常求值**：run/run-script 下定理函数的体正常执行——实测 `@theorem fun t(): Nat = 7` 解释执行打印 `7`，compile 后同一调用变成 `null`。
- **旧注释冲突已由实测裁决**：Types.kt:356 注释称「有体定理照常生成运行时代码」，与 JsCodeGen.kt:576 的实现冲突；实测**有体定理同样被擦除**，以实测为准（旧注释口径已过时；见 wiki/03-证明-theorem与@simp.md 陷阱 6/11）。

```subl
@theorem fun t(): Nat = 7

@impure fun main() {
    print(t())        // run-script: 7        compile: console.log(__dshtoStr(null))
}
```

## 11. 命题 → JS 断言形态

命题层（类型、理论参数、上下文、axiom/by、命题算符）零成本擦除（决策 22），落地产物分两类形态：

### 11.1 值位命题表达式 → 布尔断言

$$\frac{e_1 \circ e_2 \qquad \circ \in \{=, :, \rightarrow, \leftrightarrow, \text{自定义双参符号}\}}{\textsf{expr} = \text{true}} \quad (\text{G-PROP-TRUE}, \text{ :958-959}) \qquad \frac{}{\top \Rightarrow \text{true} \qquad \bot \Rightarrow \text{false}} \quad (\text{G-PROP-LIT}, \text{ :867-868})$$

$$\frac{\text{QuantExpr}(\forall/\exists)}{\textsf{expr} = \textsf{expr}(\text{体}) \ (\text{量词擦除，只留体})} \quad (\text{G-QUANT}, \text{ :926}) \qquad \frac{$n \ (\text{参数引用，命题层专用})}{\text{/* $n */} \ (\text{注释占位})} \quad (\text{G-PARAMREF}, \text{ :866})$$

即：值位出现的命题算符一律退化为 JS 布尔字面量——命题真值已在编译期由证明器判定，运行时只需一个恒真断言占位。_langfacts \7 所述「命题以断言形态落地」即此（值位布尔化 + 语句注释化）：**不存在运行时 assert 断言**。

### 11.2 证明层语句 → 审计注释

$$\frac{\text{axiom } p_1, \ldots, p_n}{\text{// axiom: } \textsf{tag}(p_i) \text{ 逐条}} \quad (\text{G-AXIOM}, \text{ :820}) \qquad \frac{\text{by } [q_1, \ldots, q_n]}{\text{// by: } \textsf{tag}(q_i) \text{ 逐条}} \quad (\text{G-BY}, \text{ :821})$$

- tag() 把命题项渲染为可读标签（NameRef/字面量/CallExpr/量词等，:1837-1849），便于 grep 审计。
- ∵∴、命题 when、策略语句等证明构造零输出（G-PROOF-STMT）。

```subl
@impure fun main() {
    axiom p ∧ (p → q)          // // axiom: p ∧ (p → q)
    ∵ p ∴ q                    // （零输出）
    by [r]                     // // by: r
    print(if[p ∨ q] 1 else 0)  // 命题算符 ∨ 在值位：(true) ? 1 : 0
}
```

## 13. 已知限制与待核

**v1 限制（JsCodeGen 类注释 :17-24 钉死）**

- `is T` 模式：基本类型用 typeof 近似，其余保守生成 true——v2.1 已迁移为 `__isa` 结构判定（tag 名义）；总体边界不变：JS 不记录类型信息，结构判定与零 tag 名义区分（:281-292）。
- impl 方法按函数名生成，跨 trait 同名方法会冲突（单态化留待后续）。
- `==`/`!=` 生成 `__eq`（递归比较 tag 与全字段），仅在源码用到时注入。
- structFields 按声明收集、不读符号表：同名结构体跨模块时取最后者（见《模块系统.md》限制）。

**待核**

- ⊤/⊥ 在解释器的失真是否既定边界（差异清单 #1）。
- 解释器 var 解构不拆分的修复状态（差异清单 #2）。
- Checker（`-5 : Nat`）与解释器全局推导（`-5 : Int`）的口径统一（差异清单 #3）。
- 旧 `unchecked.axiom[p]` 引导句从未触发属实现细节（wiki/04-效应-unchecked语句.md 语法节）。
- 本卷未覆盖：安卓视图生成的全部细节（`recomposion` 副本机制、`__dshFn_*` 回调注册）、HKT 字典签名的完整推导、具名实参重排与集合方法糖的 Checker 留痕细节——需要时另卷展开。
