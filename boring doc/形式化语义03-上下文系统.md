## 1. Frame 结构

### 1.1 字段定义

作用域帧 `Frame`（Diffusion.kt:10–42）是上下文 `Γ` 的实现载体：

$$\Gamma = \langle \textit{parent},\ \textit{vars},\ \textit{facts},\ \textit{localTheorems},\ \textit{muts},\ \textit{refs},\ \textit{children},\ \textit{used},\ \textit{audited} \rangle$$

| 字段 | 类型 | 语义 |
|---|---|---|
| `parent` | `Frame?` | 父帧指针；`null` 表示顶层帧（函数体根帧） |
| `vars` | `LinkedHashMap<String, Type>` | 变量类型环境；`lookupVar` 沿父链查找（Diffusion.kt:23） |
| `facts` | `LinkedHashSet<Prop>` | 命题事实集；去重 O(1) 且保插入序（Diffusion.kt:12 注 P8） |
| `localTheorems` | `LinkedHashMap<String, FunDecl>` | 局部定理表（∀ 引入的局部函数定义）；∴ 搜索时并入定理空间（Diffusion.kt:14） |
| `muts` | `LinkedHashSet<String>` | `@mut` 变量登记；`isMut` 沿父链查找（Diffusion.kt:28） |
| `refs` | `LinkedHashSet<String>` | `@ref` 变量登记；`isRef` 沿父链查找（Diffusion.kt:30） |
| `children` | `ArrayList<Frame>` | 子帧列表；创建子帧时自动注册（Diffusion.kt:22） |
| `used` | `HashSet<String>` | 已使用变量集；`markUsed` 沿父链上溢（Diffusion.kt:31） |
| `audited` | `LinkedHashMap<String, String>` | W-UNUSED 审计目标（名字 → 声明点 pos） |

`Γ_vars(x) = τ` 的定义：

$$\frac{x \in F.\textit{vars}}{\Gamma_{\textit{vars}}(x) = F.\textit{vars}[x]} \qquad \frac{x \notin F.\textit{vars} \qquad F.\textit{parent} \neq \bot}{\Gamma_{\textit{vars}}(x) = \Gamma_{\textit{parent.vars}}(x)} \quad (\text{G-LOOKUP})$$

### 1.2 注入与可见性

$$\frac{p \neq \top}{\text{inject}(F,\ p) \triangleq F.\textit{facts} \cup \{p\}} \qquad \frac{p = \top}{\text{inject}(F,\ p) \triangleq F.\textit{facts}} \quad (\text{G-INJECT})$$

`⊤` 不被注入（Diffusion.kt:40：`if (p != PTop) facts.add(p)`）——恒真命题无信息量。

$$\frac{}{\text{allFacts}(F) = \text{allFacts}(F.\textit{parent}) + F.\textit{facts}} \quad (\text{G-ALLFACTS})$$

方向自下而上：子帧沿父链读取全部事实；父帧不主动读子帧事实（Diffusion.kt:41）。

### 1.3 全域事实池 `globalFacts`

`Γ ⊢ P` 的搜索空间 = 本帧 `allFacts()` + `globalFacts`（跨帧全域事实池）。`globalFacts` 当前承载：

| 事实形态 | 注册条件 | 源码 |
|---|---|---|
| `pure<f>` | 未标 `@impure` 的函数（含跨模块可见函数；同名任一处 `@impure` 则整名不注册） | Symbols.kt:26、46–47 |
| `async<f>` | 标 `@async` 的函数 | Symbols.kt:28 |

（`immutable<T>` 与 `untouch<p>` 已废弃，Symbols.kt:55、105 标注 `@Deprecated`。）

证明器入口 `proveOrDeep` 在调用通用证明器时传入 `globalFacts`（Diffusion.kt:327：`prover.proves(gamma, goal, globalFacts)`）；反证法通道同样并入（Diffusion.kt:333）。

## 2. 帧链拓扑规则

三条规则构成本卷骨架：

### 2.1 嵌套帧继承外层

子帧创建时以父帧为 `parent`（`Frame(f)`），`lookupVar`/`isMut`/`isRef`/`allFacts` 均沿父链向上查找。块表达式、分支、lambda 体均创建子帧（Checker.kt:1174、1210、1113）。

### 2.2 块事实回溢父帧（弥散）

$$\frac{\text{块表达式检查结束}}{\forall p \in F'.\textit{facts}.\ \text{inject}(F,\ p)} \quad (\text{G-BLOCK})$$

块内事实回溢父帧（Checker.kt:1188：`nf.facts.forEach { f.inject(it) }`）。函数体本身也是块表达式，其事实经 G-BLOCK 回溢到函数根帧，供下文验证消费。

### 2.3 Lambda 帧隔离

$$\frac{\text{lambda 体检查结束}}{F'.\textit{facts}\ \text{不回溢}} \quad (\text{G-LAMBDA})$$

Lambda 帧的内部事实不外泄——体求值时机与次数不受定义点控制，外泄破坏健全性。唯一例外：纯 lambda 向外部注入 `pure<λ>`（Checker.kt:1168：`f.inject(PAtom("pure", listOf(e)))`）。闭包捕获在创建时深拷贝（_langfacts §6，06 卷细化）。

`if`/`when` 值表达式的分支帧同样不回溢（Checker.kt:1198–1261）：分支事实只在该分支条件下成立。但 `if[p]` 排中律语句（§5.6）和命题 when（§5.7）有专门的交集/公共结论注入机制。

## 3. 语句判断与弥散

### 3.1 核心判断式

$$\frac{\Gamma; \pi; \phi \vdash s_1 \Longrightarrow \Delta_1 \qquad \Delta_1; \pi; \phi \vdash s_2 \Longrightarrow \Delta_2}{\Gamma; \pi; \phi \vdash s_1;\ s_2 \Longrightarrow \Delta_2} \quad (\text{G-SEQ})$$

`π ∈ {pure, impure}` 为预期纯度；`φ` 为语句流标记（`flow`：`true` = 语句位，`false` = 表达式位；Checker.kt:517）。`Δ` 固定表示演义后的后件上下文（总纲 §2.4）。

实现入口 `checkStmt(s, f, pure, flow)`（Checker.kt:517）按语句种类分派。以下逐条给出规则。

### 3.2 变量声明

$$\frac{\begin{gathered} \Gamma \vdash e : \tau \qquad x \notin \Gamma_{\textit{vars}} \\ \text{若纯值且非 @mut/@ref：inject}(F,\ x = e) \\ \text{若纯值或 @mut：inject}(F,\ x : \tau) \\ \text{若 }\tau = \text{Nat：inject}(F,\ x \ge 0) \end{gathered}}{\Gamma; \pi; \phi \vdash \texttt{var } x : \tau = e \Longrightarrow \Gamma[x \mapsto \tau]} \quad (\text{G-VAR})$$

（Checker.kt:560–614。）`@mut`/`@ref` 变量不注入绑定等式（初值会变/别名共享，等式不可靠）；Nat 变量自动注入自然命题 `x ≥ 0`。

### 3.3 赋值

$$\frac{\Gamma_{\textit{vars}}(x) = \tau \qquad \textit{isMut}(x) \lor u > 0 \qquad \Gamma \vdash e : \tau'}{\Gamma; \pi; \phi \vdash x = e \Longrightarrow \Gamma} \quad (\text{G-ASSIGN})$$

不可变变量赋值仅在 `u > 0`（unchecked 内）放行；否则报 `E-IMMUT-ASSIGN`（Checker.kt:622）。Lambda 体内修改外层捕获的可变变量推导该 lambda 为 impure（Checker.kt:625–626）。

### 3.4 表达式语句

$$\frac{\Gamma; \pi \vdash e : \tau}{\Gamma; \pi; \phi \vdash e\texttt{;} \Longrightarrow \Gamma} \quad (\text{G-EXPR-STMT})$$

（Checker.kt:810。）表达式语句不改变上下文（副作用由表达式内部处理）。

### 3.5 块语句

$$\frac{\Gamma; \pi; \phi \vdash s_1 \Longrightarrow \Delta_1 \qquad \cdots \qquad \Delta_{n-1}; \pi; \phi \vdash s_n \Longrightarrow \Delta_n}{\Gamma; \pi; \phi \vdash \{ s_1 \dots s_n \} \Longrightarrow \Delta_n} \quad (\text{G-BLOCK-STMT})$$

块创建子帧 `nf = Frame(f)`（Checker.kt:1174）；语句序列按 G-SEQ 依次检查；块结束后 `nf.facts` 回溢父帧（G-BLOCK，Checker.kt:1188）。

### 3.6 `if[p]` 排中律分支

$$\frac{\begin{gathered} \text{core.classic 已挂载} \qquad p = \text{fromExpr}(s.\textit{prop}) \\ F_t = \text{Frame}(F);\ \text{inject}(F_t,\ p) \qquad F_e = \text{Frame}(F);\ \text{inject}(F_e,\ \neg p) \\ F_t; \pi; \phi \vdash \overline{s_t} \Longrightarrow \Delta_t \qquad F_e; \pi; \phi \vdash \overline{s_e} \Longrightarrow \Delta_e \\ C = \{ q \in \Delta_e.\textit{facts} \mid \exists q' \in \Delta_t.\textit{facts}.\ \text{propStructEq}(q,\ q') \} \\ C \neq \emptyset \Rightarrow \forall q \in C.\ \text{inject}(F,\ q) \\ C = \emptyset \Rightarrow \texttt{E-IF-CONCLUSION-MISMATCH} \end{gathered}}{\Gamma; \pi; \phi \vdash \texttt{if}[p]\ \{\overline{s_t}\}\ \texttt{else}\ \{\overline{s_e}\} \Longrightarrow \Gamma \cup C} \quad (\text{G-IF-PROP})$$

（Checker.kt:711–734。）两支各注入 `p`/`¬p`，检查完后取**新注入事实的结构相等交集**作为「与 p 无关、两支都成立」的公共结论注入块外。交集为空报 `E-IF-CONCLUSION-MISMATCH`。需要 `core.classic` 挂载（`@classic` 注解触发）。

示例：

```subl
@classic fun demo(n: Nat) {
    if[n = 0] {
        axiom p
    } else {
        ∵ n > 0 ∴ p
    }
    // 块外 Γ 得 p（两支公共结论）
}
```

### 3.7 命题 when

$$\frac{\begin{gathered} d = \text{fromExpr}(s.\textit{disjunction}) \qquad d \in \text{allFacts}(F) \\ \forall i.\ F_i = \text{Frame}(F);\ \text{inject}(F_i,\ c_i);\ F_i; \pi; \phi \vdash \overline{s_i} \Longrightarrow \Delta_i \\ M = \bigcap_i \{ \text{BTSStmt 结论} \in \Delta_i.\textit{facts} \} \\ M \neq \emptyset \Rightarrow \forall q \in M.\ \text{inject}(F,\ q) \\ d \notin \text{allFacts}(F) \Rightarrow \texttt{W-PROP-UNBOUND} \end{gathered}}{\Gamma; \pi; \phi \vdash \texttt{when}[d]\ \{ c_1 \Rightarrow \{\overline{s_1}\} \dots \} \Longrightarrow \Gamma \cup M} \quad (\text{G-WHEN-PROP})$$

（Checker.kt:667–693。）析取前提须在 Γ 中（否则 `W-PROP-UNBOUND`）；每个分支假设一个析取支成立；所有分支的 BTSStmt 结论取键交集注入块外。无公共结论发 `W-WHEN-NO-COMMON` 警告。

### 3.8 return

$$\frac{\Gamma \vdash e : \tau \qquad \textit{funRetType} \neq \bot \qquad \phi = \text{true}}{\Gamma; \pi; \phi \vdash \texttt{return } e \Longrightarrow \Gamma} \quad (\text{G-RETURN})$$

return 仅在语句流（`flow = true`）且在具名函数/lambda 体内合法（Checker.kt:782–809）。返回类型为 Nothing（发散标记），后续语句不可达。

### 3.9 axiom

$$\frac{}{\Gamma; \pi; \phi \vdash \texttt{axiom } p_1, \dots, p_n \Longrightarrow \Gamma \cup \{p_1, \dots, p_n\}} \quad (\text{G-AXIOM})$$

（Checker.kt:771。）独立语句，顶层与函数内通用；返回 Null。旧 `unchecked.axiom[p]` 已废除（_langfacts §2）。

### 3.10 unchecked

$$\frac{u' = u + 1 \qquad \Gamma; \text{impure}; \phi \vdash s \Longrightarrow \Delta}{\Gamma; \pi; \phi \vdash \texttt{unchecked } s \Longrightarrow \Delta} \quad (\text{G-UNCHECKED})$$

（Checker.kt:779。）`uncheckedDepth++` 并强制 `π := impure`；凡 `u > 0` 处纯度/不可变闸门一律放行——这是刻意的开口，不是闸门失效（总纲 §3.4、I-2）。解释器直接执行 inner（Evaluator.kt:194），JS 生成侧注 `// unchecked` 后透传（JsCodeGen.kt:822）。

### 3.11 ∀ 引入（局部定理）

$$\frac{f.\textit{body} \neq \bot}{\Gamma; \pi; \phi \vdash \texttt{fun } f(\dots)\{\dots\} \Longrightarrow \Gamma[\textit{localTheorems} \cup \{f\}]} \quad (\text{G-LOCAL-FUN})$$

（Checker.kt:761–769。）局部函数定义登记为局部定理（形参即绑定变元）；体非空要求（不是签名即证明）。∴ 搜索时 `localTheorems` 并入定理空间（Diffusion.kt:14、Checker.kt:656）。

### 3.12 ∃ 引入与消去

∃ 引入：

$$\frac{\Gamma \vdash P[t_1/x_1, \dots]}{\Gamma; \pi; \phi \vdash \exists x_1 = t_1, \dots .\ P \Longrightarrow \Gamma \cup \{\exists \vec{x}.\ P\}} \quad (\text{G-EXIST-INTRO})$$

（Checker.kt:737–746。）实例证不出报 `E-QUANT-UNPROVEN`。

∃ 消去：

$$\frac{\exists x.\ P \in \text{allFacts}(F) \qquad F'; \pi; \phi \vdash \overline{s} \Longrightarrow \Delta' \qquad F' = F[P(x)]}{\Gamma; \pi; \phi \vdash \exists x.\ P\ \{\overline{s}\} \Longrightarrow \Gamma \cup \{\text{BTSStmt 结论}\}} \quad (\text{G-EXIST-ELIM})$$

（Checker.kt:748–759。）前提不在 Γ 发 `E-PROP-UNBOUND` 警告；块内 BTSStmt 结论回溢父帧。

### 3.13 ∵∴ 义务

$$\frac{\begin{gathered} \forall i.\ \Gamma \vdash p_i \qquad \Gamma \cup \{p_1, \dots, p_n\} \vdash q \\ \text{（或 searchTheorems}(q,\ 0,\ \textit{localTheorems})\text{）} \end{gathered}}{\Gamma; \pi; \phi \vdash \because p_1, \dots, p_n \therefore q \Longrightarrow \Gamma \cup \{q\}} \quad (\text{G-BTS})$$

（Checker.kt:643–664。）前提各自先证（不成报 `E-PREMISE-UNPROVEN`）；结论由定理空间 + 前提推出（不成报 `E-CANNOT-PROVE`）；成功后注入 Γ。

### 3.14 by 语句（已删除）

$$\frac{}{\Gamma; \pi; \phi \vdash \texttt{by } [q] \Longrightarrow \texttt{E-BY-REMOVED}} \quad (\text{G-BY-REMOVED})$$

（Checker.kt:772–777。）t30 后免验证命题注入已删除；供给命题改用 `axiom`，断言改用后缀式 `expr by [q]`。

## 4. 上文 `<p>`：调用方供给义务

### 4.1 签名文法

具名函数签名（Parser.kt:270–306）：

```
fun 名[理论参数](实际参数)<上文> : 返回类型<下文> { 体 }
```

- 形参表后、冒号前的 `<…>` = **上文**（`preps`）；
- 冒号后的 `<…>` = **下文**（`posts`）；
- 返回类型可省略：`: <q>` 是无返回类型的后置上下文（Parser.kt:290）；
- `: T <q>` 是旧形态仍兼容（Parser.kt:293）；
- `<…>` 内以逗号分隔命题表达式列表（`parseAngleList`，Parser.kt:603–617）；尾随逗号被接受（Parser.kt:610）。

### 4.2 上文判断式

$$\frac{\begin{gathered} \text{调用点 } f(a_1\dots a_k) \qquad f.\textit{preps} = [p_1\dots p_m] \\ \text{声明期改写：}\$n \to \text{形参名，this} \to f \\ \text{调用点代入：}\sigma_p,\ \sigma_t,\ \sigma_e \end{gathered}}{\forall j.\ \Gamma \vdash p_j[\sigma_p, \sigma_t, \sigma_e]} \quad (\text{G-PRE})$$

声明期改写：`rewriteDollarN`（Checker.kt:259–266）+ `substThisExpr`（Checker.kt:280–291），在 `checkFun` 内完成（Checker.kt:378）。调用点代入：`substAll`（CallCheck.kt:1067–1075）。

任一上文证不出报 `E-PRE-UNPROVEN`（ERROR，CallCheck.kt:921–925）。

### 4.3 上文的双重身份

$$\frac{\text{checkFun}(f)\ \text{时}}{\forall p \in f.\textit{preps}.\ \text{inject}(F_0,\ p[\$n \to \text{形参名},\ \text{this} \to f])} \quad (\text{G-PRE-IN-BODY})$$

上文在声明处被改写后注入函数体帧（Checker.kt:380）。上文既是调用方的义务，也是被调函数体内可用的前提。

### 4.4 排除集

$$\frac{}{\text{排除集} = \{=,\ ==,\ !=,\ <,\ >,\ <=,\ >=\} \cup \{\$,\ :,\ \text{\_\_call\_\_},\ \text{\_\_inst\_\_},\ \text{\_\_t\_\_}\}} \quad (\text{G-EXCLUSION})$$

（Prop.kt:25–27：`structuralHeads`。）排除集在两处控制弥散命题的候选范围：

1. **自动供给候选过滤**（CallCheck.kt:911）：等式、比较、类型归属、`$` 原子、调用/实例化记录是推理材料，不是可供给的弥散命题；
2. **显式供给合法性**（`propFromSupply`，CallCheck.kt:1064）：结构性原子不允许作为显式供给项。

## 5. 下文 `<q>`：体内兑现

### 5.1 下文判断式（声明处）

$$\frac{\begin{gathered} \text{fun } f(\dots) : \tau\ \langle\text{posts}\rangle\ \{\ \text{body}\ \} \\ \$ := \text{dollarOf}(\text{body}) \qquad \text{posts 经}\ \$n/\text{this}\ \text{改写} \end{gathered}}{\forall q \in \text{posts}.\ \text{allFacts}(F_0) \vdash q[\$]} \quad (\text{G-POST-CHECK})$$

（Checker.kt:411–421。）函数体是证明义务：声明不是可信公理，体结束时 Γ 必须蕴含下文。证不出报 `E-POST-UNPROVEN`。

### 5.2 `$` 的解法

`dollarOf`（Diffusion.kt:52–59）：

$$\frac{\begin{gathered} \text{① 块内有唯一一处带值的显式 return } e \Rightarrow \$ := e \\ \text{② 否则取尾表达式} \Rightarrow \$ := \text{tailExpr} \\ \text{③ 都没有} \Rightarrow \$ := \texttt{null} \end{gathered}}{\$\ \text{的解}} \quad (\text{G-DOLLAR-OF})$$

**多路 return 保守取 null**：`if/else` 各返回一个值时无法归一为单一项，`dollarOf` 返回 `NameRef("null")`，让后件核对显式失败——源码原注「不猜测——猜测会产生『看似通过实则错误』的证明」（Diffusion.kt:48–50）。这是总纲 I-1 的直接体现。

### 5.3 `@axiom` 豁免

$$\frac{\texttt{"axiom"} \in f.\textit{annotations}}{\text{免除 } f\ \text{的下文验证义务} \qquad \text{发 D-AXIOM-POST}} \quad (\text{G-AXIOM-FUN})$$

（Checker.kt:414–416。）签名即公理；函数体仍正常类型检查；上文仍在调用点强制证明。

### 5.4 下文注入（调用点弥散）

$$\frac{\begin{gathered} e = f(a_1\dots a_k) \qquad f.\textit{posts} = [q_1\dots q_n] \\ \text{上文检查已通过} \qquad \sigma = [\$ \to e,\ \$n \to a_n,\ \text{this} \to f,\ \sigma_p,\ \sigma_t,\ \sigma_e] \end{gathered}}{\forall i.\ \text{inject}(F,\ q_i[\sigma])} \quad (\text{G-POST-INJECT})$$

（CallCheck.kt:939–943。）下文在调用点直接注入，不经验证——下文是被调函数的保证（兑现义务已在声明处强制）。注入目标帧是调用点所在帧。

### 5.5 伴生记录

$$\frac{\text{调用 } f(a_1\dots a_k)\ \text{成功}}{\text{inject}(F,\ \text{PAtom}(f,\ [a_1\dots a_k]))} \quad (\text{G-COMPANION})$$

（CallCheck.kt:939。）伴生记录把函数名当谓词符号、实参当项，记录「这次调用发生过」。方法路径的伴生记录用全量实参（含 self 作调用痕迹）。

### 5.6 全局弥散：纯度事实

$$\frac{\texttt{"impure"} \notin f.\textit{annotations}}{\textit{globalFacts} \cup= \{\text{pure}\langle f\rangle\}} \qquad \frac{\texttt{"async"} \in f.\textit{annotations}}{\textit{globalFacts} \cup= \{\text{async}\langle f\rangle\}} \quad (\text{G-GLOBAL})$$

（Symbols.kt:26–28。）驱动纯作用域调用闸与异步闸（04 卷）。

## 6. `$` 与 `$n`：指代系统

### 6.1 `$n` 第 n 形参引用

$$\frac{\$n\ \text{出现在具名函数的上文或下文中}}{\text{声明期改写为第 } n\ \text{个形参的名字}} \quad (\text{G-DOLLAR-N})$$

（Checker.kt:376–379 调用 `rewriteDollarN`；替换器 `substDollarNExpr`，Checker.kt:269–277：`params.getOrNull(e.index - 1)`。）`$n` 从 1 起，仅在前件/后件位有效。

附带诊断：

$$\frac{n > |\text{params}|}{\texttt{E-PARAM-REF}} \qquad \frac{n \le |\text{params}|}{\texttt{H-PARAM-REF}} \quad (\text{G-DOLLAR-N-DIAG})$$

位置限制：

$$\frac{\$n\ \text{出现在函数体值位}}{\texttt{E-PARAM-REF-IN-BODY}} \quad (\text{G-PARAM-REF-IN-BODY})$$

（Checker.kt:904–908。）

词法层：`$n` 粘连为单 token `ParamRefExpr`（_langfacts §1）。

### 6.2 `$` 返回值指代

| 出现位 | 解法 | 源码 |
|---|---|---|
| 下文（声明处） | `dollarOf(body)` | Checker.kt:411 |

## 8. 约束表与歧义消解

### 8.1 `constraintListAhead` 歧义消解

形参表后的 `<` 先经 `constraintListAhead()`（Parser.kt:311–316）判别：

$$\frac{\begin{gathered} \text{角括内首项为 IDENT} \qquad \text{其后跟带空格的 LE/GE/EQ/NEQ 或文本 in} \end{gathered}}{\text{按约束表解析，不作为上文}} \quad (\text{G-CONSTRAINT-DISPATCH})$$

**核实结论**：`constraintListAhead` 的判定条件是 `nm.kind == IDENT && op.precededBySpace && op.kind in {LE, GE, EQ, NEQ} || (op.kind == IDENT && op.text == "in")`（Parser.kt:314–315）。关键设计：**LT/GT 被排除在触发条件之外**（Parser.kt:315 注释明确说明），避免 `<a < b>` 这类上文命题被误判为约束表。因此 `fun f<a < b>` 正确解析为上文命题 `<a < b>`，而 `fun f<score <= 100>` 正确解析为约束表。**总纲 §7.6 登记的待核项在此解决：歧义消解机制完备，无遗留问题。**

约束表只解析登记（Parser.kt:318–337），三态判断（CallCheck.kt:929–937）：

$$\frac{\Gamma \vdash \text{goal}}{\text{通过}} \qquad \frac{\Gamma \nvdash \text{goal} \quad \Gamma \vdash \neg\text{goal}}{\texttt{E-CONSTRAINT-VIOLATED}} \qquad \frac{\Gamma \nvdash \text{goal} \quad \Gamma \nvdash \neg\text{goal}}{\texttt{W-CONSTRAINT-UNPROVEN}} \quad (\text{G-CONSTRAINT})$$

### 8.2 angle 上下文中 `>` 的处理

angle 上下文（`parseExpr(angle = true)`）中 `>` 作中缀须「前有空格且后有操作数」（Parser.kt:1028–1034）；紧贴的 `>`（`valid<7>` 终止符、`>>` 序列）仍是终止符。这保证了 `<n > 0>` 中的 `>` 被正确解析为比较中缀而非角表终止符。

## 9. 与第 12 卷的边界

凝华的泛型约束有两条独立通道（12 卷 §8.2）：

- **通道 A：类型类约束**（已实现）——`class C[a]` + `impl C for T`，运行时以字典落地；
- **通道 B：有界量化**（12 卷规格）——`[X <: τ]`，完全擦除。

本卷的上下文命题 `<p>` 属于**命题层**，与上述两条通道正交：

| 需求 | 走哪条 | 理由 |
|---|---|---|
| "X 必须有 map 方法" | 通道 A（类型类） | 需要运行时字典 |
| "X 必须是 Nat 的子类型" | 通道 B（有界量化） | 纯类型层约束 |
| "X 必须满足命题 p" | 03 卷上下文命题 `<p>` | 命题不是类型 |

**边界纪律**：有界量化属类型层，不得把命题当界写（`[X <: p]` 非法），也不得把类型子类型判断的结果注入 `Frame.facts`（`Γ ⊢ X <: τ` 不进入事实集）。命题层与类型层是二分的（设计公理「值与命题二分」），唯一的桥是分支条件提升。
