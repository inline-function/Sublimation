# boring doc —— 形式化语义卷集

> 本目录是 Sublimation（凝华）语言的**形式化层文档**：以判断式（inference rules）体例规约语言行为，而非以示例或散文描述。
> 事实来源优先级：**源码 > `_facts/_langfacts.md`（语言事实表）> 本卷集**。所有规则前缀、判断形式、跨卷符号表、健全性底线与勘误程序见 [形式化语义00-总纲](形式化语义00-总纲.md)。行号为近似定位，以代码语义为准。

## 一条必须先知道的事实

**凝华的基础类型系统没有子类型关系（no subtyping）。** 类型之间的 `≡`（严格相等）与 `≈`（宽松相容）回答的都是"两个类型是否可视为同一个"，不是"谁是谁的子集"。基础方言里带方向性的关系只有三处（`@mut` 视图转换、数值升格、变体入联合），都不是格意义上的 `<:`。

唯一带 `<:` 的是**第 12 卷规约的 Kernel Fω<: 方言**——它由编译器旗标分离、是基础方言的**方言**（保守扩展）而非升级版。凝华尚未决定是否采纳该方言，第 12 卷因此是**规格卷**（描述应当满足的判断系统），不是实现现状卷。读基础方言各卷时，不要预期任何 `<:` 判定。

## 读法

1. 先读 00 总纲的 §2 语义域（尤其 §2.2「基础方言无子类型」这条根本事实）与 §4.1 主题归属裁决表，建立坐标；
2. 按需跳卷——每卷独立可读，跨卷符号在总纲 §6 登记；
3. **主题只在一卷定义**：每个主题有唯一权威卷（总纲 §4.1 裁决表），其余卷只交叉引用、不重复定义。若发现两卷讲同一主题且口径不一，以权威卷为准并按总纲 §8 勘误；
4. 规则名带前缀（T-/U-/C-、P-/R-/A-、G-、E-/K-、M-、V-、J-、X-、N-、H-、B-、F-），命名空间裁决见总纲 §6.2；`F-` 前缀专属第 12 卷方言；
5. **`待核` 标记** = 该行为未完全坐实，见各卷末清单与总纲 §7.2；**`⚠️ 单源待校验`** = 该结论只有一个来源、尚未取得第二个独立来源；
6. 三层标注：〔实现现状〕（源码坐实，给 file:line）／〔规格〕（应当满足但尚未实现）／〔待核〕（源码不足以下结论）——阅读时注意区分，尤其第 12 卷几乎全是〔规格〕。

## 本轮重写的三项实质改动

1. **补入"基础方言无子类型"这条根本事实**（总纲 §2.2）：旧卷集完全未提，是此前最大的语义漏洞——读者容易把 `≈`/`@mut` 转换/数值升格误当成子类型。
2. **确立单一权威卷原则**（总纲 §4.1 主题归属裁决表）：旧卷集按实现模块切分，导致 `@mut` 与拷贝规则散在 01/04、Γ 与弥散散在 02/03、when 定型散在 01/05、三阶段检查散在 08/10。现在每个主题只认一卷为权威，其余卷只能引用。
3. **回填六项已核实结论、清理过时待核**（总纲 §7.1）：诊断码表实测 107/109 条且 Severity 实为四级（旧记"约 100 条/三族"）、`__dc` 函数穿透与运行时注入触发条件已坐实、注解处理器轮次上限实测 R=5、`constraintListAhead` 歧义已解决、`printable` 与 `D-BY` 两处旧记载证伪删除。
