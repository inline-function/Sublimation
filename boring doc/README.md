## 读法

1. 先读 00 总纲的 §2 语义域与 §4 卷分工，建立坐标；
2. 按需跳卷——每卷独立可读，跨卷符号在总纲 §6 登记；
3. 规则名带前缀（T-/P-/R-/G-/E-/K-/M-/V-/J-/X-/N-/H-/B-），命名空间裁决见 00 总纲 §3.8 与 §4；
4. **待核**标记 = 该行为未完全坐实，见各卷末清单与 00 总纲 §7。
