## 一、本卷定位与判断形式

### 1.1 本卷定义什么

本卷给出凝华语言**运行期**的形式化语义。一个树遍历解释器（`Evaluator`，Evaluator.kt:8）对已通过 Checker 静态检查的 AST 做大步求值（big-step evaluation）。求值不重复类型系统的职责——类型、纯度、命题义务在编译期完成，运行期仅保留值层面的操作与显式错误拒绝。

基础方言无子类型关系。本卷不引入 `<:` 符号。Kernel Fω<: 方言属第 12 卷范畴。

### 1.2 判断形式

$$\frac{\text{前提}_1 \qquad \text{前提}_2 \qquad \cdots}{\sigma \vdash e \Downarrow v} \quad (\text{V-规则名})$$

其中 σ 为求值帧（ScriptFrame，§三），e 为 AST 表达式，v 为值域 Val（§二）中的值。语句判断统一为：

$$\frac{\sigma \vdash s \Downarrow v}{\sigma \vdash s \Downarrow v} \quad (\text{V-STMT})$$

万物皆表达式（总纲 §1.3）：语句的值固定为 Null，或发散标记。求值的三个出口：

1. **正常值**：σ ⊢ e ⇓ v，v ∈ Val；
2. **运行时错误**：σ ⊢ e ⇓ ⊥(msg)，InterpreterError 沿 Kotlin 调用栈抛出（ScriptFrame.kt:90）；
3. **return 异常**：σ ⊢ e ⇓ return(v)，ReturnException 由最近的函数体边界拦截（Evaluator.kt:999-1000）。

### 1.3 引用语义基线

值跨宿主边界一律引用语义（ScriptValue.kt:6）：脚本改宿主对象即改宿主对象本体。深拷贝仅在 §六规定的显式路径触发。这两条路径——引用语义（跨边界默认）与拷贝语义（bindCopy 判据成立时）——属于不同层面，不得混淆。

## 二、值域 Val

### 2.1 值构造子

值域由 sealed class `ScriptValue`（ScriptValue.kt:19）给出：

$$v ::= \text{Num}(\mathbb{Z}) \mid \text{Real}(\mathbb{R}) \mid \text{Str} \mid \text{Bool} \mid \text{Null} \mid \text{ListV} \mid \text{Struct} \mid \text{OptionalV} \mid \text{ResultV} \mid \text{Fun} \mid h$$

| 构造子 | 载荷 | 源码位置 | 说明 |
|---|---|---|---|
| Num | Long | ScriptValue.kt:22 | Nat/Int 整数 |
| Real | Double | ScriptValue.kt:27 | Rat 浮点 |
| Str | String | ScriptValue.kt:31 | 字符串 |
| Bool | Boolean | ScriptValue.kt:35 | 布尔 |
| Null | 单例对象 | ScriptValue.kt:39 | Null 类型唯一成员 |
| ListV | MutableList\<ScriptValue\> | ScriptValue.kt:44 | List 与元组的运行时载体 |
| Struct | (typeName, 字段表, 可变字段集) | ScriptValue.kt:51 | 结构体、enum 构造子、宿主注入类型、Range |
| OptionalV | ScriptValue?（null 表示 None） | ScriptValue.kt:61 | Optional[T] |
| ResultV | (isOk, value?, error?) | ScriptValue.kt:66 | Result[T,E] |
| Fun | ScriptFunction | ScriptValue.kt:71 | 宿主函数与脚本闭包的统一接口 |
| h | 宿主穿透值 | 11 卷 | 跨边界引用语义 |

Struct 的 mutableFields 是类型元数据（只读共享），深拷贝时仅复制值字段（Evaluator.kt:149-150）。OptionalV 以内部 null 表示 None。ResultV 分 Ok(isOk=true)/Err(isOk=false) 两态。Fun 统一包装宿主函数与脚本闭包，**按标识判等，不按结构**（ScriptValue.kt:72-73，equals 重写为 `===`）。

### 2.2 类型→值映射

| 类型 τ | 值 v | 宿主（Kotlin）态 |
|---|---|---|
| Nat / Int | Num(Long) | Long |
| Rat | Real(Double) | Double |
| Str | Str(String) | String |
| Bool | Bool(Boolean) | Boolean |
| Null | Null | null |
| List[T] / 元组 | ListV | List\<*\> |
| Optional[T] | OptionalV | 宿主边界解包为内值或 null |
| Result[T,E] | ResultV | 保留 ScriptValue 身份 |
| 结构体 / 宿主注入类型 | Struct | 保留 ScriptValue 身份 |
| 函数值 | Fun | ScriptFunction |

实现决策：① 元组无独立构造子，TupleExpr 求值为 ListV（:242），解构参数按编码名拆分量（:841-851）；② Struct/ResultV 跨界保留身份（toHost :972-974），OptionalV 宿主边界解包（:973）；③ fromHost（:978-996）反向映射，兜底 toString() 成 Str。

### 2.3 值的相等性

==/!= 走 structEquals（Evaluator.kt:404-421）：

$$\frac{\sigma \vdash l \Downarrow v_1 \qquad \sigma \vdash r \Downarrow v_2 \qquad v_1 \doteq v_2}{\sigma \vdash l\ \texttt{==}\ r \Downarrow \text{Bool}(\top)} \quad (\text{V-EQ})$$

其中 ≐ 为结构相等，逐层定义：Num/Real 升格比较（1 == 1.0 为真，:407-408）；Str/Bool 按值；Null 同一单例（:411，===）；ListV 长度相等且逐元素递归（:412-413）；Struct typeName 相同、字段键集相同、逐字段递归（:414-416）；OptionalV/ResultV 递归比较（:417-419）；兜底 Kotlin ==，Fun 因此按引用身份比较（:420）。

〔待核〕SymbolCallExpr 的 `==(…)`（符号前缀调用，Evaluator.kt:700）走 Kotlin == 而非 structEquals——中缀 `a == b` 与前缀 `==(a, b)` 语义不一致。

## 三、脚本帧 σ = ScriptFrame

### 3.1 帧结构

环境 σ 是帧链（ScriptFrame.kt:7），每帧四张表：

$$\sigma ::= \sigma_0 \mid \sigma \cdot \langle \textit{vars},\ \textit{muts},\ \textit{refs},\ \textit{funs} \rangle$$

- vars：变量名 → ScriptValue 映射（LinkedHashMap，:9）；
- muts：可变变量名集合（LinkedHashSet，:10）；
- refs：引用变量名集合（LinkedHashSet，:11）；
- funs：函数名 → 重载组列表（LinkedHashMap，:12）。

可变性与引用性是变量名上的运行时标记，不在值内。

### 3.2 查找与扩展规则

$$\frac{x \in \textit{vars}(\sigma) \qquad \textit{vars}(\sigma)(x) = v}{\sigma \vdash x \mapsto v} \quad (\text{V-LOOKUP-LOCAL})$$

$$\frac{x \notin \textit{vars}(\sigma) \qquad \sigma' \vdash x \mapsto v}{\sigma \cdot \sigma' \vdash x \mapsto v} \quad (\text{V-LOOKUP-PARENT})$$

实现要点（ScriptFrame.kt）：

- lookupVar（:16-19）沿父链迭代查找（t44：深作用域链下避免 JVM 栈溢出）；
- declareVar（:28-32）在本帧声明并登记 muts/refs；
- assignVar（:34-41）先在本帧找键，否则递归委托父帧（改写定义帧的槽位，不在本帧遮蔽）；未找到抛 InterpreterError；
- isMutable/isRef（:43-52）沿父链查询标记——bindCopy 的目标侧判据由此而来；
- lookupFunctions（:60-75）合并本帧与父帧同名重载组，distinctBy(signatureKey) 去重；
- child()（:87）造子帧。

帧层次在求值中出现于：块体（Evaluator.kt:709）、函数体（:602）、impl 方法体（:635）、when 作用域与各分支（:726/:734）、lambda 调用（:868）。

## 四、大步求值规则

### 4.1 字面量

$$\frac{n \in \mathbb{Z} \qquad n = \texttt{toLongOrNull}(lit)}{\sigma \vdash lit \Downarrow \text{Num}(n)} \quad (\text{V-INT})$$

$$\frac{}{\sigma \vdash r \Downarrow \text{Real}(r)} \quad (\text{V-REAL}) \qquad \frac{}{\sigma \vdash s \Downarrow \text{Str}(s)} \quad (\text{V-STR})$$

IntLit 经 toLongOrNull 解析，失败抛 InterpreterError("非法整数")（Evaluator.kt:204-205）。

### 4.2 变量查找

$$\frac{\sigma \vdash x \mapsto v}{\sigma \vdash x \Downarrow v} \quad (\text{V-VAR})$$

名字查找分派序（Evaluator.kt:210-217）：帧内变量 → 字面量 true/false/null → None → Nil → 同名函数声明组（包成函数值，:920-934）→ 否则 InterpreterError("未定义的变量")。

### 4.3 lambda 求值为闭包

$$\frac{\phi = \langle \vec{p},\ e,\ \sigma \rangle \qquad \phi \in \text{ClosureFun}}{\sigma \vdash \{\vec{p}\ \texttt{=>}\ e\} \Downarrow \text{Fun}(\phi)} \quad (\text{V-LAMBDA})$$

evalLambda（Evaluator.kt:859-874）产出闭包型函数值，实现 ClosureFun 接口。闭包持有**定义点帧** σ。调用时以 σ 为父帧造子帧绑定形参（:868-869）。copyCapture 的实现见 §六。

匿名函数同理（Evaluator.kt:877-893）：

$$\frac{\phi = \langle \vec{p},\ e,\ \sigma \rangle}{\sigma \vdash \texttt{fun}(\vec{p})\ \texttt{=>}\ e \Downarrow \text{Fun}(\phi)} \quad (\text{V-ANONFUN})$$

### 4.4 函数调用

函数调用是本卷最重的规则。分三步：实参求值 →  callee 分派 → 体求值。

#### 4.4.1 callee 分派序

**(a) 点号 callee（o.m(args)）**——字段优先 + 方法糖回退（Evaluator.kt:444-462）：

$$\frac{\sigma \vdash o \Downarrow \text{Struct}(T,f,\cdot) \qquad m \in f \qquad f(m) = \text{Fun}(\phi)}{\sigma \vdash o.m(\vec{a}) \Downarrow \phi(\vec{a})} \quad (\text{V-FIELD-CALL})$$

若字段不命中：Range 内建方法（V-RANGE-METHOD，:456-457）→ 类型类字典分派（V-TRAIT-METHOD，:460-461）→ 自由函数重载分派（V-FREE-METHOD，:462）。

**(b) 名字 callee（f(args)）**——内建构造子特判在先（Evaluator.kt:464-499）：Some(e) → OptionalV(v)、Ok(e) → ResultV(⊤,v,·)、None → OptionalV(null)、Err(e) → ResultV(⊥,·,v)、Nil() → 空 ListV、Cons(h,t) → 头部加进尾表（尾须为 ListV，否则 ⊥）。其后：结构体构造 → 变量持有函数值 → 普通函数调用。

**(c) 其余 callee**：evalExpr 求值后须为 Fun，否则 ⊥（:501-506）。

#### 4.4.2 callFunction 分派序

callFunction（Evaluator.kt:509-538）按以下顺序分派：① `in` 且 |args|=2 → evalIn（:511）；② `listOf` → ListV(args)（:513）；③ `setOf` → buildSet（:514）；④ hostFuns 命中 → 宿主调用（:515-519）；⑤ 帧内同名函数 → pickOverload + invokeFunDecl（:521-527）；⑥ 首参 typeTag 在类型类字典中 → invokeImplMethod（:532-536）；⑦ 否则 ⊥("未定义的函数")。同名自由函数优先于类型类字典。

#### 4.4.3 函数体执行

invokeFunDecl（Evaluator.kt:598-616）：造子帧 → 绑定形参（**不经 bindCopy**，直接 declareVar，:603-606）→ 登记本函数进子帧（供递归，:608）→ 求值体 → ReturnException 截获取值。命名实参由 applyNamedArgs（:566-574）按形参名落位到位置列表，缺位补 Null。

invokeImplMethod（Evaluator.kt:634-652）：普通类型类注入 self 变量并平铺结构体字段进子帧；HKT 形态（self 带类型实参）receiver 注入首形参位。pickOverload（:655-659）按首参运行时 typeTag 匹配首形参类型。

### 4.5 结构体构造与字段访问

$$\frac{\textit{structInfo}(T) = \langle F, M, D \rangle \qquad \forall f_i \in F:\ \sigma \vdash a_i \Downarrow v_i \qquad \forall f \in F \setminus \{f_i\}:\ f \in D}{\sigma \vdash T(\vec{a}) \Downarrow \text{Struct}(T, \{f_i \mapsto v_i\} \cup \textit{defaults}, M)} \quad (\text{V-STRUCT-CTOR})$$

位置实参按 fieldNames 顺序对位（Evaluator.kt:487-488/:944-946）；缺字段若无默认值则 ⊥（:950）；默认值表达式在构造时按帧求值（:951）。

$$\frac{\sigma \vdash o \Downarrow \text{Struct}(T,f,\cdot) \qquad n \in f}{\sigma \vdash o.n \Downarrow f(n)} \quad (\text{V-FIELD})$$

$$\frac{\sigma \vdash o \Downarrow v \qquad n \notin \textit{fields}(v) \qquad \textit{methodPath}(n, v) \neq \varnothing}{\sigma \vdash o.n \Downarrow \text{Fun}(\textit{绑定}\ v)} \quad (\text{V-METHOD-PATH})$$

字段优先、不命中则尝试方法路径作值（Evaluator.kt:229-237）；对非结构体值只走方法路径，否则 ⊥。

### 4.6 运算符

$$\frac{\sigma \vdash l \Downarrow v_1 \qquad \sigma \vdash r \Downarrow v_2 \qquad \textit{op} \in \{+,-,*,\%\}}{\sigma \vdash l\ \textit{op}\ r \Downarrow \textit{arith}(v_1,v_2,\textit{op})} \quad (\text{V-ARITH})$$

arith（:313-318）：两侧转 Double 计算；任一侧为 Real 则结果 Real，否则截断回 Num。`/` 固定 Real。`+` 任一侧为 Str 则拼接（strOf :333-340）。比较走 cmp（:342-345）。& ∧ / | ∨ 走 truthy（:397-401）：Bool 取值、Null 为假、其余为真。区间 .. 求值为惰性 Range 结构（:359-364）。∈/in（:347-355）左操作数需数字，右操作数为 ListV 或 Range。

编译期算子在运行期拒绝：

$$\frac{}{\sigma \vdash l\ \texttt{=}\ r \Downarrow \bot(\text{"命题等式 '=' 是编译期概念"})} \quad (\text{V-PROP-EQ})$$

$$\frac{}{\sigma \vdash l\ \to\ r \Downarrow \bot} \quad (\text{V-PROP-IMPLIES}) \qquad \frac{}{\sigma \vdash l\ \leftrightarrow\ r \Downarrow \bot} \quad (\text{V-PROP-EQUIV})$$

一元（Evaluator.kt:429-438）：`-` 取负（Real 保持 Real，其余截断 Num），`!`/`¬` 取 truthy 的否定。

### 4.7 when 与模式匹配

$$\frac{\sigma_w = \sigma \cdot \langle\rangle \qquad \sigma_w[\textit{sb} \mapsto \sigma \vdash s \Downarrow v_s] \qquad \exists a \in \vec{a}:\ \textit{match}(p_a, v_s, \sigma_a) \wedge \textit{guard}_a(\sigma_a)}{\sigma \vdash \texttt{when}(s\ \texttt{as}\ sb)\{\vec{a}\} \Downarrow \sigma_a \vdash b_a \Downarrow v_b} \quad (\text{V-WHEN-MATCH})$$

whenFrame 限定主题绑定与分支作用域（Evaluator.kt:726）；每分支独立子帧（:734），模式变量不泄漏到下一分支或外层；无主题 when 的分支必须有 cond（:736-738）；守卫失败则 continue（:741）；首个命中的分支体求值后立即返回。

$$\frac{\forall a \in \vec{a}:\ \neg\textit{match}(p_a, v, \sigma_a)}{\sigma \vdash \texttt{when}(s)\{\vec{a}\} \Downarrow \text{Null}} \quad (\text{V-WHEN-FALL})$$

不可判穷尽的 when 固定返回 Null，不抛异常（:744，注释明言这是语言语义决定）——类型层保证穷尽、运行层宽容的分层设计。

matchPattern（:749-768）：PatLit 按 structEquals 判等；PatBind 绑定变量（_ 除外）；PatElse 恒真；PatCtor 零参小写名按绑定变量处理；其余 matchCtor（:776-816）逐构造子判定（true/false/null/Some/None/Ok/Err/Cons/Nil/自定义）。

### 4.8 块、if、return

$$\frac{\sigma_b = \sigma \cdot \langle\rangle \qquad \sigma_b \vdash s_n \Downarrow v}{\sigma \vdash \{s_1;\dots;s_n\} \Downarrow v} \quad (\text{V-BLOCK})$$

空块求值 Null（Evaluator.kt:710）；块内 var 声明留在子帧。仅末条语句承尾位（:713）。

$$\frac{\sigma \vdash c \Downarrow v \qquad \textit{truthy}(v)}{\sigma \vdash \texttt{if}\ c\ t\ \texttt{else}\ e \Downarrow \sigma \vdash t \Downarrow v_t} \quad (\text{V-IF-T})$$

$$\frac{\sigma \vdash c \Downarrow v \qquad \neg\textit{truthy}(v)}{\sigma \vdash \texttt{if}\ c\ t\ \texttt{else}\ e \Downarrow \sigma \vdash e \Downarrow v_e} \quad (\text{V-IF-F})$$

无 else 分支返回 Null（Evaluator.kt:721）。

$$\frac{\sigma \vdash e \Downarrow v}{\sigma \vdash \texttt{return}\ e \Downarrow \texttt{return}(v)} \quad (\text{V-RETURN})$$

return 以 ReturnException 实现（Evaluator.kt:188-189），拦截点仅在函数体边界（invokeFunDecl :613、invokeImplMethod :651、evalLambda :871、evalAnonFun :889、funDeclAsValue :913、FunRefExpr 绑定闭包 :265、methodPathValue 绑定闭包 :559）。顶层 return 不在任何函数体内，异常泄漏为运行时错误。

### 4.9 编译期位的求值退化

以下 AST 位固定返回 Null（:191-197/:271-273）：AxiomStmt、ByStmt、BTSStmt、WhenPropStmt、IfPropStmt、StrategyStmt、ExistIntroStmt、ExistsElimStmt、FunStmt、QuantExpr、TopExpr、BotExpr、ReturnSym。命题层在运行时完全擦除。

$$\frac{}{\sigma \vdash \textit{命题位} \Downarrow \text{Null}} \quad (\text{V-PROP-VOID})$$

明确抛 ⊥ 的位：TaskExpr/FlowExpr（:270）、IsPatExpr（:228/:241）、ParamRefExpr（:274）、§4.6 编译期算子。

### 4.10 插值解糖的求值

字符串插值在解析期脱糖（Parser.kt:1258-1299），不引入新 AST 节点。因此在求值层没有独立的插值规则——它落回 V-ARITH 的 + Str 拼接语义与宿主 concat/toStr。

### 4.11 语句的值

所有语句（VarStmt、AssignStmt、ReturnStmt 除外）的值固定为 Null：

$$\frac{\sigma \vdash e \Downarrow v \qquad \textit{bindCopy 判定}}{\sigma \vdash \texttt{var}\ x = e \Downarrow \text{Null}} \quad (\text{V-VAR-STMT})$$

$$\frac{\sigma \vdash e \Downarrow v \qquad \textit{bindCopy 判定}}{\sigma \vdash x = e \Downarrow \text{Null}} \quad (\text{V-ASSIGN})$$

VarStmt 返回值 Null（Evaluator.kt:168）；AssignStmt 返回值 Null（:184）；ExprStmt 返回内部表达式的值（:186）。

## 五、deepCopy 与闭包捕获

### 5.1 deepCopy 规则

deepCopy（Evaluator.kt:145-158）逐构造子递归：

$$\frac{}{\textit{dc}(\text{Struct}(T,f,m)) = \text{Struct}(T,\ \{k \mapsto \textit{dc}(f(k))\},\ m)} \quad (\text{V-DC-STRUCT})$$

$$\frac{}{\textit{dc}(\text{ListV}(\vec{v})) = \text{ListV}(\textit{dc}(\vec{v}))} \quad (\text{V-DC-LIST})$$

$$\frac{}{\textit{dc}(\text{OptionalV}(v?)) = \text{OptionalV}(\textit{dc}(v)?)} \quad (\text{V-DC-OPT})$$

$$\frac{}{\textit{dc}(\text{ResultV}(b,v?,e?)) = \text{ResultV}(b,\textit{dc}(v)?,\textit{dc}(e)?)} \quad (\text{V-DC-RESULT})$$

$$\frac{\phi \in \text{ClosureFun}}{\textit{dc}(\text{Fun}(\phi)) = \phi.\textit{copyCapture}()} \quad (\text{V-DC-FUN-CLOSURE})$$

$$\frac{\phi \notin \text{ClosureFun}}{\textit{dc}(\text{Fun}(\phi)) = \text{Fun}(\phi)} \quad (\text{V-DC-FUN-HOST})$$

Num/Real/Str/Bool/Null 不可变，拷贝即自身（:157 else 分支）。mutableFields 元数据只读共享（:149-150）。

### 5.2 copiedFrame：沿父链的完整快照

copiedFrame（Evaluator.kt:130-143）沿父链收集全部帧，再外层优先地逐名字深拷装入新帧：

$$\frac{\sigma^* = \textit{reverse}(\sigma \cdots \sigma_0)}{\textit{copiedFrame}(\sigma) = \textit{fold}(\varnothing, \sigma^*)} \quad (\text{V-COPIED-FRAME})$$

具体步骤：收集父链 → 外层优先遍历 → 逐名字深拷装入新帧（:135-138）→ 可变/引用标注按源帧保留 → 局部函数一并登记（:140）。

〔待核〕:137 的查找用 f.lookupVar(n)（最内层解析）而非 fr.lookupVar(n)——若外层名字被内层遮蔽，外层名字会拿到内层值。需确认是有意遮蔽还是实现疏漏。

### 5.3 copyCapture：闭包捕获深拷贝

copyCapture 的实现（evalLambda :866 / evalAnonFun :884）：

$$\textit{copyCapture}(\langle \vec{p},\ e,\ \sigma \rangle) = \langle \vec{p},\ e,\ \textit{copiedFrame}(\sigma) \rangle$$

即用快照帧替换定义帧重新造一个 lambda。此后对原帧的写操作与该函数值绝缘。这是 I-5 纯度守恒的运行期体现（总纲 §5）。

对照示例（.subs 脚本模式）：

```subl
var n = 10
var f = { => n }
n = 20
print(f())          // 20
@mut var g = f      // bindCopy → deepCopy(Fun) → copyCapture
n = 30
print(g())          // 20（捕获被深拷冻结）
```

### 5.4 拷贝只落在三个绑定点

bindCopy 的唯一三处调用（Evaluator.kt）：VarStmt（:166）、AssignStmt 的 NameRef 目标（:174）、表达式位 VarExpr（:248）。因此：

- 函数形参绑定不拷贝（invokeFunDecl :603-606 / invokeImplMethod :644-646 / bindLambdaParams :841-851 都是直接 declareVar）；
- 字段赋值不拷贝（AssignStmt 的 FieldExpr 目标直接 obj.fields[name] = v，:179）；
- 结构体构造的字段表达式不拷贝（evalStructCtor 直接 evalExpr 装入，:945）。

## 六、bindCopy 的求值期执行

### 6.1 谓词定义

bindCopy（Evaluator.kt:112-119）与编译期 binderNeedsCopy 是同一谓词、同一判据。四条规则的定义见 04 卷 §2；本卷给出求值期的执行语义。

$$\textit{copy} \iff (m_t \wedge (\neg r_t \vee p_s)) \vee (m_s \wedge p_t) \vee (r_s \wedge \neg r_t)$$

其中 $p_t/r_t/m_t$ = 目标纯 / 不带 ref / 带 mut；$p_s/r_s/m_s$ = 源纯 / 带 ref / 带 mut。

### 6.2 求值期执行

$$\frac{\sigma \vdash e \Downarrow v \qquad \textit{copy}(\mu_{tgt} \leftarrow \mu_{src})}{\sigma \vdash \texttt{var}\ x : \tau = e \Downarrow \text{Null} \quad [\sigma[x \mapsto \textit{dc}(v)]]} \quad (\text{V-BIND-COPY})$$

$$\frac{\sigma \vdash e \Downarrow v \qquad \neg\textit{copy}(\mu_{tgt} \leftarrow \mu_{src})}{\sigma \vdash \texttt{var}\ x : \tau = e \Downarrow \text{Null} \quad [\sigma[x \mapsto v]]} \quad (\text{V-BIND-SHARE})$$

源/目标维度的提取（Evaluator.kt:121-126）：sourceIsRef 查帧 isRef；sourceIsMut 查帧 isMutable。目标维度来自语句注解（VarStmt :164-165）或帧标记（AssignStmt :174）。

〔待核〕VarExpr 位（:248）把 ref 误作 targetMut 传入 bindCopy 的第 4 实参——`@mut var x = e` 在表达式位的目标 @mut 维度可能错位。

### 6.3 引用语义边界

bindCopy 的拷贝语义与 §1.3 的引用语义属不同层面：引用语义是跨宿主边界/形参绑定/字段赋值的默认行为（不拷贝）；拷贝语义仅在 var 声明与赋值两个绑定点、且 bindCopy 判据成立时触发。二者不冲突。

## 七、unchecked 的运行时语义

$$\frac{\sigma \vdash s \Downarrow v}{\sigma \vdash \texttt{unchecked}\ s \Downarrow v} \quad (\text{V-UNCHECKED})$$

求值器对 UncheckedStmt 直接执行 inner（Evaluator.kt:196）——无运行时闸门、无深度计数、无动态检查回退。unchecked 纯粹是编译期开关（Checker uncheckedDepth++），放行的闸门（E-IMMUT-ASSIGN、pure 传播、CallCheck Any 准入、impure 调用闸、async-in-sync 闸）在运行期本来就不存在，故直通是唯一可实现的行为。

JS 编译端对 unchecked 语句生成 `// unchecked` 注释后透传（JsCodeGen.kt:822）——两端语义一致。

## 八、错误路径

### 8.1 InterpreterError

$$\frac{}{\sigma \vdash e \Downarrow \bot(\textit{msg})} \quad (\text{V-ERR})$$

InterpreterError（ScriptFrame.kt:90）是 RuntimeException。主要 ⊥ 位：未定义变量（Evaluator.kt:217）、非法整数（:205）、运算符需数字（:321-322）、编译期算子（:288/:301/:302）、不可调用（:506）、结构体缺字段/无字段（:234-236/:950）、未定义函数（:538）、方法消歧（:625）、赋值目标非法（:180/:182）、异步不支持（:270）。

### 8.2 ReturnException

return 抛 ReturnException(v)（:188-189），拦截点仅为函数体边界（invokeFunDecl/evalLambda/evalAnonFun/funDeclAsValue/FunRefExpr/methodPathValue 等）。顶层 return 无拦截，泄漏为 RuntimeException。

### 8.3 panic

panic 在类型层是内建纯函数（Types.kt:180：无参、返回 Nothing）。解释器未注册 panic 的运行时实现（Interpreter.kt registerStdlib 无 panic 条目）。因此脚本模式一旦执行到 panic()：

$$\frac{\textit{hostFuns}(\texttt{panic}) = \varnothing \qquad \sigma(\texttt{panic}) = \varnothing}{\sigma \vdash \texttt{panic}() \Downarrow \bot(\text{"未定义的函数「panic」"})} \quad (\text{V-PANIC-SCRIPT})$$

编译模式的对应行为是 `throw new Error('panic: unreachable')`（JsCodeGen.kt:1256）。两端不等价：脚本模式把 unreachable 变成了「未定义函数」错误而非显式停机断言。

〔待核〕这是否为有意省略，还是解释器实现的遗漏。

### 8.4 unwrapOr 与容错路径

unwrapOr(r, d) 是 core/collection/result.subl:25 的普通库函数（无内建特判），求值落回 V-WHEN-MATCH + V-STRUCT-CTOR：Ok → ResultV(⊤,v,·) 命中 `is Ok(v) => v`，Err → 回退 d。这条错误路径不依赖运行时特权，是标准库可自身表达的证据。

### 8.5 其他非异常出口

when 不可判穷尽 → Null（:744）；宿主函数返回 null → Null（:979）；缺位实参/形参 → 补 Null；宿主函数自身抛异常 → 直达 CLI RuntimeException 出口。

## 九、边界与待核清单

### 9.1 与 JS 编译端的差异入口

差异集中在深拷贝与内建落地方式（细节属 07 卷）：① 深拷贝对函数：解释器 copyCapture 捕获一并深拷，JS 端 __dc 对函数穿透（既定边界）；② panic：脚本模式无运行时实现，编译模式 throw new Error；③ unchecked：两端一致（直通/注释透传）；④ Range：解释器 Struct + evalRangeMethod，JS 端 __range 助手；⑤ 数值：解释器 Long/Double 二分，JS 端统一 Number。
