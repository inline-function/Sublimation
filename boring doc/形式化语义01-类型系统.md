## 0. 记号与判断形式

本卷规则前缀：`T-`（定型）、`U-`（合一）、`C-`（转换）。这是总纲 §6.2 分配给 01 卷的前缀，不得改用 `F-`（`F-` 属第 12 卷规格层）。

| 判断 | 读法 | 实现对应 |
|---|---|---|
| `Σ ⊢ τ : Type` | 类型 τ 良构（可解析、kind 正确） | checkTypeResolvable（Symbols.kt:325） |
| `Γ ⊢ e : τ` | 上下文 Γ 下表达式 e 定型为 τ | checkExpr（Checker.kt:922） |
| `τ ≡ σ` | 严格相等 | typeEq（Types.kt:323） |
| `τ ≈ σ` | 宽松相容（定型核对用） | typeLooseEq（Diffusion.kt:417） |
| `unifyInto(τ, σ, V, S)` | 限定 V 内的合一，写入替换表 S | unifyInto（TypeInfer.kt:18） |
| `Γ ⊢ copy(τ_t, μ_t, ρ_t ← τ_s, μ_s, ρ_s)` | 绑定发生深拷贝 | binderNeedsCopy（Checker.kt:865） |

**上下文** Γ 是四元组 `Γ = (Δ, M, R, Π)`：

- `Δ : Var → Type` —— 变量类型环境，Frame.vars 沿父链查找（lookupVar，Diffusion.kt:23）；
- `M ⊆ Var` —— 可变变量集（declareMut / isMut，Diffusion.kt:27—28，由 `@mut` 声明注解登记）；
- `R ⊆ Var` —— 引用别名变量集（declareRef / isRef，Diffusion.kt:29—30，由 `@ref` 声明注解登记）；
- `Π` —— 命题事实集（Frame.facts，allFacts 沿父链并集，Diffusion.kt:41）。

全局符号表 Σ（Symbols，Types.kt:355）提供 struct/enum/class/fun/ctor/alias 查表。检查模式位（纯度 pure、uncheckedDepth、flow、funRetType）是 Γ 的附加标志，在下文相关规则中显式出现。

**类型变量的定义**（TypeInfer.kt:22—23）：vars 集合 V 内的零实参 NamedType 是类型变量。即 `α ∈ V` 当且仅当 `τ = NamedType(α, [])` 且 `α ∈ V`。

## 1. 类型语法域

### 1.1 类型的归纳生成

$$\frac{}{\text{NamedType}(n, [\tau_1 \dots \tau_k]) \in \text{Type} \qquad n \text{ 是标识符，} k \ge 0} \quad (\text{T-NAMED})$$

$$\frac{\tau_1 \in \text{Type} \dots \tau_k \in \text{Type} \qquad \tau_r \in \text{Type} \qquad \pi \in \{\text{""}, \text{"impure"}\} \qquad \Theta \text{ 是类型参数表} \qquad C \text{ 是上下文命题列表或空}}{\text{FunType}([\tau_1 \dots \tau_k], \tau_r, \pi, \Theta, C) \in \text{Type}} \quad (\text{T-FUN})$$

$$\frac{\tau_1 \in \text{Type} \dots \tau_k \in \text{Type}}{\text{TupleType}([\tau_1 \dots \tau_k]) \in \text{Type} \qquad k \ge 0} \quad (\text{T-TUPLE})$$

$$\frac{\tau \in \text{Type}}{\text{MutType}(\tau) \in \text{Type}} \quad (\text{T-MUT})$$

$$\frac{\tau \in \text{Type}}{\text{AtomicType}(\tau) \in \text{Type}} \quad (\text{T-ATOMIC})$$

$$\frac{\tau_1 \in \text{Type} \dots \tau_k \in \text{Type} \qquad k \ge 2}{\text{UnionType}([\tau_1 \dots \tau_k]) \in \text{Type}} \quad (\text{T-UNION})$$

$$\frac{}{\text{QualifiedType}(m, n, [\tau_1 \dots \tau_k]) \in \text{Type} \qquad m \text{ 是模块路径段列表}} \quad (\text{T-QUAL})$$

语法与 AST 节点对应（Ast.kt:136—231）：

| 语法形态 | AST 节点 | 备注 |
|---|---|---|
| Nat、List[Nat]、T | NamedType | 名义类型与类型参数引用同节点 |
| `(A) => B`、`() => Null`、`[T](T) => T`、`@impure (A) => Null` | FunType(params, ret, purity, theory, context) | theory 为多态理论参数；context 为上下文命题 |
| `(A, B)` | TupleType | EmptyTuple / SingleTuple[T] 走 NamedType 具名形态 |
| `@mut T` | MutType(inner) | 类型位注解 |
| `@atomic T` | AtomicType(inner) | 类型位注解 |
| `A \| B \| C` | UnionType(variants) | Parser 解析竖线 |
| `core.Point` | QualifiedType(module, name, args) | 展开时折叠为同简单名 NamedType（Types.kt:392） |
| `type F[a] = Optional[a]` | TypeAliasDecl | 展开规则见 §1.5 |

**类型位注解仅支持三种**：`@mut`、`@atomic`、`@impure`，其余一律解析失败。`@impure` 只能修饰函数类型（写入 purity 字段）。

### 1.2 @ref 的结构地位

语言事实表以「类型形态」口径列出 T / `@mut T` / `@ref T` / `@ref @mut T`。**实现层中 `@ref` 不是类型域构造子**：Parser 的类型位不识别 `@ref`，它是**变量声明注解**，由 Checker 登记进帧的 R 集：

```subl
@ref var a : @mut T = T(0)      // ρ(a) = 真；类型仍是 @mut T
@ref var b : @mut T = a         // 双侧 @ref → 别名共享（不拷贝）
```

因此本卷将 `@ref` 形式化为变量层属性 `ρ(x) ∈ {真, 假}`（Frame.isRef，Diffusion.kt:30），而 `@ref @mut T` 的组合语义 = `@ref` 变量持有 `@mut T` 类型。是否存在类型位的 `@ref T` 语法 **待核**。

### 1.3 元层分类

| 分类 | 判据 | 用途 |
|---|---|---|
| 名义类型 | NamedType 且首字母大写且非合成；或 QualifiedType | 决定按名字比对（Types.kt:43—45） |
| 数值类型 | Nat / Int / Rat 且零实参 | 数值升格（isNumeric，Diffusion.kt:449） |
| 合成类型 | NamedType 且名以 `(推导:` 起始且零实参 | 推导期占位，比对恒放行（Types.kt:19—20） |
| 非密封类型 | NamedType("(未密封)") | 非穷尽 when 的值类型，仅与 Null 相容（Types.kt:52—53） |
| 底类型 | NamedType("Nothing") 零实参 | 与任何类型相容（isNothing，Diffusion.kt:452） |
| 透明标记 | AtomicType | 与内层类型等价（typeEq EQ-ATOMIC，Types.kt:333—335） |

函数类型与元组类型**不是**名义类型（哨兵名 `"(fn)"` / `"(tuple)"` 不可能撞用户标识符，Ast.kt:131—135）。

### 1.4 内建类型

BASE_TYPES（Types.kt:10—16）：Nat、Int、Rat、Real、Str、Bool、Null、Nothing、Any、EmptyTuple、SingleTuple、Task、Channel、Mutex、Flow、Range、Json。prelude 每模块注册三个枚举：`Bool {true, false}`、`Null {null}`、`Optional[T] {None, Some(T)}`（Checker.kt:186—189）。

Any 是受限顶类型兼自动类型类（autoTraits 仅含 Any，Types.kt:8）；只在**期望位**豁免——形参位（CallCheck.kt:42/677）、返回位 4 处（Checker.kt:404/791/1129/1327 + Types.kt isAnyExpect）、默认值位（Symbols.kt:227/240）、变长回退（CallCheck.kt:885）。实际侧仍严格（实参是 Any 而期望是具体类型时不放宽）。旧文档的 E-ANY-STRUCT / E-ANY-CALL 已废弃不再触发。

### 1.5 类型别名展开

$$\frac{\Sigma(n) = \text{TypeAliasDecl}(n, [a_1 \dots a_k], \sigma)}{\text{expand}(\text{NamedType}(n, [\tau_1 \dots \tau_k])) = \text{expand}(\sigma[a_1 := \tau_1, \dots, a_k := \tau_k])} \quad (\text{T-ALIAS})$$

展开按位置逐位代入、递归至不含别名、深度上限 16 防环（Symbols.expand，Types.kt:389—414）。别名与目标类型在类型检查中完全互通；与既有 struct/enum/class/基类型重名报 E-DUP-DECL。所有宽松相容判定（typeLooseEq）**必须先展开别名**（决策 30，Diffusion.kt:418）。

## 2. 定型规则

### 2.1 字面量

$$\frac{}{\Gamma \vdash n : \text{Nat} \qquad n \text{ 是整数字面量}} \quad (\text{T-INT})$$

$$\frac{}{\Gamma \vdash r : \text{Rat} \qquad r \text{ 是浮点字面量}} \quad (\text{T-FLOAT})$$

$$\frac{}{\Gamma \vdash s : \text{Str} \qquad s \text{ 是字符串字面量}} \quad (\text{T-STR})$$

$$\frac{}{\Gamma \vdash \text{true} : \text{Bool} \qquad \Gamma \vdash \text{false} : \text{Bool}} \quad (\text{T-BOOL})$$

$$\frac{}{\Gamma \vdash \text{null} : \text{Null}} \quad (\text{T-NULL})$$

实现：IntLit → Nat（Checker.kt:923—926，同时向 Π 注入 `n ≥ 0` 自然命题）；FloatLit → Rat（Checker.kt:928）；StrLit → Str（Checker.kt:929）。true / false / null 是 prelude 枚举的零参构造子，走下文 T-CTORVAL 路径。

### 2.2 变量与名字引用

$$\frac{\Delta(x) = \tau}{\Gamma \vdash x : \tau} \quad (\text{T-VAR})$$

附加效应：标记 x 已用（markUsed，消除 W-UNUSED）；若处于 lambda 体内且 x 申明于外层且 `μ(x)`，则标记当前 lambda 不纯（P-3，Checker.kt:943）。

$$\frac{x \notin \Delta \qquad \Sigma_{\text{ctor}}(x) = \text{构造子} \in E \qquad \Theta = E \text{ 的类型参数表}}{\Gamma \vdash x : E[\alpha \mapsto \text{synthetic}(\alpha)] \qquad \alpha \in \Theta} \quad (\text{T-CTORVAL})$$

零参构造子作值引用时带多态参数（`None : Optional[T]` 对任意 T，Checker.kt:948—953）。

$$\frac{x \notin \Delta \qquad \Sigma_{\text{fun}}(x) = f \qquad f = (\vec{p}, r, \Theta)}{\Gamma \vdash x : (\vec{p}) \Rightarrow r \quad \text{（理论参数 } \Theta \text{ 随行）}} \quad (\text{T-FUNREF})$$

函数名作值即其**函数类型**：形参类型列表 + 返回类型（显式标注优先，省略时取推导表 inferredRets，兜底 Null；Checker.kt:954—966）。

$$\frac{x \notin \Delta \qquad x \text{ 不匹配构造子/结构体/函数}}{\Gamma \vdash x : \text{synthetic}("\text{未定义}") \qquad \text{报 E-UNBOUND-NAME}} \quad (\text{T-UNBOUND})$$

未定义名不阻塞检查：填合成类型承接（Checker.kt:968）。

### 2.3 lambda（双向推导）

$$\frac{\text{expect} = (\vec{\sigma}) \Rightarrow \sigma_r \qquad |\vec{x}| \ne |\vec{\sigma}|}{\Gamma \vdash \{\vec{x} => e\} : \text{报 E-TYPE-MISMATCH}} \quad (\text{T-LAMBDA-ARITY})$$

$$\frac{\Delta' = \Delta \uplus [x_i \mapsto \sigma_i] \qquad \Gamma' = (\Delta', M, R, \Pi) \qquad \Gamma' \vdash e : \tau \qquad \tau \approx \sigma_r \lor \sigma_r \text{ 是未解析类型参数} \lor \tau \text{ 是合成类型}}{\Gamma \vdash \{\vec{x} => e\} : (\vec{\sigma}) \Rightarrow \tau} \quad (\text{T-LAMBDA-EXPECT})$$

$$\frac{\text{无 expect} \qquad \Gamma' \vdash e : \tau \qquad \Delta' = \Delta \uplus [x_i \mapsto \text{synthetic}("\text{参数}")]}{\Gamma \vdash \{\vec{x} => e\} : (\text{synthetic}, \dots) \Rightarrow \tau} \quad (\text{T-LAMBDA-FREE})$$

实现要点（Checker.kt:1107—1171）：

- 参数类型从期望函数类型反推（T2 双向推导，决策 55/57）；解构参数 `(a, b)` 按期望的元组 items / 结构体字段绑定（Checker.kt:1120—1136）；
- 期望返回是**未解析类型参数**时跳过核对（决策 78：由调用点反推，报了是误报，Checker.kt:1153—1155）；
- **返回组合类型**：有期望时返回 FunType(期望参数, 实际体类型)——调用点据此反推类型参数；
- **多态继承**：lambda 满足多态函数类型位（如 `[T](T) => T`）时继承期望的 theory，保持可实例化（Checker.kt:1170）；
- **纯度跟踪**：体内发生 impure 调用或读写外层可变变量 → FunType.purity = "impure"（v3.0 完美函数类型，Checker.kt:1164—1169）；
- 纯 lambda 注册自然命题 `pure<{ … }>`（Checker.kt:1168）。

匿名函数 `fun(x: A): B = e`（AnonFunExpr）的规则与之同构，区别是形参带显式类型、可自带 theory 与前后件，返回真函数类型（Checker.kt:1335—1376）。

### 2.4 应用与实例化

$$\frac{\Gamma \vdash f : (\vec{\sigma}) \Rightarrow \sigma_r \qquad \Gamma \vdash e_i : \tau_i \qquad \text{inst}(\Theta) = S \qquad \forall i.\ \tau_i \approx \sigma_i[S] \qquad C[S] \text{ 可证}}{\Gamma \vdash f\langle \vec{\kappa} \rangle(e_1, \dots, e_k) : \sigma_r[S]} \quad (\text{T-APP})$$

其中 `inst(Θ) = S` 是实例化替换，求法为**显式优先 + 定点反推 ≤8 轮**（CallCheck.kt:785—836）：

1. 显式类型实参 `f<Nat>(…)` 先绑定 S（一次绑定，后续不覆盖，CallCheck.kt:789—793）；
2. 非合成实参逐位 extractTpBinding(σ_i, τ_i, V, S) → unifyInto（CallCheck.kt:795—799）；
3. **lambda 实参带期望类型二次检查**并以其**实际返回类型反推**类型参数，整个检查包入定点循环：每轮按当前 S 重解参数，直到 S 无新解或达 **8 轮上限**（防环）；循环后诊断去重（d.dedupe()）。

定点迭代是必要的：链式泛型（`compose[A,B,C](f:(B)=>C, g:(A)=>B, x:A): C`）中 f 的返回 C 要等 g 解出 B 才可知，按声明序单轮检查无法解出。

实参核对的四个宽容位（CallCheck.kt:839—892）：

- 形参代入后仍是**裸类型变量**（wantIsTv）→ 任意实参放行；
- 形参是 Any 且零实参 → 任意实参放行（决策 59）；
- 形参是联合类型 → 实参命中任一变体即放行；
- 实参是合成类型 → 跳过（「有证据才报错」）。

其余不符报 E-TYPE-MISMATCH；实参个数不符报 E-ARITY（CallCheck.kt:781）；函数类型携带的上下文命题不可证报 E-CTX-UNPROVEN。

**函数值调用**（多态函数值存于变量后调用）：显式实例化后逐位核对实参与实例化形参；无显式实例化时逐位 unifyInto 反推；impure 函数值在纯上下文调用报 E-IMPURE-CALL。

**实例化表达式作值**（`id<Nat>` 不跟调用）：返回实例化后的函数类型（Checker.kt:1080—1089）。

### 2.5 结构体与枚举构造

$$\frac{\Sigma(S) = \text{struct } S(f_1 : \sigma_1, \dots, f_k : \sigma_k) \qquad \Gamma \vdash e_i : \tau_i \qquad \tau_i \approx \sigma_i[S] \qquad \Gamma \vdash p_j[f_i := e_i]\ (j = 1..m)}{\Gamma \vdash S(e_1, \dots, e_k) : S[S]} \quad (\text{T-STRUCT})$$

$$\frac{\Sigma(C) = \text{构造子} \in E \text{，字段类型 } \vec{\sigma} \qquad \Gamma \vdash e_i : \tau_i \qquad \tau_i \approx \sigma_i}{\Gamma \vdash C(e_1, \dots, e_k) : E[\text{实参}]} \quad (\text{T-CTOR})$$

- 位置构造：ctor 元数不符报 E-TYPE-MISMATCH，字段类型不符报 E-TYPE-MISMATCH；
- 命名字段构造 `A(name = e)`：按字段名核对，缺字段且无默认值报 E-FIELD-MISSING，重复字段报 E-DUP-FIELD，同样反推类型实参（checkStructCtor，CallCheck.kt:24—53）；
- 第二前提是**伴生命题义务**：结构体 `struct Student<score <= 100>` 的构造在代入实参后须证出伴生命题；
- `var t = Test(m)` 声明后向 Π 注入 `t.n = 实参` 等绑定等式与伴生命题。

### 2.6 when 与 if

$$\frac{\Gamma \vdash \text{subj} : \tau_s \qquad \forall i.\ \Gamma, \neg p_1, \dots, \neg p_{i-1}, p_i \vdash b_i : \tau_i \qquad \tau = \text{join}(\tau_1, \dots, \tau_n) \qquad p_1 \lor \dots \lor p_n \text{ 可由 } \Pi \text{ 证出}}{\Gamma \vdash \text{when}(\text{subj}) \{ p_i \Rightarrow b_i \} : \tau} \quad (\text{T-WHEN-EXH})$$

$$\frac{\text{（同上前提，但穷尽性不可判定）}}{\Gamma \vdash \text{when}(\text{subj}) \{ p_i \Rightarrow b_i \} : \text{(未密封)}} \quad (\text{T-WHEN-UNSEALED})$$

实现要点（WhenCheck.kt）：

- 分支命题：字面/构造子模式 → `subj = pat`；`is T` → `subj : T`；`else` / `_` → ⊤；
- **顺序敏感**：第 i 分支帧注入前 i−1 个分支命题的否定（WhenCheck.kt:131）；
- else 对联合主题做**反收窄**：剩余变体（WhenCheck.kt:139—145）；
- 分支类型 join 用 TypeInfer.unify，失败保留前者；
- 穷尽 = `Γ ⊢* p₁ ∨ … ∨ pₙ`（决策 43），主题是名义枚举时用覆盖律展开（enumCoverageDisj），联合主题的 is 分支覆盖全部变体也算穷尽；**穷尽性是提示不是要求**（决策 66）：判不出即退化为 (未密封)，仅名义枚举主题发 W-NON-EXHAUSTIVE；
- 非密封 when 的值流向非 Null 上下文报 **E-NON-SEALED-MATCH**（Checker.kt:402）。

if 规则与之同构（Checker.kt:1198—1261）：条件为 `x is T` 时 then 帧注入 `x : T`（智能转换），else 帧对联合主题收窄；分支类型一致或一侧发散（Nothing 协变），否则报 E-TYPE-MISMATCH；两支皆发散 → Nothing；无 else → Null。

### 2.7 块

$$\frac{\Gamma \vdash s_1 : \text{Null} \dots \Gamma \vdash s_k : \text{Null} \qquad \Gamma' \vdash e : \tau \qquad \text{前序语句无 Nothing 发散}}{\Gamma \vdash \{ s_1; \dots; s_k; e \} : \tau} \quad (\text{T-BLOCK})$$

块事实回溢父帧（弥散，Checker.kt:1188）；Nothing / return 之后的语句与尾表达式报 W-UNREACHABLE（Checker.kt:1184、1190）；无尾表达式 → Null；尾表达式发散 → Nothing。

### 2.8 is 判别与中缀

$$\frac{\Gamma \vdash e : \tau \qquad \Sigma \vdash T : \text{Type} \qquad T \text{ 不是类型类（class）}}{\Gamma \vdash e \text{ is } T : \text{Bool}} \quad (\text{T-TYPETEST})$$

is 只能判断结构体/枚举（含基本类型）；类型类是编译期约束、无运行时 tag，禁止（违者报 E-TYPE-MISMATCH，Checker.kt:1453—1458）。`x is T` 作 if 条件时分支帧注入 `x : T`（v2.1 智能转换）。

$$\frac{\Gamma \vdash e_1 : \tau_1 \qquad \Gamma \vdash e_2 : \tau_2 \qquad \text{builtinOp}(\circ, [\tau_1, \tau_2]) = \sigma}{\Gamma \vdash e_1 \circ e_2 : \sigma} \quad (\text{T-BIN})$$

内建算符表（TypeInfer.kt:135—146）：`+ - * %` 数值（join）；`/` 数值 → Rat；`= == != < > <= >=` 二元 → Bool；`! ¬` → Bool；`& | <-> ∧ ∨ → ↔` → Bool；`..` → Range[T]（端点须数值）；`in` 右侧须区间字面量或 Range[T]。特例：(Str, Str) 的 `+` → Str（Checker.kt:1429）。**宽容位**：操作数是合成类型或类型变量形（isTypeVarForm）时返回合成占位而非误报（Checker.kt:1422—1425）。

### 2.9 声明与赋值

$$\frac{\Gamma \vdash e : \tau \qquad \text{want} = \text{expand}(\sigma) \qquad \text{unify}(\tau, \text{want}) \ne \text{null} \lor \tau \sim \text{want}}{\Gamma \vdash \text{var } x : \sigma = e : \text{want} \qquad \Delta' = \Delta \uplus [x \mapsto \text{want}]} \quad (\text{T-VARDECL})$$

标注类型即变量类型（Kotlin 语义）：unify 只做兼容性检查，不把未绑定类型参数残留进变量类型（Checker.kt:1314—1323）。`τ ~ want` 是绑定兼容视图 compatibleView（§3.1）。无标注时 τ 即变量类型。递归函数值（letrec）：初值是 lambda / 匿名函数时先以合成占位声明、检查完再更新真实类型（Checker.kt:1309—1310）。

## 3. 可变性与引用的所有权规则

### 3.1 视图三公理

- **M-1**：`@mut T` 与 `T` 不是子类型关系，是同一结构的两个视图，严格不相等（typeEq 的 EQ-MUT：双 MutType 时比内层，其余 false，Types.kt:331）。
- **M-2**：`@mut T` 可隐式转 `T`（转换点 = 拷贝点），typeLooseEq 中 a ∈ MutType 时按内层比对（Diffusion.kt:432—434）。
- **M-3**：反向 `T → @mut T` 在**一般相容判定中恒不成立**（typeLooseEq 中 b ∈ MutType 且 a ∉ MutType → false，Diffusion.kt:436）。

唯一例外是 **var 声明位的 compatibleView**（Checker.kt:875—882）：

$$\frac{\text{got} \in \text{MutType} \qquad \text{got.inner} \equiv \text{want}}{\text{got} \sim \text{want}} \quad (\text{CV-MUT-DOWN}) \qquad \frac{\text{want} \in \text{MutType} \qquad \text{got} \equiv \text{want.inner}}{\text{got} \sim \text{want}} \quad (\text{CV-MUT-UP})$$

即 `var a : @mut T = T(0)` 合法——声明标注建立可变视图；`var b : T = a`（@mut T → T）也合法（M-2，转换点深拷贝）。

### 3.2 赋值闸

$$\frac{\Delta(x) \ne \bot \qquad \neg \mu(x) \qquad \text{uncheckedDepth} = 0}{\Gamma \vdash x = e : \text{报 E-IMMUT-ASSIGN}} \quad (\text{S-IMMUT-ASSIGN})$$

不可变变量不能赋值，除非处于 `unchecked` 语句内（uncheckedDepth > 0 时闸门放宽）。

### 3.3 字段写

$$\frac{\Delta(r) = \tau_r \qquad (\tau_r = \text{@mut } S \lor \mu(r)) \qquad \Sigma(S) = \text{struct} \qquad f \text{ 是 } S \text{ 的 @mut 字段}}{\Gamma \vdash r.f = e : \tau_e} \quad (\text{S-FIELD-WRITE})$$

两个前提各自失败都报 **E-NOT-MUT**（Checker.kt:897、899）：字段须是 @mut 字段，且接收者须持有 @mut 视图。@atomic 字段写以 AtomicType 内层同判（Checker.kt:890）。

### 3.4 函数层的 @mut / @impure 联动

$$\frac{\text{pure}(f) \qquad \exists p \in \text{params}(f).\ \text{expand}(p.\tau) \in \text{MutType}}{\text{报 E-IMPURE-REQUIRED}} \quad (\text{F-MUT-PARAM})$$

函数参数类型可变（@mut T）时必须标注 @impure。反向地，函数值类型 FunType 携带 purity 位：体内 impure 调用 / 读写外层可变变量的 lambda 被标记 impure；impure 函数值在纯上下文调用报 E-IMPURE-CALL。可变方法（@mut 注解的方法）只能由持有 @mut 视图的接收者调用，否则 E-NOT-MUT。

### 3.5 绑定等式注入的排除

可变/引用使相等命题不可靠，以下情形**不向 Π 注入** `x = e`（Checker.kt:1331）：

$$\frac{\mu(x) \lor \rho(x) \lor \text{refsMut}(e) \lor \text{isMutStructType}(\tau_x)}{\Pi' \neq \Pi \uplus [x = e]} \quad (\text{P-NO-BIND-EQ})$$

`@mut` 变量仅保有自反相等；`@ref` 变量与 @mut 同等对待（值可经别名变更）。类型层仍注入 `x : T`。Nat 变量恒注入 `x ≥ 0` 自然命题（Checker.kt:925）。

## 4. 绑定拷贝四规则

### 4.1 判断形式

绑定的拷贝判定综合**类型层 @mut**（MutType）与**变量层可变/引用标记**：

$$\Gamma \vdash \text{copy}(\tau_t, \mu_t, \rho_t \leftarrow \tau_s, \mu_s, \rho_s)$$

合并可变标记定义：

- `mut♯_t = (τ_t ∈ MutType) ∨ μ_t`，`mut♯_s` 同理（binderNeedsCopy 的 tgtHasMut / srcHasMut，Checker.kt:866—867）；
- `pure_t = ¬ρ_t ∧ ¬mut♯_t`，`pure_s` 同理。

### 4.2 拷贝规则

$$\frac{\text{mut}^{\sharp}_t \qquad (\neg \rho_t \lor \text{pure}_s)}{\Gamma \vdash \text{copy}} \quad (\text{COPY-①②})$$

$$\frac{\text{mut}^{\sharp}_s \qquad \text{pure}_t}{\Gamma \vdash \text{copy}} \quad (\text{COPY-③})$$

$$\frac{\rho_s \qquad \neg \rho_t}{\Gamma \vdash \text{copy}} \quad (\text{COPY-④})$$

$$\frac{\neg (\text{mut}^{\sharp}_t \land (\neg \rho_t \lor \text{pure}_s)) \qquad \neg (\text{mut}^{\sharp}_s \land \text{pure}_t) \qquad \neg (\rho_s \land \neg \rho_t)}{\Gamma \vdash \text{共享（不拷贝）}} \quad (\text{COPY-SHARE})$$

四条款的自然语读法（Checker.kt:858—863 注释）：

1. 目标含 @mut 视图且源是纯 T（不可变、无引用）→ 拷贝（向纯不可变对象引入可变视图，须快照）；
2. 目标带 @mut 且不带 @ref → 拷贝（每个 @mut 绑定持独立对象）；
3. 源含 @mut 视图且目标是纯 T → 拷贝（割除可变性，须快照）；
4. 源带 @ref 且目标不带 @ref → 拷贝（冻结引用快照）。

其余（不可变值互传、把可变值绑定到 @ref 引用、引用互相别名）共享同一个对象，不拷贝。

### 4.3 判定矩阵

| 绑定（目标 ← 源） | 命中条款 | 判定 | 语义 |
|---|---|---|---|
| `@mut T ← T` | ① | 拷贝 | 引入可变视图，快照 |
| `@mut T ← @mut T`（源非 @ref） | ② | 拷贝 | 每个可变绑定独立对象 |
| `T ← @mut T` | ③ | 拷贝 | 割除可变性，快照 |
| `T ← @ref T` | ④ | 拷贝 | 冻结引用快照 |
| `@mut T ← @ref T` | ①④ | 拷贝 | 冻结引用快照 |
| `@ref @mut T ← @mut T`（源非 @ref） | — | **共享** | 别名 |
| `@ref @mut T ← @ref @mut T` | — | **共享** | 引用互别名 |
| `@ref T ← T` | — | **共享** | 只读视图 |
| `T ← T` | — | **共享** | 不可变值互传 |

每次拷贝发 **D-DEEP-COPY** 补充级诊断并在 deepCopyHits 留痕，代码生成层以 `__dc` 包裹。可运行示例：

```subl
@mut struct Cell(@mut n : Nat)
@impure fun main() {
    var a : @mut Cell = Cell(0)        // CV-MUT-UP
    @ref var r : @mut Cell = a         // 共享（别名）
    var b : @mut Cell = a              // ① 拷贝：b 是独立副本
    b.n = 1                            // a.n 不变；r.n 也不变
}
```

### 4.4 闭包捕获

函数闭包捕获的变量在 lambda 创建时**深拷贝**：解释器沿父链逐值拷（ClosureFun.copyCapture + copiedFrame），JS 侧 `__dc` 对函数**穿透**为既定边界。

## 5. 类型推导

### 5.1 策略定性

凝华的推导**不是** Hindley-Milner，而是实用主义策略（TypeInfer.kt:117—121）：推导失败不立即报错，填 `synthetic` 占位，合成类型在一切比对中恒放行（Diffusion.kt:424），配套三个宽容位。两个层次：

- **简化合一** TypeInfer.unify(τ, σ) → Type?：返回公共类型或 null（分支 join 用）；
- **带替换合一** unifyInto(τ, σ, V, S)：约束求解写入替换表 S（调用点实例化用）。

### 5.2 简化合一（TypeInfer.kt:123—130）

$$\frac{\tau \equiv \sigma}{\text{unify}(\tau, \sigma) = \tau} \quad (\text{U-EQ}) \qquad \frac{\tau \text{ 是合成类型}}{\text{unify}(\tau, \sigma) = \sigma} \quad (\text{U-SYNTH-L}) \qquad \frac{\sigma \text{ 是合成类型}}{\text{unify}(\tau, \sigma) = \tau} \quad (\text{U-SYNTH-R})$$

$$\frac{\tau, \sigma \text{ 均为数值}}{\text{unify}(\tau, \sigma) = \text{rank 高者} \qquad \text{Nat}=0, \text{Int}=1, \text{Rat}=2} \quad (\text{U-NUM}) \qquad \frac{\tau \equiv_{\text{名义}} \sigma}{\text{unify}(\tau, \sigma) = \tau} \quad (\text{U-NOMINAL}) \qquad \frac{\text{其他}}{\text{unify} = \text{null}} \quad (\text{U-FAIL})$$

### 5.3 带替换合一 unifyInto（TypeInfer.kt:18—94）

先对两侧行 deref：沿 S 链展开类型变量，步数上限 32 防环（TypeInfer.kt:97—104）。

$$\frac{\alpha, \beta \in V \qquad \alpha \ne \beta}{S(\alpha) := \beta} \quad (\text{UI-VAR-VAR})$$

$$\frac{\alpha \in V \qquad \sigma \text{ 是合成类型}}{\text{宽容放行（不绑）}} \quad (\text{UI-VAR-SYNTH}) \qquad \frac{\alpha \in V \qquad \alpha \in \text{occurs}(\sigma)}{\text{失败（拒绝无限类型）}} \quad (\text{UI-OCCURS})$$

$$\frac{\alpha \in V \qquad \sigma \text{ 非合成} \qquad \text{occurs check 通过} \qquad S(\alpha) \text{ 已有绑定 } \sigma_0}{\text{looseEq}(\sigma_0, \sigma) \text{ 静默一致性检查}} \quad (\text{UI-VAR-CONSIST})$$

$$\frac{\alpha \in V \qquad \sigma \text{ 非合成} \qquad \text{occurs check 通过} \qquad \alpha \text{ 未绑定}}{S(\alpha) := \sigma} \quad (\text{UI-VAR-TYPE})$$

occurs check 拒绝 `T = Optional[T]` 形无限类型（TypeInfer.kt:107—112）。已绑定变量遇更高数值类型（Nat→Int）走 looseEq 静默保持（数值升格）。

**HKT 合一（方案 A）**（TypeInfer.kt:49—68）：

$$\frac{\text{arity}(F) > 0 \qquad F[\vec{\tau}] \sim C[\vec{\sigma}] \qquad \text{arity}(C) = \bot \qquad |\vec{\tau}| = |\vec{\sigma}|}{S(F) := C \text{（零实参头），并逐位递归 unifyInto}(\tau_i, \sigma_i)} \quad (\text{UI-HKT})$$

$$\frac{S(F) = C_0 \text{ 已绑定} \qquad C_0 \ne C}{\text{失败（构造子不一致）}} \quad (\text{UI-HKT-CONFLICT})$$

对称处理（形参在右时先对调，TypeInfer.kt:55—57）；两端都是构造子形参（`F[A] ~ G[B]`）回落常规分支宽松失败，不误放行（HKT-2 待办）。

**结构递归**（TypeInfer.kt:70—80）：

$$\frac{\text{FunType} \sim \text{FunType}}{\text{逐参数 + 返回值递归}} \quad (\text{UI-FUN}) \qquad \frac{\text{TupleType} \sim \text{TupleType} \qquad |\vec{\tau}| = |\vec{\sigma}|}{\text{逐项递归}} \quad (\text{UI-TUPLE}) \qquad \frac{\text{NamedType}(n, \vec{\tau}) \sim \text{NamedType}(n, \vec{\sigma}) \qquad |\vec{\tau}| = |\vec{\sigma}|}{\text{逐实参递归}} \quad (\text{UI-NAMED})$$

兜底 looseEq（数值放行、synthetic 放行、结构递归；TypeInfer.kt:84—92）——**提取语义非核对语义**：宽松通过不等于类型正确，错误仍由 §6 诊断码在有证据的位置报告。

### 5.4 调用点定点迭代

T-APP 的实例化替换 S 由不动点迭代求解（CallCheck.kt:805—836）：

```
S ← 显式类型实参（一次绑定不覆盖）
重复（≤ 8 轮）:
    逐位 extractTpBinding(形参, 实参, V, S)   // → unifyInto
    lambda 实参带期望二次检查，以其返回反推 S
    若 S 无新解 → 停止
诊断去重（d.dedupe()）
```

这覆盖三类场景：显式实例化（`id<Nat>(1)`）、实参反推（`id(1)` → T := Nat）、lambda 体反推（`xs.map({ x + 1 })` 的 U 只能由体推出）。显式优先 + 不覆盖保证 `id<Nat>("a")` 在实参核对处报 E-TYPE-MISMATCH 而非静默改绑。

### 5.5 推导失败的承接

推导失败**不立即报错**，填合成类型占位（TypeInfer.kt:117—121）：

$$\frac{\Gamma \nvdash e : \tau \text{（无确切证据）}}{\Gamma \vdash e : \text{synthetic}("\text{原因}")} \quad (\text{T-SYNTH})$$

合成类型在一切比对中恒放行（typeLooseEq，Diffusion.kt:424）。配套的三个宽容位：lambda 期望返回是未解析类型参数时跳过核对（Checker.kt:1153—1155）、containsUnresolvedTp 豁免（Types.kt:25—34）、中缀操作数是类型变量形时返回合成（Checker.kt:1422—1425）。这是「实用语言 + 增量类型系统」的过渡策略：类型错误只报有确切证据的。

### 5.6 与第 12 卷的关系

本卷的 `T-/U-/C-` 规则描述**基础方言（当前实现，无子类型）**的宽松策略；[形式化语义12-有界高阶类型](形式化语义12-有界高阶类型.md) 的 `F-` 规则描述**由旗标分离的 Kernel Fω<: 方言**的目标判定系统。两层并存，`F-` 规则不取代任何 `T-/U-/C-` 判定路径（总纲 I-9、12 卷 §0.5 D-2）。关键区分：

1. **两层类型变量**：本卷的合成类型（`synthetic`）与推导期占位类型变量（总纲 `α, β`）**不是**第 12 卷的绑定类型变量（`X, Y, Z`），不参与子类型判定——对应 12 卷的隔离条款 F-VAR-INFER 与 F-ASUB-OPAQUE（见 [形式化语义12-有界高阶类型](形式化语义12-有界高阶类型.md) §0.3、§8.3）。
2. **基础方言无子类型**：本卷的 `≈`/`≡` 是"是否同一类型"的判定，`@mut` 视图转换、数值升格、变体入联合都不是格意义上的 `<:`（总纲 §2.2 根本事实、12 卷 §0.5）。
3. **HKT**：本卷的 HKT 是基础方言的扁平 kind 片段（`★ⁿ→★`、禁嵌套 E-NON-PATTERN-HKT）；方言放开嵌套禁令、引入一般 kind 箭头（见 [形式化语义12-有界高阶类型](形式化语义12-有界高阶类型.md) §1.2、§8.1）。
4. **kind 信息载体**：`Symbols.kindArity`（Symbols.kt:314—321）与 `TypeParam.arity`（Ast.kt:158）是当前唯一的 kind 信息载体，其语义即 kind `★ⁿ→★` 的 n。
5. **不健全点阻塞方言**：本卷 §7 登记的两个不健全点（`typeEq` 忽略 theory 位、QualifiedType 折叠）是启用方言子类型判定的**阻塞项**，修复路线见 [编译器旗标扩展类型系统指导](编译器旗标扩展类型系统指导.md) 工程分期 P0。

## 7. 边界与待核

1. **@ref 的语法层地位**：实现为变量声明注解（帧 R 集），非类型域构造子；语言事实表以「类型形态」口径表述。类型位是否存在 `@ref T` 语法 **待核**。
2. **FunType.theory 位在比对中被忽略**：typeEq（Types.kt:323—337）不比较理论参数；unifyInto / typeLooseEq 同样忽略。Ast.kt:158 注释自述「宽松，后续收紧」。多态函数类型的相等判定不健全——例如 `[T](T) => T` 与 `(Nat) => Nat` 在当前 typeEq 下可能被判为相等。**这是启用 12 卷方言子类型判定的阻塞项**，修复路线见 [编译器旗标扩展类型系统指导](编译器旗标扩展类型系统指导.md) 工程分期 P0。
3. **QualifiedType 折叠**：跨模块限定类型展开为同简单名 NamedType（Types.kt:392），不同模块同名类型会合并为同一类型。折叠后 `≡` 会把两个本应不同的类型判为相等。**同为方言子类型判定的阻塞项**。
