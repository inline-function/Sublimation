## 一、本卷的地位与判断形式

### 1.1 本卷管什么

本卷形式化命题世界的全部判断：命题如何从表达式读出（§2）、事实如何进入 Γ（§3）、自动证明器如何饱和与分解目标（§4、§5）、人怎样用手写语句 discharge 义务（§6）、算术与等式链如何作为独立判定通道（§7）、激进模式如何把搜索放宽而不放宽判定（§8）、以及证明族的诊断判断式（§9）。

本卷的规则前缀为 **P-**（命题域：语法、归一、结构）、**R-**（推理：闭包饱和与目标分解）、**A-**（算术通道）。诊断码（E-CANNOT-PROVE 等）属 09 卷命名空间，本卷只定义其**触发条件判断式**。

### 1.2 两条主判断

$$\frac{}{\Gamma \vdash P \quad \text{或} \quad \Gamma \nvdash P} \qquad \text{（可证判断，二值）}$$

- `Γ ⊢ P`：命题 P 在上下文 Γ 中可证——实现入口 `Checker.proveOrDeep`（Diffusion.kt:208），其内核为 `Prover.proves`（Prop.kt:565）。
- `Γ; P₁,…,Pₙ ⊢ Q`：由定理空间加额外前提 discharge 结论 Q——`BTSStmt` 分支（Checker.kt:633）即此判断的用户接口。

本卷的元变量沿用总纲 §6.1：P, Q, R 命题、e 表达式、Γ/Δ 上下文、Σ 符号表。Γ := `Frame.allFacts()`（沿父链拼接的本帧事实）∪ `globalFacts`（跨帧全域事实池，见 §3.2）。

### 1.3 健全性底线（承接总纲 I-1）

本卷所有规则共同遵守**不猜测底线**：

$$\frac{\Gamma \nvdash P \qquad P\ \text{是证明义务}}{\Phi \vdash \text{编译失败} (\texttt{E-}\dots) \qquad \text{绝不允许} \Gamma \vdash P \text{ 被降级为成立}} \quad (\text{R-NO-GUESS})$$

三条实现锚点：

1. **多路 return 的 $ 归一取保守 null**：`dollarOf`（Diffusion.kt:52）在块内带值 `return` 不唯一时返回 `NameRef(空)`，让下文核对显式失败——源码原注「不猜测——猜测会产生『看似通过实则错误』的证明」。
2. **普通模式轮次有界**：`Prover(maxRounds = 3, maxDepth = 6)`（Checker.kt:41；maxSatDepth = 6）；激进模式才放开（§8）。
3. **不可表达的前提一律跳过而非近似**：算术通道对形态不在片段内的约束返回 `null`（三态），「少用前提只会更保守」（ArithProve.kt:46）。

## 二、命题语法域

### 2.1 Prop 语法

命题域由 `Prop`（Prop.kt:10）给出，PAtom 承载一切原子：

$$P ::= \top \mid \bot \mid \neg P \mid P \land P \mid P \lor P \mid P \to P \mid P \leftrightarrow P \mid \forall \vec{x}.P \mid \exists \vec{x}.P \mid \exists! \vec{x}.P \mid h\langle e_1,\dots,e_n\rangle$$

原子 `h⟨e…⟩` 的来源（`PropLogic.fromExpr`，Prop.kt:29）：

| 源形态 | Prop | 说明 |
|---|---|---|
| `p` | `PAtom(p, [])` | 0 元命题 |
| `valid<7>` | `PAtom(valid, [7])` | 参数化命题（`InstExpr`，Prop.kt:44） |
| `$ == 7` | `PAtom(==, [$, 7])` | 比较/等式（`BinExpr` 归一，Prop.kt:41） |
| `q ○ p` | `PAtom(○, [q, p])` | 两参解糖（符号前缀调用 `<(1,2)` 同理，Prop.kt:48） |
| `$` / `$1` | `PAtom($, [])` / `PAtom($1, [])` | 返回值与第 n 形参引用（决策 65，Prop.kt:32–34） |

### 2.2 从表达式到命题

$$\frac{e = \texttt{TopExpr}}{\textit{fromExpr}(e) = \top} \quad (\text{P-TOP}) \qquad \frac{e = \texttt{BinExpr}(\texttt{→}, a, b)}{\textit{fromExpr}(e) = \textit{fromExpr}(a) \to \textit{fromExpr}(b)} \quad (\text{P-IMP})$$

其中 op ∈ {→,↔,∧,∨} 映射 PImp/PIff/PAnd/POr（ASCII `->`/`<->`/`&`/`|` 与 Unicode 同义）；`∈` 归一为 `in`；其余二元算符一律降为 PAtom 头（Prop.kt:41）。量词 `QuantExpr` 按 ∀/∃/∃! 映射 PForall/PExists/PExists1（Prop.kt:53）。结构外的表达式兜底为 `PAtom(__t__, [e])`（Prop.kt:58）。

**命题位的蕴含必须写作 →（Unicode）**：词法层 `->` 全位非法，lexer 出 ARROW 仅供诊断（langfacts §1）。命题 `when`、上/下文、`axiom` 列表里的表达式都经过 fromExpr。程序位的分支与函数体符号用 `=>`（与本卷无关，见 03/04 卷）。

### 2.3 ASCII ⇄ Unicode 归一表

归一发生在**命题层**（`cmpCanon`，Prop.kt:760；算术通道同表，ArithProve.kt:97–104、384–391）：

| Unicode | ASCII | 归一头 |
|---|---|---|
| ≤ | <= | <= |
| ≥ | >= | >= |
| ≠ | != | != |
| = | == | == |
| ∈ | in | in |
| ∧ ∨ ¬ → ↔ ⊤ ⊥ | & ⏐ ! -> <-> top bot | 结构归一 |

即 `a <= b` 与 `a ≤ b` 在事实匹配、MP、算术通道中视为同一原子（`atomsCmpEq`，Prop.kt:752）。

### 2.4 项结构相等与位置盲

命题项的同一性只认结构，不认源位置：

$$\frac{\textit{termEq}(e_1, e_2)}{e_1 \equiv e_2} \quad (\text{P-STRUCT-EQ})$$

`termEq`（Prop.kt:128）按 IntLit/StrLit/NameRef/ReturnSym/ParamRefExpr/BinExpr/UniExpr/CallExpr/InstExpr/FieldExpr/SymbolCallExpr 逐层结构比较。**位置盲**（`blindPos`，Prop.kt:66）：NameRef.pos 是 LSP 高亮/rename 的定位元数据，但 PAtom 项的 == 是事实成员判定与等式图可达性的基础——「同一变量在两处出现必须仍是同一项」。`proveOrDeep` 入口先对 gamma 与 goal 统一 `blindProp`（Diffusion.kt:211）。

### 2.5 α-等价与命题结构相等

$$\frac{\textit{canonicalize}(P) = \textit{canonicalize}(Q)}{P \equiv_\alpha Q} \quad (\text{P-ALPHA})$$

绑定变量按出现序重命名为 #k 后做忽略 pos 的结构比较（`alphaEq`，Prop.kt:315）：∃x.P 与 ∃y.P 同真。`propStructEq`（Prop.kt:346）服务事实库成员判定与交集操作；`propHash`（Prop.kt:383）供 BFS seen 集 O(1) 去重，碰撞由 propStructEq 兜底。

### 2.6 事实库归一化

事实入 Γ 前先归一（`normalizeFacts`，Prop.kt:62）——四步流水线，对应四条 P- 规则：

$$\frac{P = A \leftrightarrow B}{\textit{norm}(P) = (A \to B) \land (B \to A)} \quad (\text{P-IFF-EXPAND})$$

$$\frac{P = A \land B}{\textit{norm}(P) = \textit{norm}(A) \uplus \textit{norm}(B)} \quad (\text{P-AND-FLAT}) \qquad \frac{P = \neg\neg A}{\textit{norm}(P) = \textit{norm}(A)} \quad (\text{P-NN-STRIP})$$

$$\frac{}{\textit{norm}(P) = \textit{blindPos}(\textit{stripNN}(\textit{flattenAnd}(\textit{expandIff}(P))))} \quad (\text{P-NORM})$$

设计意图：a ↔ b 拆双蕴含「使 MP 能由 ¬irrational<power> 推出 rational<power>」；合取分解让每条合取支独立可匹配。⊤ 不入事实集（`Frame.inject` 丢弃 PTop，Diffusion.kt:40）。

## 三、上下文 Γ 与事实

### 3.1 帧事实集

$$\Gamma = \textit{allFacts}(f) = \textit{allFacts}(f.\textit{parent}) \uplus f.\textit{facts} \quad (\text{P-FRAME})$$

`Frame.facts` 为 LinkedHashSet（去重保序、O(1) 成员判定）；`allFacts` 沿父链拼接（Diffusion.kt:41）。Γ ⊢ P 的搜索空间 = allFacts() + globalFacts。帧拓扑（块事实回溢父帧、lambda 帧隔离）是 03 卷的主题，本卷只消费 allFacts。

### 3.2 全局事实池

`globalFacts`（Checker.kt:43）是跨帧全域事实，由符号注册阶段填充（Symbols.kt）：

$$\frac{f\ \text{未标} \texttt{@impure}}{\Sigma \vdash \texttt{pure<f>} \in \textit{globalFacts}} \quad (\text{P-PURE}) \qquad \frac{p\ \text{未标} \texttt{@mut}}{\Sigma \vdash \texttt{untouch<p>} \in \textit{globalFacts}} \quad (\text{P-UNTOUCH})$$

外加 `immutable<s>`（结构体未含 @mut 字段）、`async<f>`（异步注册）。跨模块补全：可见模块的 pure<f> 按裸名注册，但**某名字在任一可见模块有 @impure 定义则整名不注册**——调用解析无法区分同名异模块，否则对 impure 版本的裸名调用会被同名 pure 事实错误放行（Symbols.kt:31–47）。

### 3.3 公理注入

$$\frac{s = \texttt{axiom } P_1, \dots, P_k}{\Gamma \vdash P_1 \uplus \dots \uplus P_k \in \Gamma} \quad (\text{R-AXIOM})$$

`axiom` 语句（顶层与函数内通用，`canStartAxiomProp` 允许 IDENT/SYMBOL/INT/FLOAT/STR/LPAREN/LNOT/BANG/TOP/BOT/MINUS/FORALL/EXISTS/EXISTS1 起始）逐条 `f.inject(fromExpr(Pᵢ))`，语句值为 Null（Checker.kt:761）。旧的 `unchecked.axiom[p]` 形态已废除，报错引导至新语法。

与 **@axiom 函数注解**（标准库用）别混淆：`@axiom fun` 的签名即公理——下文由作者声明、编译器信任，**不做自动证明义务检查**（只发 D-AXIOM-POST 提示），但函数体仍正常类型检查，上文仍在调用点强制证明（Checker.kt:410）。

```subl
axiom validRange                          // 顶层 axiom：注入模块级作用域事实集

fun bounded(n: Nat) : Nat {
  axiom n ≤ 100                          // 函数内 axiom：注入函数帧 Γ
  n
}
```

## 四、自动证明：饱和闭包

`Prover`（Prop.kt:404）在可判定片段上工作：合取分解、双否、== 自反、∀ 合一特化（单向实例化）、∃ 见证、前向链接 MP、⊥ 爆炸。**不做**：算术推理（由 §7 的独立通道承担）、∨/¬/→ 待证侧引入（激进模式除外，§8.4）、∃! 唯一性的闭包内处理（只在目标分解层，§5.2）、多名字 ∃ 目标（v1 限制）。

### 4.1 MP 闭包饱和

$$\frac{(P \to Q) \in \Gamma \qquad P \in \Gamma}{Q \in \textit{closure}(\Gamma)} \quad (\text{R-MP})$$

加强形态——前件按规范形拆解（合取拆诸支、等价已拆双蕴含、双否已消），各支都在 Γ 即触发（Prop.kt:458–463）：

$$\frac{(P_1 \land \dots \land P_n \to Q) \in \Gamma \qquad P_1,\dots,P_n \in \Gamma}{Q \in \textit{closure}(\Gamma)} \quad (\text{R-MP-CONJ})$$

### 4.2 逆否分离

$$\frac{(P \to Q) \in \Gamma \qquad \neg Q \in \Gamma}{\neg P \in \textit{closure}(\Gamma)} \quad (\text{R-MT})$$

modus tollens（后件否定推前件否定）——经典逻辑健全（Prop.kt:466）。

### 4.3 矛盾检测

$$\frac{P \in \Gamma \qquad \neg P \in \Gamma}{\bot \in \textit{closure}(\Gamma)} \quad (\text{R-CONTRA})$$

先收集 ¬ 集合转 O(N) 判定（Prop.kt:472）。⊥ 是穷尽性/不可达分支判定的基础。

### 4.4 ∀ 实例化

$$\frac{(\forall x. P) \in \Gamma \qquad t \in \textit{keyTerms}(\Gamma, \textit{goal})}{P[x := t] \in \textit{closure}(\Gamma)} \quad (\text{R-FORALL-INST})$$

候选项 keyTerms 是**命题池全局供给**：由 `groundTerms`（Prop.kt:259）收集「程序里出现的一切表达式」——后序遍历（内层先入、外层后入），复合项 `1+2`、`f(1+2)`、`a.x` 也进候选；**一次性固定、此后不随新增事实扩张**。源码原注：否则复合项会自我增殖导致笛卡尔爆炸、永不达不动点（Prop.kt:429）。目标的 ground 项并入候选（否则 `∀n.p<n>` 永远举不出目标里的具体项，Prop.kt:569）。多名字 ∀ 取候选的笛卡尔积（Prop.kt:439）。

健全性边界：extraGoals 的项只作实例化候选、不作为事实加入——否则目标平凡可证（Prop.kt:424）。

### 4.5 不动点与终止

$$\frac{\text{本轮无新事实}}{\textit{closure}(\Gamma)\ \text{停止}} \quad (\text{R-FIXPOINT})$$

普通模式另有 maxRounds = 3 的硬截断（Checker.kt:41）；深度截断产 E-DEEP-SATURATION（§9）。实例化矩阵预计算（forallSubs）：keyTerms 固定 ⇒ 各 ∀ 的候选替换跨轮不变——每轮重建是 Kⁿ 开销（show.subl 卡顿根因，Prop.kt:435）。

### 4.6 ∃ 匹配（目标侧）

闭包不做 ∃ 消去；∃ 事实在**目标原子判定**时做单向合一特化（`matchAtom`，Prop.kt:714）：

$$\frac{(\exists x. P) \in \Gamma \qquad \textit{matchProp}(P[x \mapsto \text{通配}], Q)}{\Gamma \vdash Q} \quad (\text{R-EXISTS-MATCH})$$

`matchTerm`（Prop.kt:152）中属于量词约束名的 NameRef 是通配：首次出现绑定、之后要求一致（合一的单向特化，非完全合一）。

## 五、自动证明：目标分解

`Prover.prove`（Prop.kt:598）对目标按结构递归分解，visited 集防环（同目标在证明路径上重现即剪枝），深度预算 curBudget（普通模式恒为 maxDepth = 6；激进模式迭代加深，§8.2）。

### 5.1 结构分解规则

$$\frac{}{\Gamma \vdash \top} \quad (\text{R-TOP}) \qquad \frac{\bot \in \Gamma}{\Gamma \vdash \bot} \quad (\text{R-BOT}) \qquad \frac{\bot \in \Gamma \qquad P \neq \bot}{\Gamma \vdash P} \quad (\text{R-BOT-EXP})$$

$$\frac{\Gamma \vdash A \qquad \Gamma \vdash B}{\Gamma \vdash A \land B} \quad (\text{R-AND-INTRO}) \qquad \frac{\Gamma \vdash A \to B \qquad \Gamma \vdash B \to A}{\Gamma \vdash A \leftrightarrow B} \quad (\text{R-IFF-INTRO})$$

$$\frac{\Gamma \vdash A \quad \Gamma \vdash B \qquad (\text{先试两支}) \qquad \textit{disjSubset}(\Gamma, A \lor B)}{\Gamma \vdash A \lor B} \quad (\text{R-OR-INTRO})$$

$$\frac{\Gamma, \textit{norm}(A) \vdash B}{\Gamma \vdash A \to B} \quad (\text{R-IMP-INTRO}) \qquad \frac{\Gamma \vdash A}{\Gamma \vdash \neg \neg A} \quad (\text{R-DN-INTRO})$$

注意 (A∨B) ⊢ (A∨B∨C) 与 (A∨B∨C) ⊢ (A∨B) 的不对称：**析取子集规则**（`disjSubset`，Prop.kt:692）只允许子集 ⊆ 超集方向——「覆盖律 (R∨G∨B) 证得出穷尽目标，但证不出残缺目标 (R∨G)，恰是 partial when 应报 W-NON-EXHAUSTIVE 的语义」。不递归、不随事实库膨胀。

### 5.2 量词目标规则

$$\frac{\Gamma \vdash P[x := c] \quad \text{对某个} c \in \textit{groundTerms}(\Gamma)}{\Gamma \vdash \exists x. P} \quad (\text{R-EXISTS-WITNESS})$$

见证候选取 Γ 的 ground 项；多名字 ∃ 目标当前不可判（names.size != 1 → false，v1 限制，Prop.kt:615）。

$$\frac{\Gamma \vdash P[\vec{x} := \#vg]}{\Gamma \vdash \forall \vec{x}. P} \quad (\text{R-FORALL-INTRO})$$

概括规则（Prop.kt:620）：绑定名替换为新鲜常量（按深度与序编号、合法标识符不含 # 故必新鲜）后证 body。多名字量词修复：新鲜常量在原闭包的实例化候选之外——以替换后的目标为 extraGoals **重算闭包**，使 Γ 里的 ∀ 事实能以这些常量为候选实例化（如 `∀n,m. n=m ⊢ ∀a,b. a=b`，Prop.kt:627）。

$$\frac{\Gamma \vdash P[x := c] \qquad \Gamma \vdash \forall y. (P[x := y] \to y = c)}{\Gamma \vdash \exists! x. P} \quad (\text{R-EXISTS1-DECOMP})$$

唯一存在分解（Prop.kt:636）：∃!x.P(x) ⟺ ∃x.P(x) ∧ ∀y.(P(y) → y = x)，见证候选取 Γ 的 ground 项，对每个候选 c 证两支。

### 5.3 原子目标判定

原子 Q = h⟨e₁,…,eₖ⟩ 的判定是多通道析取（Prop.kt:654，自上而下短路）：

$$\frac{h\langle e\rangle \in \Gamma \ (\text{结构等})}{\Gamma \vdash h\langle e\rangle} \quad (\text{R-MEMBER}) \qquad \frac{(P \to Q) \in \Gamma \qquad \Gamma \vdash P \qquad \textit{matchProp}((P \to Q).b, Q)}{\Gamma \vdash Q} \quad (\text{R-BACKCHAIN})$$

$$\frac{\text{目标} C\langle a_1\rangle = C\langle b_1\rangle \qquad a_1 = b_1 \in \Gamma \lor a_1 ≡ b_1}{\Gamma \vdash C\langle a_1\rangle = C\langle b_1\rangle} \quad (\text{R-INJ})$$

构造子单射（决策 49）：一元构造子如 Some 最常见；覆盖律公理由检查器注入 Γ 后 MP 通道可自动触发，此规则补一层直接判定免深度不足漏证（`injective`，Prop.kt:774）。

$$\frac{e_1 \rightsquigarrow_\Gamma e_2 \ (\text{等式图 BFS 双向边})}{\Gamma \vdash e_1 = e_2} \quad (\text{R-EQ-REACH})$$

等式推理（决策 80）：以预提取的 = / == 事实建无向图（无向边含对称、BFS 即传递闭包），有界 O(V+E)（`eqReachable`，Prop.kt:793）。适用头：= == <= ≤ >= ≥，且先试 termEq 自反。

$$\frac{e : T \in \Gamma \qquad e \rightsquigarrow_\Gamma e'}{\Gamma \vdash e' : T} \quad (\text{R-TYPEFACT-EQ})$$

类型事实在等式下的传播：`var m = n`（未声明类型）经 `m = n` 与 `n : Nat` 连上（`typeFactEq`，Prop.kt:815）。

**filter 后验推理**（`membershipFilterPred`，Prop.kt:728）：Γ 含 `e ∈ filter(xs, λp. body)` 时，filter 的语义保证该元素满足谓词——把谓词 β-归约到 body[p:=e] 与目标原子比对（比较运算符允许 ASCII/Unicode 等价）。

**$ 代换**（`substDollar`，Prop.kt:234）：命题中的 $ 在函数下文核对时替换为 dollarOf(body)（体内唯一带值 return，否则尾表达式，否则 null）；$n 在声明期已改写为参数名，若漏到此处原样透传。

### 5.4 纯度对结构相等的限制

$$\frac{e \text{纯} \ (\text{不含} \texttt{@impure} \text{调用})}{\Gamma \vdash e = e} \quad (\text{P-REFL}) \qquad \frac{e \text{含不纯调用}}{e = e \text{只认} \Gamma \text{显式事实}} \quad (\text{P-IMPURE-NO-REFL})$$

实现：`containsImpureCall`（Diffusion.kt:144）——NameRef/FieldExpr 形 callee 查符号表 @impure，**动态计算 callee（λ 槽位等）保守视为不纯**；不纯表达式的比较命题（= == != ≠ < > <= ≤ >= ≥）只走显式事实匹配（Diffusion.kt:308）。

### 5.5 通道流水线

`proveOrDeepInner`（Diffusion.kt:278）按**顺序敏感**的通道链尝试，命中即短路返回（P27 通道顺序）：

1. **自定义命题展开** `expandDefined`：`def p<a,b> ↔ <等价>` 按定义代换（最多 5 层，展开结果与目标同构即停视为原子；仅有签名无 ↔ 的 def 是原子谓词，Diffusion.kt:127）；
2. **PNot/PImp 常量拆解**：¬<1=0> 真 ⟺ <1=0> 假；蕴含前提常量假则恒真、常量真则只证后件；
3. **PAnd 引入**：逐支证；
4. **常量原子真值** `constAtomValue`（含 in 区间分支，Diffusion.kt:62）；
5. **常量类型** `constTypeAtom`（1 : Nat、"s" : Str，Diffusion.kt:91）；
6. **不纯结构相等限制**（§5.4）；
7. **类型判定** `typeJudgement`：Γ 的 x : T 事实匹配，或构造表达式结果类型归属（Diffusion.kt:173）；
8. **常量归约** `reduceGoalToConstants`：`var m = 5 ⇒ m = 5` 事实把目标里的名字替换为字面量（Diffusion.kt:102）；
9. **Real 代数重写**：等式两边转 Real → normalize + structuralEqual（Diffusion.kt:318、Real.kt）；
10. **线性算术通道**：**只有判成立（true）才短路**；判不成立或形态不支持都继续——避免掐断等式图/等量代换等其它推理（P4 链式代换回归教训，Diffusion.kt:323）；
11. **通用证明器** `prover.proves(Γ, goal, globalFacts)`；deepAborted 时报 E-DEEP-SATURATION；
12. **反证法**（仅激进 + @classic）：Γ ∪ {¬goal} 饱和出 ⊥ ⇒ Γ ⊢ goal（Prop.kt:417）；
13. **定理搜索** `searchTheorems`：定理空间（core 标准库跨模块 + 用户 @theorem + 局部定理）后件与目标结构合一。

### 5.6 能力边界

普通模式**不做**：算术推理（通道 10 独立承担）、∨/¬/→ 待证侧引入、多名字 ∃ 目标。判不出即 Γ ⊢ P 不成立——返回诊断而非近似成立（I-1）。

## 六、公理注入与手动证明语句

### 6.1 ∵∴ 证明义务

$$\frac{(\Gamma \vdash P_i)_i \qquad \Gamma; P_1,\dots,P_n \vdash Q}{\Gamma, \texttt{∵} P_1,\dots,P_n \texttt{∴} Q \vdash Q \in \Gamma} \quad (\text{R-BTS})$$

两阶段判断（`BTSStmt`，Checker.kt:633）：

1. **前提各自先证**：`proveOrDeep(f.allFacts(), Pᵢ) || searchTheorems(Pᵢ, 0, f.localTheorems)`——任一不成则 E-PREMISE-UNPROVEN（§9），结论不再尝试；
2. **结论由「定理空间 + 前提」证**：`proveOrDeep(allFacts + premises, Q) || searchTheorems(...)`——不成则 E-CANNOT-PROVE；成则 f.inject(Q) 并发 D-BTS 提示。

```subl
axiom validRange                          // 顶层 axiom 注入模块级作用域

fun bounded(n: Nat) : Nat {
  axiom n ≤ 100                          // 函数内 axiom：注入函数帧 Γ
  ∵ n ≤ 100 ∴ n ≤ 101                    // 前提 ∈ Γ；结论由算术通道 discharge（A-NEG）
  n
}
```

### 6.2 by 断言（t30 后；旧「直接供给」已废除）

$$\frac{\Gamma \vdash Q_1 \quad \cdots \quad \Gamma \vdash Q_k}{\Gamma \vdash \texttt{expr by} [Q_1,\dots,Q_k] : T} \quad (\text{R-BY-ASSERT})$$

t30（用户决策「by 只有委托」）废除旧语义：语句式 `by [q]` 删除（Parser 仍解析，Checker 报 `E-BY-REMOVED` 并指引改用 `axiom`）；后缀式 `expr by [q]` 的 props **不再注入 Γ**，改为证明义务——挂入 checker 的待核队列（pendingByAsserts），在包围语句/函数体检查完（名字绑定与事实注入就绪）后由 `proveOrDeep(f.allFacts(), Qᵢ)` 逐条核对，证不出报 `E-CANNOT-PROVE`。旧规则 R-BY（免验证入 Γ）与 `D-BY` 提示随之删除；免验证供给只剩 `axiom`（§6.1）。

### 6.3 量词语句

$$\frac{\Gamma \vdash P[\vec{x} := \vec{t}]}{\Gamma \vdash \exists \vec{x}. P \in \Gamma} \quad (\text{R-EXIST-INTRO}) \qquad \frac{(\exists x. P) \in \Gamma (\text{渲染等}) \qquad \Gamma, P \vdash \dots}{\Gamma \vdash \text{块结论回溢}} \quad (\text{R-EXIST-ELIM})$$

- **∃ 引入** `∃ x = t . P`（`ExistIntroStmt`，Checker.kt:727）：实例化后证明不成则 E-QUANT-UNPROVEN；成则注入 ∃x.P 并发 D-EXIST-INTRO；
- **∃ 消去** `∃ x . P { … }`（`ExistsElimStmt`，Checker.kt:738）：前提 ∃x.P 须在 Γ（按渲染比较），不在则 E-PROP-UNBOUND（warn 级）；在则子帧注入 P(x)，块内 ∵∴ 结论回溢父帧（弥散机制见 03 卷）；
- **∀ 引入 = 局部函数**（`FunStmt`，Checker.kt:751）：局部函数定义登记为局部定理（形参即绑定变元），**必须有体**——「∀ 引入要求有体，不是签名即证明」，无体则 E-QUANT-UNPROVEN。

### 6.4 分类讨论与排中律

命题 when `when[p ∨ q] { p => {…} }`（`WhenPropStmt`，Checker.kt:657）：析取前提须在 Γ（渲染比较），不在发 W-PROP-UNBOUND；每支注入自己的析取支后检查块体，各支 ∵∴ 结论取**按渲染键的公共交集**注入块外——空交集发 W-WHEN-NO-COMMON。分支位的蕴含须加括号（parser stopArrow 机制）。

`if[p]` 排中律（`IfPropStmt`，Checker.kt:701）：需 @classic 挂载（文件内任一声明加 @classic 即挂载；未挂载发 E-NEED-CLASSIC 警告）。两支各注 p / ¬p，两支**新注入事实按结构相等取交**作为「与 p 无关、两支都成立」的公共结论注入块外；交集为空发 E-IF-CONCLUSION-MISMATCH。

### 6.5 策略语句

$$\frac{@\textit{strat}[P] \qquad \textit{strat}(P, \Gamma) = \text{真}}{P \in \Gamma} \quad (\text{R-STRATEGY})$$

`StrategyStmt`（Checker.kt:685）按策略名分派，证出则注入并发 D-STRATEGY，不成则 E-STRATEGY-FAILED：

- **@simp**（`simpProve`，Checker.kt:1445）：委托 ArithProve.proves（区间 + 常量折叠 + 不等式，§7）；
- **@subst**（`substProve`，Checker.kt:1477）：莱布尼茨代换——① 项级用 = / == 等式事实单向代入 PAtom 的任意 term；② 命题级用 ↔ 等价事实单向代入子命题。BFS 传递闭包改写直至命中事实库（步数上限 400、项体积上限 400——防膨胀型改写 2→√2·√2 指数爆炸）；命中判据含平凡自反等式 t = t。

### 6.6 定理函数与定理搜索

$$\frac{\texttt{@theorem} \text{在} f \text{的注解里}}{\Sigma \vdash f \in \textit{theorems}} \quad (\text{P-THEOREM})$$

**只有 @theorem 显式标注的函数才是定理函数**（登记进定理空间，编译器擦除其代码，只供证明位）；非 @theorem 函数即使纯 + Null 也不进定理空间（`isTheoremFun`，Diffusion.kt:340）。@classic 挂载使 `syms.classicMounted = true`（Symbols.kt:187）。

**定理搜索**（`searchTheorems`，Diffusion.kt:346）：搜索深度默认**两跳**——超限报 E-THEOREM-SEARCH-DEPTH（warn 级）。命中判据：定理后件（post）与目标做**结构合一**——定理的 theory 参数（如 @p）与局部函数形参为元变量，可绑定到目标对应位置的任意项（`postUnifies`/`termUnifies`，Diffusion.kt:370；命题元变量 = 后件里无参数的裸名原子，可绑定到任意目标命题——排中律等形态）。后件里的名字若可由全局事实归为字面量，归约后再合一。

**下文义务**：函数下文 `⟨q⟩` 在体内兑现——goal = substDollar(fromExpr(post), dollarOf(body))，`proveOrDeep(allFacts, goal)` 不成则 E-POST-UNPROVEN（Checker.kt:414）；@axiom 函数豁免此义务（§3.3）。上部前件 preps 在声明期即注入函数帧 Γ（Checker.kt:377）。匿名函数（lambda）下文同构（Checker.kt:1330）。

## 七、算术通道

`ArithProve`（ArithProve.kt:22）是证明器的**通用算术通道**：把约束归一为线性形式 Σ cᵢ·vᵢ ≤ C（移项、常数折叠、系数提取），整数域判定。返回**三态**：true 成立 / false 判定不成立 / null 形态不在片段内。

### 7.1 线性化

$$\frac{e \rightsquigarrow \textit{lin}(e) = Σ c_i \cdot v_i + c}{\text{A-LIN}} \quad (\text{字面量→常数；变量→系数 1；+ - * / folding；一元 - 取负})$$

`linOf`（ArithProve.kt:173）：乘法仅当一侧为常数（scale）；除法仅当两侧常数且整除；其余形态返回 null（不可表达）。

### 7.2 前提消费（约束注入）

$$\frac{l \texttt{<=} r \qquad \textit{lin}(l) - \textit{lin}(r) = Σ c_i v_i + c}{Σ c_i v_i ≤ -c \in \textit{Ctx}} \quad (\text{A-REL})$$

按 coefs 个数分派（`applyRel`，ArithProve.kt:108）：

- **0 个变量**：C < 0 ⇒ 前提矛盾（Ctx.contradicted，爆炸原则）；
- **1 个变量**（含系数）：2x ≤ 6 → x ≤ 3、x + 1 ≤ 5 → x ≤ 4、-x ≥ 5 → x ≤ -5，收紧绝对界 [lo, hi]（整数 floorDiv/ceilDiv 上下取整，两端安全）；lo > hi ⇒ 矛盾；
- **2 个变量 ±1（差分）**：x ≤ y 建边 to ≤ from + w，Bellman–Ford 传播（x ≤ y ∧ y ≤ 5 → x ≤ 5 即传递链）；
- **= / ==**：拆 ≤ ∧ ≥ 是**原子约束**——任一侧不可表达则整体不注入（快照后统一回滚，含名字索引表防边索引错位，ArithProve.kt:116）；
- **in 区间**：x ∈ (a..b) 消费为 x ≥ a ∧ x ≤ b。

¬P 前提（`consumeNeg`）按比较取反注入（≤→> 等）。**无法表达的前提一律跳过**：「少用前提只会更保守，绝不因无关事实放弃通道」（ArithProve.kt:46）。Ctx 每次 proves 新建，杜绝跨证明同名变量共用索引（P1 全局状态污染，ArithProve.kt:72）。

### 7.3 目标判定与反证

$$\frac{\Gamma \land \neg G \text{不可满足}}{\Gamma \vdash G} \quad (\text{A-NEG})$$

单原子目标 G 判 Γ ∧ ¬G 不可满足（`atomImplied`/`negateAndApply`，ArithProve.kt:282/317）：¬G 为单变量界时用界判（lo > b 或上界 upperBound < b——upperBound 把单变量界转 ZERO 边与差分边一起求最短路，x = y = z ≤ 7 时 upper(x) = 7，等式链传播）；差分时并入图判负环；常量对直接折叠判定（`evalConst`：1 + 1 = 2、2 * 3 = 6、1 ≠ 2）。两变量等式判 ≤ 与 ≥ 两向都成立 ⟺ 相等。

### 7.4 负环 ⇒ 矛盾

$$\frac{\textit{Ctx} \text{的差分图含负环}}{\Gamma \vdash \text{任意目标}} \quad (\text{A-CYCLE})$$

`bfHasNegCycle`（ArithProve.kt:238）：前提片段内矛盾（负环/界空）→ 蕴含一切（爆炸原则），直接返回 true。健全性关键：**健全性靠「无法表达即跳过」与「矛盾即爆炸」，不存在近似判定**。

### 7.5 析取反证（when 穷尽）

$$\frac{\text{叶子共享同一变量} v \qquad [lo,hi] \setminus \bigcup_i \textit{rng}(\textit{leaf}_i) = \emptyset}{\Gamma \vdash \textit{leaf}_1 \lor \dots \lor \textit{leaf}_n} \quad (\text{A-DISJ-REFUTE})$$

`disjRefute`（ArithProve.kt:354）：单变量叶子域差集反证（原子否定为区间补）——覆盖律析取 (R∨G∨B) 经此通道证出，残缺目标证不出。when 穷尽性（05 卷）据此。

### 7.6 差分图与等式链代换的形式化

差分图即 §7.2 的双变量 ±1 边；**等式链代换（= 双向边 + 传递）**有两处落点：

1. 算术通道内：= 拆 ≤ ∧ ≥ 双向差分边 + x = c 夹定，Bellman–Ford 传播；
2. 通用证明器内：R-EQ-REACH 的无向等式图 BFS（§5.3）。

回归测试口径（compiler/.../checker/CheckerTest.kt:1762–1819）：前提 {x + 1 ≤ 5, 2y ≤ 6} → x ≤ 4（移项）/ y ≤ 3（系数）；a ≤ b ∧ b ≤ c → a ≤ c（传递），而 c ≤ a 推不出（反例守健全）；x = y = z ≤ 7 → x ≤ 7（等式链双向差分边 + 传递）；x = 2 且 0 ≤ x ≤ 5 → x ∈ (1..3)（in 区间），x = 2 ∉ (3..9) 为反例。

### 7.7 Real 代数重写通道

$$\frac{\textit{realFromExpr}(e_1) = a \qquad \textit{realFromExpr}(e_2) = b \qquad \textit{structuralEqual}(\textit{normalize}(a), \textit{normalize}(b))}{\Gamma \vdash e_1 = e_2} \quad (\text{A-REAL})$$

仅判 = / ==：等式两边能转成 Real（含根式等代数形态）→ normalization 后结构相等即证得（Diffusion.kt:316、Real.kt）。**只判等式**，不判不等式；realFromExpr = null 则落空。

## 八、激进模式

CLI 标志 `--prover=aggressive`（Main.kt:36、48），**只作用于 compile/check**（Main.kt:195）。定位：**更彻底的搜索，不是更宽松的判定**（Aggressive.kt 标题注）。

### 8.1 与普通模式的差异边界（I-7）

$$\frac{\textit{aggressive} = \text{false}}{\textit{session} = \text{null} \qquad \text{所有激进分支关闭} \qquad \text{行为与开启前完全一致}} \quad (\text{R-NORMAL-STABLE})$$

普通模式：Prover(maxRounds = 3, maxDepth = 6)，无会话、无三维池、无 ∨ 消去、无反证法。同一源文本不加旗标时，诊断与产物必须完全一致（总纲 I-7；aggressive 默认 false，Checker.kt:26）。

### 8.2 会话与迭代加深

激进模式：maxRounds = Int.MAX_VALUE——**靠不动点判据退出**（本轮无新事实则停，Prop.kt:559）；prove 深度预算**迭代加深 4→8→16…**（`provesAggressive`，Prop.kt:577），配 visited 剪枝；deepAborted 为假即真不可证（未被深度截断）。

$$\frac{\textit{memo}[\Gamma \mapsto Q] \text{命中}}{\Gamma \vdash Q} \quad (\text{R-MEMO})$$

**正向记忆化**：只记**已证**（渲染键）——「失败可能只是深度不够，迭代加深后或可证，记失败会误杀」（Aggressive.kt:29）。

### 8.3 三维关键池与按维度分派

`KeyPool`（Aggressive.kt:198）：表达式 / 类型 / 命题三维。池的守门人是**有约束来源**：候选只来自程序里实际出现过的项/类型/命题——**不枚举名义类型、不枚举命题空间**（「无约束的凭空生成是永动机」，Aggressive.kt:196）。

$$\frac{x \text{在体里以裸原子出现}}{x \to \textit{PROP} \text{池}} \qquad \frac{x \text{在} : \text{事实右端出现}}{x \to \textit{TYPE} \text{池}} \qquad \frac{x \text{在其余项位置出现}}{x \to \textit{EXPR} \text{池}} \quad (\text{R-DIMS})$$

`dimsOf`（Aggressive.kt:256）：裸原子 p → 命题池（排中律的 P）；: 右端 T → 类型池（预算外另补符号表类型提示：结构体/枚举/类型类名经 typeToExpr 装为项候选，Diffusion.kt:229）；其余 → 表达式池。命题维替换用 `substPropParam`（裸原子 @q → 实际命题），项/类型维用 `substProp`（类型经 typeToExpr 再装为项）。组合上限 maxCombos = 4096（每条 ∀）——**只截搜索不猜**，健全性不受影响（Aggressive.kt:41）。池规模上限：maxExprs = 500、maxTypes = 200、maxProps = 200，超限时保留与目标重叠度高者。

**命题维实例化**即「∀p 的 p 分派命题池穷举」：排中律等命题定理的命题元变量由此分派到 Γ/目标里出现过的实际命题。

### 8.4 经典逻辑扩展

$$\frac{A \lor B \in \Gamma \qquad \Gamma, A \vdash Q \qquad \Gamma, B \vdash Q}{\Gamma \vdash Q} \quad (\text{R-OR-ELIM}) \qquad \frac{\Gamma \cup \{\neg Q\} \vdash \bot}{\Gamma \vdash Q} \quad (\text{R-CONTRADICTION})$$

- **∨ 消去**（Prop.kt:665，**仅激进**）：Γ 含 A∨B 时分情况证目标，两支都证出才算成；分支内 p 与 ¬p 并存 ⇒ 该分支矛盾、任意目标成立（析取三段论落点）。curUsedOr 记录本路径已拆析取式，防同一析取被反复拆。
- **反证法**（Prop.kt:417，**激进 + @classic**）：Γ ∪ {¬goal} 饱和出 ⊥ ⇒ Γ ⊢ goal——「经典逻辑独有（直觉主义只得 ¬¬goal），未挂 core.classic 绝不启用」（Diffusion.kt:330）。
- **排中律前向实例化** `lemAugment`（Diffusion.kt:253，**激进 + @classic**）：可见定理里形状为 p ∨ ¬p 的（如 core.classic tertiumNonDatur），对命题池每个候选 A 注入 A ∨ ¬A 进 Γ——配合 ∨ 消去完成分情况证明。

### 8.5 不猜测底线（不可违反）

§1.3 的 R-NO-GUESS 在激进模式下的具体形态：此处的一切只做「搜得更深更广」——不猜、不近似、不接受未证前提。中断时（Ctrl-C → `ProverInterrupted`，Aggressive.kt:22，一路打到 CLI、checker 内无吞异常）证不出的目标**如实列为未证**。

### 8.6 可观测性与诊断报告

`ProverSession`（Aggressive.kt:31）：进度 stderr 节流（默认 5 秒或 100 步）、义务计数（「证明义务」= 顶层 proveOrDeep 调用，递归展开不计）、正向记忆化、当前目标栈与 Γ 栈。Ctrl-C 钩子经 `AggressiveRuntime.interrupt()`（Main.kt:199）置中断位，搜索循环在下一个 `checkAbort` 抛异常退场。报告（`writeReport`，Aggressive.kt:140，默认 sublimation-prover-dump.md，仅中断时写）：卡住的目标、当前 Γ、已证/总计义务、搜索统计（总步数、三维池规模、最近尝试的定理）、issue 模板。

## 九、证明族诊断判断式

诊断码属 09 卷命名空间；本卷给出**触发条件判断式**。位置一律取语句位 行:列（从 1 计）。

### 9.1 ∵∴ 族

$$\frac{\Gamma \nvdash P_i (\text{某前提，含定理空间})}{\Phi \vdash \texttt{∵} \dots \texttt{∴} \dots ⇒ \texttt{E-PREMISE-UNPROVEN}} \quad (\text{N-PREMISE})$$

$$\frac{\Gamma \vdash P_i (\forall i) \qquad \Gamma; P_1,\dots,P_n \nvdash Q (\text{含定理空间})}{\Phi \vdash \texttt{∵} \dots \texttt{∴} Q ⇒ \texttt{E-CANNOT-PROVE}} \quad (\text{N-CONCL})$$

两条消息都附「当前已知事实 Γ」全文渲染；E-CANNOT-PROVE 另附已试定理名列表（空则「（无定理函数）」）。

### 9.2 量词与上下文族

$$\frac{\Gamma \nvdash P[\vec{x} := \vec{t}]}{\Phi \vdash \exists \text{引入} ⇒ \texttt{E-QUANT-UNPROVEN}} \quad (\text{N-EXIST-INTRO}) \qquad \frac{(\exists x. P) \notin \Gamma}{\Phi \vdash \exists \text{消去} ⇒ \texttt{E-PROP-UNBOUND} (warn)} \quad (\text{N-EXIST-ELIM})$$

### 9.3 饱和与策略族

$$\frac{\textit{deepAborted} \land \Gamma \nvdash P}{\Phi \vdash \texttt{E-DEEP-SATURATION}} \quad (\text{N-DEEP}) \qquad \frac{\text{搜索深度} > 2}{\Phi \vdash \texttt{E-THEOREM-SEARCH-DEPTH} (warn)} \quad (\text{N-DEPTH})$$

### 9.4 unchecked 与证明的关系

`unchecked <语句>` 使 uncheckedDepth++ 并强制 pure := false（Checker.kt:767）——unchecked 是效应/可变性的受控开口（04 卷），**不是证明义务的逃逸**：∵∴、下文、穷尽性等证明义务在 unchecked 内**仍然检查**——本卷无任何「unchecked 跳过证明」的规则。解释器直接执行 inner（Evaluator.kt:194 附近），JS 侧注 // unchecked 后透传。
